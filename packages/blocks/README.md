# @birdycom/omniaui-blocks

Ready-made page sections composed from OmniaCSS utilities and components: hero, hero-split, page-hero, features, pricing, stats, stats-counter, CTA, auth, footer.

```bash
npx omniacss add block pricing        # → omnia/blocks/pricing.html
npx omniacss list blocks
```

CSS: `import "@birdycom/omniaui-blocks"` (or let `omniacss build` include it). MIT
