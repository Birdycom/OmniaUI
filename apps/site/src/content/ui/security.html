Security notices

When we find a serious security problem in OmniaUI or OmniaUI Pro, it is listed here with the affected versions and the fix. Every OmniaUI Pro customer, also those whose subscription has ended, gets an email as well.

Notices

No security notices

No security problems have been reported so far. Last checked: 30 October 2026.

Who gets the fix

  • Free packages (OmniaCSS, OmniaUI, the React, Vue and Laravel packages): a patch release on npm and Packagist, for everyone.
  • OmniaUI Pro, active license: a patch release in Birdycom/OmniaUI-Pro-releases.
  • OmniaUI Pro, ended subscription: serious security fixes stay free for everyone who ever had a license, for the versions they received. The notice explains the fix; mail support@omniaui.eu and we send a patched release of the last version you had. See the terms.

Report a problem

Found a security problem? Mail support@omniaui.eu with the package, the version and the steps to reproduce it. Please do not open a public issue for it. We answer within a few working days.

Machine-readable list

The same notices as JSON, for tools that check the installed versions: /data/security.json.

{ "updated": "2026-10-30", "advisories": [ { "id": "OMNIAUI-2026-001", "package": "@birdycom/omniaui-pro", "affected": "<0.12.4", "fixed": "0.12.4", "severity": "high", "title": "Short description", "url": "https://omniaui.eu/ui/security.html#OMNIAUI-2026-001" } ] }
