OTP verification

Verification screens around the .oc-otp component: simple card, split layout and a four-digit PIN with a back link. All blocks.

Variants

Plain HTML and CSS. Each preview shows the markup that builds it, also available as a snippet in packages/blocks/blocks/ (the variants marked Pro are part of OmniaUI Pro): otp-01, otp-02, otp-03.

OTP 01 - Simple card

Verification card: six-digit code, verify button and a resend link. Snippet: otp-01 (npx omniaui add otp-01).

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).

.oc-block-authpagePage wrapper that centers one card. Modifier: --plain (page background instead of muted)
.oc-block-authcardCard column. Modifiers: --flat (no card chrome), --wide

.oc-block-authcard-head / -title / -textCentered heading block, title and description
