Overflow and search v0.17.0

With many modules the links no longer scroll sideways: with overflow the links that do not fit move into a More menu at the end of the navigation (a ResizeObserver measures again when the bar gets wider or narrower). When the current page sits in that menu, the More button is marked current too. moreLabel sets its text. The search slot puts a field between the navigation and the actions. Blade: :overflow="true" with the script oc-nav-overflow.js (npx omniaui copy-js nav-overflow) and <x-slot:search>; Vue: overflow and #search. Make the window narrower to see links move into More.

Search that folds away on a phone v0.18.0

On a narrow bar (below 40rem, measured on the bar itself) a search field takes the room the title and the actions need. searchCollapse (Blade search-collapse) shrinks it to a magnifier; a tap or Tab opens it over the whole bar and leaving the field folds it again. No script: the field is the button. Click the magnifier below.

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: toggle, module nav, actions (theme switch, workspace select, user dropdown).

Class / attributeDescription
.oc-block-appbarBar (flex row)
.oc-block-appbar-navNavigation area; contains an .oc-navmenu
.oc-block-appbar-actionsRight-aligned actions (theme switch, switchers, user menu)
.oc-block-appbar-titleOptional page title
.oc-block-appbar-searchSearch field between the navigation and the actions (0.17.0); React search, Vue #search, Blade <x-slot:search>.
[data-oc-nav-overflow] on .oc-block-appbar-navLinks that do not fit move into a More menu (0.17.0): React and Vue overflow (+ moreLabel / more-label), Blade :overflow="true" with oc-nav-overflow.js. Hidden links keep data-oc-hidden so they can be measured again; event oc-nav-overflow ({ visible, hidden }).
.oc-block-appbar-moreThe More button (li[data-oc-nav-more] with an .oc-dropdown-menu[popover]); aria-current="page" when the current page is in the menu. Styles in packages/blocks/src/parts/app-appbar-overflow.css.
data-moduleModule color of the bar (0.17.0): React and Vue module, Blade module.
