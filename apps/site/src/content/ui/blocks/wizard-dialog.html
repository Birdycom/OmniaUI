Wizard dialog

A dialog.oc-modal with the stepper as navigation rail. Show one .oc-block-wizard-step at a time (the wrapper sets hidden on the others). All blocks.

Demo

Click Open setup wizard: a dialog with numbered steps opens; Escape or the close button closes it. Snippet: packages/blocks/blocks/wizard-dialog.html.
