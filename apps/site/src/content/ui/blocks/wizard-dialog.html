Wizard dialog

A dialog.oc-modal with the stepper as navigation rail. Show one .oc-block-wizard-step at a time (the wrapper sets hidden on the others). All blocks.

Demo

Click Open setup wizard: a dialog with numbered steps opens; Escape or the close button closes it. Snippet: packages/blocks/blocks/wizard-dialog.html.

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: stepper rail, step content (one per step), footer (back, next/finish).

.oc-block-wizard-railContains an ol.oc-stepper
.oc-block-wizard-mainRight column
.oc-block-wizard-stepOne step's content (hidden when inactive)
.oc-modal-footerBack / Next buttons
