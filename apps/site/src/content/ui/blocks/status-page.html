500 - server error

--500 switches to the destructive tone. Show a request id in the detail box so support can find the log line. --403 uses the warning tone ("You do not have access"); --maintenance uses a muted tone for planned downtime. --full makes the block fill the whole viewport on a real error page.

Reference

Styles live in packages/pro/src/parts/app-status-page.css (OmniaUI Pro). Colors are theme tokens, so light and dark mode work without extra classes. Slots: visual, logo, code, title, text, detail, actions, help.

Class / attributeDescription
.oc-block-statuspageGrid root (two columns from 62rem). Modifiers: --403, --500, --maintenance, --full. Height: --oc-block-statuspage-height
.oc-block-statuspage-visual / -number / -quotePanel with rings, the big code and a short quote (hidden on small screens)
.oc-block-statuspage-content / -card / -logoRight column, width limiter, logo link
.oc-block-statuspage-code / -title / -textCode badge, heading and explanation
.oc-block-statuspage-detailMonospace box for the path or request id (optional)
.oc-block-statuspage-actions / -helpButtons and a help line (optional)

Browser support

The gradient number uses background-clip: text; the full-height variant uses dvh.
