Contact grid

Contact information as a grid of cards: e-mail, phone, office address and opening hours, each with a soft product mark. Install with npx omniaui add contact-grid. All blocks.

Demo

blocks/contact-grid.html

The address card is an <address>. Links (mail, phone) are real mailto: and tel: links.
