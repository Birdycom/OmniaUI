Relations list

A customers, companies and suppliers screen, ready to drop in: breadcrumb and title with a New button, type tabs with colored counts, the list toolbar (list actions, search, trash filter, table or cards), filter selects, and a data table with avatar names, type badges, counts and row actions that change in the trash. Built on the free Data table component. All blocks.

What is in it

Styles: packages/pro/src/parts/app-relations-list.css (OmniaUI Pro) for the page head; the table is the free .oc-data-table with data-table.js.

PartDescription
.oc-block-relationsThe block: page head above the data table, full width.
.oc-block-relations-headBreadcrumb (chevrons and icons) and title on the left, page actions on the right.
Type tabsAll / Customers / Companies / Suppliers with counts in the color of their type; they filter the Type column.
RowsAvatar with initials, name and VAT number, a colored type badge, address and e-mail cut with an ellipsis, a projects count (muted at 0), soft edit and open buttons, restore and delete permanently in the trash.
React / Vue / Blade<BlockRelationsList title breadcrumb actions table={…DataTable props} />, <OcBlockRelationsList> (slot head-actions; other slots go to the table) and <x-oc::block.relations-list />.
