Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon, title, intro, meta, actions.

Class / attributeDescription
.oc-block-moduleheadWrapper
.oc-block-modulehead-bandTinted band with icon and text
.oc-block-modulehead-iconIcon tile
.oc-block-modulehead-title / -introTitle and intro
.oc-block-modulehead-metaRow for badges under the title (optional)
.oc-block-modulehead-actionsRow for buttons below the band (optional)
