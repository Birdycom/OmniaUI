Module colour, eyebrow and fixed height v0.17.0

module (data-module) turns the band into a flat tint of the module colour and colours the icon tile and the eyebrow. eyebrow is a small line above the title (the module or section). fixedHeight (.oc-block-modulehead--fixed, Blade fixed-height) keeps one band height (--oc-modulehead-height, 7.5rem) with or without an intro, so the page below does not jump when you switch pages; the intro is cut to two lines. Both bands here are the same height.

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon, title, intro, meta, actions.

Class / attributeDescription
.oc-block-moduleheadWrapper
.oc-block-modulehead-bandTinted band with icon and text
.oc-block-modulehead-iconIcon tile
.oc-block-modulehead-title / -introTitle and intro
.oc-block-modulehead-metaRow for badges under the title (optional)
.oc-block-modulehead-actionsRow for buttons below the band (optional)
.oc-block-modulehead-eyebrowSmall line above the title (optional; eyebrow)
.oc-block-modulehead--fixedOne band height, --oc-modulehead-height (default 7.5rem); fixedHeight, Blade fixed-height
data-module="<name>"Module colour for the band, icon tile and eyebrow; module prop (see Module colour)
