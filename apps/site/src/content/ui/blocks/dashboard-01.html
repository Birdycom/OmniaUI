Reference

Styles live in packages/pro/src/pro.css (OmniaUI Pro). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).

Class / attributeDescription
.oc-block-shellApp shell grid (see App shell). Height via --oc-block-shell-height
.oc-block-dashVertical stack of the dashboard sections
.oc-block-kpis / .oc-block-kpiKPI cards (see Dashboard stats)
.oc-block-chartChart card (head, title, description, SVG or CSS chart, legend)
.oc-block-chart-svgStretched SVG: use .oc-block-chart-line, -area, -grid with series modifiers -s1 to -s3
.oc-chart-legend / .oc-chart-swatchLegend from the components package (series colors via --oc-chart-1 to --oc-chart-5)
.oc-card.oc-block-datatableData table card (see Data table)
