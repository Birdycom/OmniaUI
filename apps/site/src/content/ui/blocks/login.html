Login

Five sign-in layouts built from the card, field, input, reveal and button components: simple card, split with image, muted page with social buttons, reversed split and a minimal magic-link form. All blocks.

Demo

Plain HTML and CSS. Each preview shows the markup that builds it, also available as a snippet in packages/blocks/blocks/ (the variants marked Pro are part of OmniaUI Pro): login-01, login-02, login-03, login-04, login-05.

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).
