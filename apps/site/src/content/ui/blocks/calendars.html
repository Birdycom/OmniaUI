Reference

Styles live in packages/pro/src/pro.css (OmniaUI Pro). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).

Class / attributeDescription
.oc-block-calCard around the calendar; parts -title, -foot, -months, -layout, -side, -slots, -presets, -form
.oc-calendarCalendar component
.oc-block-cal-monthsFlex row of calendars (wraps on narrow widths)
.oc-calendar-day--range-start / -middle / -endRange states from the Calendar component
.oc-block-cal-footSummary line under the calendars
.oc-block-cal-layoutCalendar and side panel in a wrapping row
.oc-block-cal-sideSide panel with a left rule
.oc-block-cal-slotsTwo-column grid of time buttons (scrolls)
.oc-block-cal-presetsWrapping row of preset buttons
.oc-block-cal-formNarrow form column
.oc-date-picker-trigger / .oc-popover--calendarDate picker components
