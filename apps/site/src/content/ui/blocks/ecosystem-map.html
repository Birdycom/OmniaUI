Ecosystem map

Show how your products belong together: your logo on top, your apps below it per level, and dotted curves from each app to what it builds on, with dots flowing down. Point at an app (or tab to it) and its way to the top and the apps built on it light up, with a caption that says it in words. All blocks.

One family of apps

Every app comes from the same team, and many build on each other.

How it works

  • Each app says what it builds on: data-oc-parents="desk shop" (the ids of other apps, or of the root). The root has no parents.
  • The script @birdycom/omniaui-pro/ecosystem-map.js draws one curve per parent into the empty <svg>, from the bottom of the parent to the top of the app, and redraws when the map changes size.
  • The dots flowing down are CSS (stroke-dashoffset); they stop with prefers-reduced-motion.
  • Pointing at or focusing an app lights up its way to the top and the apps built on it; the caption (aria-live) says "builds on …; basis for …". Set your own words with data-label-parents, -children, -alone and -root on the map.
  • Without the script the apps still show, in their rows, as links.

Reference

Styles live in packages/pro/src/parts/site-ecosystem-map.css (OmniaUI Pro), the lines in packages/pro/src/ecosystem-map.js. The app icons are the free .oc-icon-tile.

Class / attributeDescription
.oc-block-ecosystem-map[data-oc-ecosystem]The card; the script binds every one on the page (initEcosystemMaps())
-canvas / -linesThe frame of reference and the empty <svg> the lines go into
-rootYour logo on top (a link; an <img> or <svg> logo inside works)
-row / -row--firstA level of apps; the first one zigzags (set --n to the number of apps)
-node + .oc-icon-tile + -nameAn app: data-oc-node, data-oc-name, data-oc-parents
-captionThe text under the map; its own content is the default
--oc-eco-line / --oc-eco-line-activeLine colors

Use it

// Bundler (Vite, webpack): bind every map on the page import { initEcosystemMaps } from "@birdycom/omniaui-pro/ecosystem-map.js"; initEcosystemMaps(); // Plain HTML or Blade: copy node_modules/@birdycom/omniaui-pro/dist/ecosystem-map.js to public/js/oc-ecosystem-map.js // <script type="module" src="/js/oc-ecosystem-map.js"></script> (starts on its own) // React / Vue: <BlockEcosystemMap apps={…} /> and <OcBlockEcosystemMap :apps="…" /> place the apps in rows themselves
