Masonry gallery

A project gallery: photos of different heights packed without gaps, a caption on hover or focus, category chips that filter without JavaScript, and every photo opens the lightbox. The layout is CSS columns, and display: grid-lanes where the browser supports real masonry. Comes from the projects page of the Verdavita site, which used a layout script and a lightbox library. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.
