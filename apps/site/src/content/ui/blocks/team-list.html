Team list

A bordered list of members. Each row is a user info component, a role badge and a dropdown for actions. All blocks.

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-block-teamList container
.oc-block-team-rowOne member
.oc-userAvatar + name + e-mail
.oc-block-team-metaRight side (badges, actions)
