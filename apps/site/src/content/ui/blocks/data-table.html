Data table

The list page pattern: a card that holds a toolbar (search, status pills), a sortable table with selection and row actions, and a footer with the entry count, page size and pages. With data-table.js it works in the browser (try search, the pills, sorting, selecting and deleting); server side (Livewire) the same look renders links instead. Type tabs, filter selects, rich name cells and cards: the Data table component. All blocks.

Server-driven: trash pills, columns and loading v0.17.0

The Livewire table (Omniacss\Livewire\DataTable) renders this block from the server: search, sort and pages run in the query. It now also has the trash pills ($trashed, automatic for a model with SoftDeletes, or your own trashedOptions() and applyTrashed()), a column chooser (columnChooser(), the hidden keys in $hidden) and skeleton rows while a request runs. The preview shows the markup it renders; the button switches the loading state. React and Vue: the server-driven Data table.
