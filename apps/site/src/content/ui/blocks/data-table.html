Data table

The list page pattern: a card that holds a toolbar (search, filter pills, column chooser), a sortable table with selection and row actions, and a footer with the entry count, page size and pagination. Sorting and filtering are links or form submits (server side). The working Korrekt and OmniaDesk list (search, sort, pages, resize, drag, trash and bulk actions in the browser) is the Data table component. All blocks.

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: title, description, header actions, toolbar, table, footer.

Class / attributeDescription
.oc-card.oc-block-datatableCard root
.oc-block-datatable-head / -title / -descriptionCard header area
.oc-block-datatable-bodyPadded body
.oc-table-toolbarSearch + filters row (.oc-table-toolbar-spacer pushes items right)
.oc-filter-pills / .oc-filter-pillSegmented link filters (aria-current="true")
.oc-block-datatable-bulkSelection bar (appears when rows are selected)
.oc-table-wrap > .oc-tableTable with .oc-table-sort headers, .oc-table-actions cells (see Table)
.oc-table-footerEntries text, page-size select and .oc-pagination
