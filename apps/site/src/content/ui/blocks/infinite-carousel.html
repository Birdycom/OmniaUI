Infinite carousel

A carousel that never ends: after the last slide the first one slides in from the right, and before the first comes the last, without rewinding through all the slides. Buttons, swipe, the mouse wheel and the arrow keys all loop. It builds on the free carousel (scroll snapping, dots); the free .oc-carousel--loop jumps back to the first slide instead. All blocks.

How the loop works

  • The script @birdycom/omniaui-pro/infinite-carousel.js copies all slides once before and once after the real ones. The copies are aria-hidden and inert, without ids, and get no dot.
  • Next on the last slide scrolls on to the copy of the first slide (so it slides in from the right). When scrolling stops (scrollend), the carousel jumps without animation to the real first slide: you see no difference.
  • Swiping, the mouse wheel and the arrow keys end on a copy the same way, so they loop too.
  • Without the script the carousel still works: the CSS arrows remain and stop at the first and last slide.

Reference

Styles live in packages/pro/src/parts/site-infinite-carousel.css (OmniaUI Pro), the loop in packages/pro/src/infinite-carousel.js. Colors are Omnia theme tokens only.

Use it

// Bundler (Vite, webpack): bind every .oc-block-carousel on the page import { initInfiniteCarousels } from "@birdycom/omniaui-pro/infinite-carousel.js"; initInfiniteCarousels(); // Plain HTML or Blade: copy node_modules/@birdycom/omniaui-pro/dist/infinite-carousel.js to public/js/oc-infinite-carousel.js // <script type="module" src="/js/oc-infinite-carousel.js"></script> (starts on its own) // React / Vue: <BlockInfiniteCarousel slides={…} perView={2} /> and <OcBlockInfiniteCarousel :slides="…" :per-view="2" /> bind it themselves
