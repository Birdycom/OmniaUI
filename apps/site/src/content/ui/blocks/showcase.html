Showcase (portfolio)

Portfolio cards with a browser frame around the screenshot - for case studies and client work. Install with npx omniaui add showcase. All blocks.

Demo

blocks/showcase.html v0.4.0

Project cards in a browser frame with a type label, name, short text and a link; two cards per row from 20rem each.
