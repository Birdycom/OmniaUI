Profile header

The top of a channel or profile page: a banner, an avatar that overlaps the banner edge, name, meta line, bio, actions and a tab bar of links. Install with npx omniaui add profile-header. All blocks.

Demo

blocks/profile-header.html

The banner uses the accent gradient; set style="--oc-profile-banner: url(…)" on the banner for an image. The active tab has aria-current="page".
