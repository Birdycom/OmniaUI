Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).

Class / attributeDescription
.oc-block-authpagePage wrapper that centers one card. Modifier: --plain (page background instead of muted)
.oc-block-authcardCard column. Modifiers: --flat (no card chrome), --wide
.oc-block-authcard-logoIcon tile above the title
.oc-block-authcard-head / -title / -textCentered heading block, title and description
.oc-block-authcard-fields / -rowField stack and a justified row (remember me / forgot password)
.oc-block-authcard-submitFull-width submit button
.oc-block-authcard-foot / -legal / -hintSwitch-form line, legal line, small helper text
.oc-block-authcard-centerCentered column (OTP input)
.oc-block-authsocialAuto-fit grid of social buttons
.oc-block-authduoSplit layout root (container query: two columns from 42rem of its own width). Modifier: --reverse
.oc-block-authduo-grid / -panel / -formGrid, brand panel (modifiers --image, --muted) and form column
.oc-block-authduo-logo / -quotePanel logo and quote
.oc-block-authminMinimal centered column without a card
.oc-separator-textDivider with centered text (separator component)
