Sidebars

Sixteen sidebar layouts built on the .oc-sidebar component: grouped, collapsible groups, submenus, floating, collapsible submenus, user dropdown, collapse to icons (CSS only), inset, double sidebar, team switcher, file tree, calendar, in a dialog, right, left plus right and sticky header. Each preview sits in a fixed-height frame; the grey placeholder blocks mark where page content goes. All blocks.

Demo

Plain HTML and CSS. Each preview shows the markup that builds it, also available as a snippet in packages/blocks/blocks/ (the variants marked Pro are part of OmniaUI Pro): sidebar-01, sidebar-02, sidebar-03, sidebar-04, sidebar-05, sidebar-06, sidebar-07, sidebar-08, sidebar-09, sidebar-10, sidebar-11, sidebar-12, sidebar-13, sidebar-14, sidebar-15, sidebar-16.

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).

Class / attributeDescription
.oc-block-sbFrame: grid of sidebar + main. Height via --oc-block-sb-height. Modifiers: --right, --both, --double, --floating, --inset
.oc-block-sb-main / -bar / -bodyMain column, top bar (modifier --sticky) and placeholder body (modifier --scroll)
.oc-block-sb-phContent placeholder block (replace with real content)
.oc-block-sb-toggleHidden checkbox: its label collapses the sidebar to icons (CSS only, :has())
.oc-block-sb-groupdetails element that makes a sidebar group label collapsible
.oc-block-sb-railNarrow icon rail for the double sidebar
.oc-block-sb-tile / -subSquare brand tile and small secondary line inside a menu button
.oc-sidebarThe sidebar component (modifiers --collapsed, --right, --floating); see Sidebar
