Auth split

Two-column authentication layout; the brand panel is hidden below 62rem. Reuses the form-field, input, reveal and button components. All blocks.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/blocks/blocks/auth-split.html. The demo uses the --photo variant; photo: hieroglyphs in the Valley of the Kings by Serge Cools (Birdycom).

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: logo, quote, title, subtitle, fields, submit, footer link.

Class / attributeDescription
.oc-block-authsplitGrid root (two columns from 62rem)
.oc-block-authsplit-brandLeft brand panel (primary gradient)
.oc-block-authsplit-logoLogo link
.oc-block-authsplit-quoteQuote (blockquote with p + footer)
.oc-block-authsplit-formRight column that centers the card
.oc-block-authsplit-cardForm width limiter
.oc-block-authsplit-title / -subtitleHeading and sub line
.oc-block-authsplit-fields / -rowField stack and a justified row (remember me / forgot password)
