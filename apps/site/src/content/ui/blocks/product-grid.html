Product grid

Grid of product cards. Every card can have its own accent color (.oc-accent--green, --orange, --violet, --cyan, ...): icon tile, tagline, border and glow follow it. Install with npx omniaui add product-grid. All blocks.

Demo

blocks/product-grid.html v0.4.0

Product cards with an icon, a type label, a one-line pitch and a link. Cards in one row keep the same height.

Styles live in packages/ui/src/showcase.css. Colors are theme tokens, so everything follows light and dark mode.

ClassDescription
.oc-card-gridResponsive grid (min width via --oc-card-min)
.oc-product-cardCard with hover lift and accent glow
.oc-product-card__top / __name / __tagline / __summary / __moreCard parts
.oc-icon-tileRounded accent tile for an icon or logo
.oc-pillSmall rounded label
.oc-accent--*Accent color presets from the Omnia palette
