Product grid

Grid of product cards. Every card can have its own accent color (.oc-accent--green, --orange, --violet, --cyan, ...): icon tile, tagline, border and glow follow it. Install with npx omniaui add product-grid. All blocks.

Demo

blocks/product-grid.html v0.4.0

Live block with the HTML that builds it. Colors come from the Omnia theme tokens, so it follows light and dark mode.
