Watch layout

A video page: a 16:9 player with title, channel, actions and description, next to an "Up next" list. Two columns from a 60rem wide container, stacked below. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.

Demo

blocks/watch-layout.html

The player is a placeholder: put a video or iframe inside .oc-block-watch-player. Thumbnails use the accent gradient, or an img.

Reference

Styles live in packages/pro/src/parts/site-watch-layout.css (OmniaUI Pro). The channel row is the user component.

Class / attributeDescription
.oc-block-watchSection (size container). Modifier --stacked: list below, as a grid
.oc-block-watch-grid / -main / -sideLayout: player column and the aside
.oc-block-watch-player / -play16:9 area (video, iframe or the play-icon placeholder)
-title / -meta / -actions / -description / -statsVideo info below the player
.oc-block-watch-list / -itemRelated list; each item is a link
-thumb / -duration16:9 thumbnail (.oc-accent--* or img) + time badge
-item-text / -item-title / -item-metaText next to the thumbnail
