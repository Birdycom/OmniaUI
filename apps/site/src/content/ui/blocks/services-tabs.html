Services tabs

A services section with one tab per service: a hero image or video, text, key points, actions and the documents of that service in document viewers. Built on the radio tabset, so it needs no JavaScript (up to six services). Below 40rem the tabs become a scrolling row. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.

Demo

Block blocks/services-tabs.html v0.9.1

One tab per service on the left, the service on the right: picture, text, key points, actions and documents. Click another service to switch (CSS only); below 40rem the tabs become a row above the panel.
