Services tabs

A services section with one tab per service: a hero image or video, text, key points, actions and the documents of that service in document viewers. Built on the radio tabset, so it needs no JavaScript (up to six services). Below 48rem the tabs become a scrolling row. Comes from the services page of the Verdavita site. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.
