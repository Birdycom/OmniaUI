Forgot and reset password

The two screens of a password recovery flow: request a reset link, then choose a new password. All blocks.

Variants

Plain HTML and CSS. Each preview shows the markup that builds it, also available as a snippet in packages/blocks/blocks/: forgot-password, reset-password.

Forgot password

Request a reset link: e-mail field, submit and a back link. Snippet: forgot-password (npx omniaui add forgot-password).

Reset password

Choose a new password: password with reveal, confirmation, a rules hint and submit. Snippet: reset-password (npx omniaui add reset-password).

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).
