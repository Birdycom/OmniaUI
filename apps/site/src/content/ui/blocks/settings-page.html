Reference

Styles live in packages/pro/src/pro.css (OmniaUI Pro). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: nav links, sections (heading + fields/rows).

Class / attributeDescription
.oc-block-settingsTwo-column grid (nav + body) from 48rem
.oc-block-settings-navSection links (.oc-nav-item-link, .is-active)
.oc-block-settings-bodyColumn of sections (max 42rem)
.oc-block-settings-sectionOne titled section (separated by a border)
.oc-block-settings-rowRow with text (-row-title, -row-hint) and a control (switch, button)
.oc-block-settings-actionsButton row
.oc-block-settings-dangerModifier on a row for destructive actions
