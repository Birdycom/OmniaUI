Hero with orbit

A variant of the hero with code window: the product marks slowly orbit around the window on a dashed ring, and stay upright while they turn. With reduced motion they stand still. Install with npx omniaui add hero-orbit. All blocks.

Demo

blocks/hero-orbit.html

Place each mark with style="--oc-orbit-angle: 60deg". The ring radius follows the width of the visual (container units).

Reference

Styles live in packages/blocks/src/parts/site-hero-orbit.css. The copy column uses the showcase classes of the hero with code window.

Class / attributeDescription
.oc-block-orbit-visualSquare stage (max 32rem), a size container
.oc-block-orbit-ringDashed ring that turns and carries the marks (aria-hidden)
.oc-block-orbit-markPosition on the ring: --oc-orbit-angle; the child stays upright
.oc-block-orbit-centerThe visual in the middle (code window or a large product mark)
--oc-orbit-durationOne turn (default 60s)
.oc-code-window / .oc-product-markComponents used inside
