Barcode maker

Make a barcode for a product, a label or a shelf: type the value, pick EAN-13, EAN-8, UPC-A or Code 128 (or let it choose), see the barcode while you type and download a print-ready SVG. A wrong EAN check digit is shown and the download waits until the value is right. It builds on the free Barcode component. All blocks.
