App shell

The frame of an application. Left: the sidebar component. Right: header bar, breadcrumb strip and a scrolling content area. A hidden checkbox plus :has() collapses the sidebar to icons (no JavaScript); below 48rem the sidebar is hidden and meant to move into a sheet. All blocks.

Reference

Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: sidebar, header bar (see App header), breadcrumbs, content (default).

Class / attributeDescription
.oc-block-shellGrid root. Height via --oc-block-shell-height (default 100dvh).
.oc-block-shell-toggleHidden checkbox that collapses the sidebar (label for it in the header bar)
.oc-sidebarSidebar component (first grid child)
.oc-block-shell-mainColumn holding the header bar, breadcrumbs and content
.oc-block-shell-breadcrumbsStrip under the header bar
.oc-block-shell-contentScrolling page content (the only scroll container)
.oc-block-shell-menu-buttonShown below 48rem to open the sidebar sheet
