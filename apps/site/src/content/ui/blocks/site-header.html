Site header

Sticky header that turns into frosted glass once you scroll (scroll-driven animation) with a gradient call-to-action. On small screens the menu opens as a native popover - no JavaScript. Install with npx omniaui add site-header. All blocks.

Demo

Live block with the HTML that builds it. Colors come from the Omnia theme tokens, so it follows light and dark mode.
