Site header

Sticky header that turns into frosted glass once you scroll (scroll-driven animation) with a gradient call-to-action, in several styles: centred with actions, a mega menu with photos, dark, floating and glass. On small screens the menu opens as a native popover - no JavaScript. Install with npx omniaui add site-header. All blocks.

Folds at its own width v0.17.0

By default the menu folds into the menu button when the window is narrower than 860px. With .oc-site-header--container it folds when the header itself is narrower than 860px (53.75rem): for a header in a narrow column, a card, a preview or a side panel. The open menu opens right under that header and is as wide as the header. Below: the same header in a wide box of 56rem (full menu; scroll sideways when this page is narrower) and in a box of 24rem (menu button); open the menu in the narrow one. React <BlockSiteHeader container>, Vue <OcBlockSiteHeader container>, Blade <x-oc::block.site-header class="oc-site-header--container"> (the class merges onto the header).

Mega menu v0.12.6

The Pro component Mega menu (OmniaUI Pro): a menu item opens a panel with link columns (icon, title, one line of text) and a feature card with a photo. button.oc-mega-trigger[popovertarget] + div.oc-mega[popover]: it closes on Escape and on a click outside, without JavaScript, and sits under the header with anchor positioning. Click Solutions or Resources. With --container the menu folds behind the button while the header is narrower than the menu (as in this preview at a normal window width): open the menu button first.
