Media manager

The files of one item (a service, a project) in an admin: documents, videos and photos in tabs with a count, each with an upload zone and a list you can reorder. Photos are a grid with checkboxes; a bulk bar with the number of selected photos appears by itself (a CSS counter, no JavaScript). Delete opens a confirm dialog. Comes from the service editor of the Verdavita admin. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.
