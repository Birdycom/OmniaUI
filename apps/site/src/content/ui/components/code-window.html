Code window

Code window: a code sample in a window frame with traffic-light dots, a file name and a copy button. The syntax colors come from the Code block; the window and the button are the pieces the docs and the homepage use. All components.

Reference

Styles live in packages/ui/src/docs-ui.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-code-windowFrame
.oc-code-window__barTitle bar with the three dots

.oc-code-copyCopy button; state .is-copied

Anatomy

  • .oc-code-window: rounded frame with a border.
  • .oc-code-window__bar: title bar. Three <i> elements draw the dots (palette colors), .oc-code-window__title the file name.
  • .oc-code-copy: the copy button. Inside the bar it sits at the right; on its own it is positioned in the top right corner of a .oc-code-window or any relatively positioned code block.
  • .oc-code-window__body for plain code, or an .oc-code-block for line numbers and syntax colors.

Copy button: the one piece that needs JavaScript

Writing to the clipboard is a script-only capability, so the button carries a data-oc-copy attribute with the selector of the code element and one small event handler (shown in the snippet) does the rest. The button is a real <button type="button">: focusable, Enter/Space activate it. After copying it gets .is-copied (success color) for 1.5 seconds. Without JavaScript the button is simply inert; hide it with .no-js .oc-code-copy { display: none } if that matters to you.

Accessibility and responsive behaviour

  • The dots are decorative; the title is plain text. Long lines scroll horizontally inside the window (overflow-x: auto) so the frame never grows wider than its container.
  • Announce the result for screen readers by putting aria-live="polite" on the button, since its label changes to "Copied".
  • Text is selectable, so the code can also be copied by hand.
