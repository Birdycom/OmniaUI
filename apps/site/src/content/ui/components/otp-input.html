OTP input

A single <input> (paste, autofill and password managers work) drawn as --oc-otp-length cells with monospaced font and a repeating gradient. Keep maxlength equal to the length. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/otp-input.html.

Enter the 6-digit code from your authenticator app.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-otpThe input. Set style="--oc-otp-length: 6" and maxlength to the code length. aria-invalid="true" shows the error state.
