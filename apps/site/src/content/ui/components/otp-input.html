OTP input

A single <input> (paste, autofill and password managers work) drawn as --oc-otp-length cells with monospaced font and a repeating gradient. Keep maxlength equal to the length. All components.

Long codes: fit and group v0.17.0

An 8-character code is wide for a phone. .oc-otp--fit lets the cells shrink with the room the parent gives (never larger than the normal size); the parent becomes the size reference. .oc-otp--group draws a darker divider after every --oc-otp-group cells (default 4), so "K7QM 2XPA" reads in two parts. It is still one input: paste, autofill and the caret work as before. This field is only 20rem wide.

Full code, focus and submit v0.17.0

A full code keeps every digit in its own cell, also while the field has focus: the digits are drawn half a cell gap to the right of the real text, so the caret after the last digit never scrolls the field. The field sets its own height and font size, so an app rule such as input { height: 2rem } does not squash it; --oc-otp-size changes the digit size. onComplete (React) and @complete (Vue) run after the new value has rendered, so a parent that submits from there already holds the full code. In plain HTML listen to input and check the length; the Livewire complete method runs on the next tick, after wire:model has the code.

Click the field: the code stays in place.

Active cell and a code from outside v0.18.0

While the field has focus, the cell the next character goes to gets a soft tint and a line in the ring colour, so it is clear where typing continues (click a cell to move it). React and Vue do this themselves; in plain HTML, Blade and Livewire load oc-form-extras.js, which sets data-otp-active and --oc-otp-active. onComplete (React), @complete (Vue) and the Livewire complete method now also run when the value arrives complete from outside (a code from a link or set by the server), and on load when it is already complete; once per code.

The cell the next digit goes to is marked.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-otpThe input. Set style="--oc-otp-length: 6" and maxlength to the code length. aria-invalid="true" shows the error state.
.oc-otp--fitThe cells shrink with the parent (container query units); at most the normal size. Prop fit.
.oc-otp--group + --oc-otp-groupA darker divider after every n cells (default 4). Prop group.
--oc-otp-sizeDigit size (default 1.5rem); the cells and the height follow. The field sets its own block-size and font-size, so a global input height rule does not squash it (0.17.0).
CompleteReact onComplete and Vue @complete run after the value update has rendered; Livewire complete runs on the next tick, after wire:model (0.17.0). Plain HTML: listen to input and compare the length with maxlength.
