Class / attributeDescription
.oc-badgeDefault: primary color.
--secondary / --outlineMuted fill, or only a border.
--success / --warning / --info / --destructiveStatus colors.
.oc-badge-version, .oc-badge-sourceThe small monospace labels used on these docs pages (version, source file).

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <Badge variant="success">Paid</Badge> <!-- Vue --> <OcBadge variant="success">Paid</OcBadge> <!-- Laravel Blade --> <x-oc::badge variant="success">Paid</x-oc::badge>
