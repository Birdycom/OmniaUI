Badge

Small labels for a status, a count or a category next to text or in a table cell. Seven variants plus a set of status badges with icons, all on theme tokens, so they follow light and dark mode. All components.

Status badges v0.17.1

A ready-made set for the statuses an app shows all day: invoices, documents, reviews and tasks. One class, .oc-badge--status, with the status in data-status: the colour follows the meaning (green done, amber waiting, red needs action, blue on its way, grey over or quiet) and a webicon before the label makes it readable without colour. React, Vue and Blade take status and add the icon and the English label themselves; your own text (a translation) replaces the label, icon replaces the icon (false: none). Statuses: paid, pending, overdue, refunded, draft, sent, scheduled, cancelled, archived, approved, rejected, read-only, active, inactive, in-progress, done, failed (and working, waiting, error, idle of the status dot). Any other name gets the colour you give --oc-badge-status.

Read-only value v0.17.1

variant="readonly" shows a value the user sees but cannot change here: the customer of an invoice, the account a booking goes to, a linked record. Squarer and calmer than a status pill, at the size of body text, with the icon in the muted colour; a long name is cut off with an ellipsis and title shows it in full. In plain HTML wrap the text in a <span> so it can be cut off.
