Badge

Small labels for a status, a count or a category next to text or in a table cell. Seven variants, all on theme tokens, so they follow light and dark mode. All components.

Demo

The four base variants. Each panel says when to use one.

Source and version badges v0.17.0

The small labels at the top of every docs section on omniacss.eu and omniaui.eu: where the code lives and since which version. One color per kind; each has its own --oc-badge-* tokens. Components: BadgeSource / VersionBadge (React), OcBadgeSource / OcVersionBadge (Vue), <x-oc::badge-source> / <x-oc::version-badge> (Blade); kind="mdi" gives the icon-set badge.

.oc-badge-source
What it is: Component, Block or Utility.
Component
.oc-badge-source-file
A file path: a snippet, a block or a CSS file.
snippets/badge.html
.oc-badge-source-scss
A SCSS source file.
_badges.scss
.oc-badge-version
Since which version the item exists.
v0.12.1
.oc-badge-version-mdi
Which version of an icon set is used.
MDI 7.4

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-badgeDefault: primary color.
--secondary / --outlineMuted fill, or only a border.
--success / --warning / --info / --destructiveStatus colors.
.oc-badge-sourceWhat it is or where it comes from (Component, Block, Utility). Teal.
.oc-badge-source-fileA file path (snippet, block, CSS file). Purple.
.oc-badge-source-scssA SCSS source file. Red.
.oc-badge-version / .oc-badge-version-mdiSince which version (or which icon set version). Green.
--oc-badge-source-color, --oc-badge-version-color …One set of tokens per kind (color, background, border, padding, radius, font size) to restyle them.

Framework wrappers

The same markup and classes as React, Vue and Blade components.
