Source and version badges

The small labels at the top of every docs section on omniacss.eu and omniaui.eu: where the code lives and since which version. One color per kind; each has its own --oc-badge-* tokens.

Component snippets/badge.html _badges.scss v0.12.1 MDI 7.4

In a section header they sit next to the title, with the matching oc-section-header__badge-* class for the spacing:

<div class="oc-section-header"> <h2 class="oc-section-header__title">Demo</h2> <span class="oc-section-header__badge-source oc-badge-source">Block</span> <span class="oc-section-header__badge-file oc-badge-source-file">blocks/pricing.html</span> <span class="oc-section-header__badge-version oc-badge-version">v0.12.1</span> </div>

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-badgeDefault: primary color.
--secondary / --outlineMuted fill, or only a border.
--success / --warning / --info / --destructiveStatus colors.
.oc-badge-sourceWhat it is or where it comes from (Component, Block, Utility). Teal.
.oc-badge-source-fileA file path (snippet, block, CSS file). Purple.
.oc-badge-source-scssA SCSS source file. Red.
.oc-badge-version / .oc-badge-version-mdiSince which version (or which icon set version). Green.
--oc-badge-source-color, --oc-badge-version-color …One set of tokens per kind (color, background, border, padding, radius, font size) to restyle them.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <Badge variant="success">Paid</Badge> <!-- Vue --> <OcBadge variant="success">Paid</OcBadge> <!-- Laravel Blade --> <x-oc::badge variant="success">Paid</x-oc::badge>
