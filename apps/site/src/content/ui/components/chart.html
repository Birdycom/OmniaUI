Chart tokens

Five categorical series colors from the Omnia palette, defined once with light-dark() as --oc-chart-1 to --oc-chart-5, plus helpers for a legend, simple CSS bars and a pie/donut. Use the tokens as fill/stroke in SVG charts or in any chart library. All components.

Anatomy

  • Tokens defined on :root next to the other theme tokens: light-dark(var(--color-vividblue-95), var(--color-vividblue-50)) and so on, so every series stays readable in both schemes.
  • Bars a grid with one child per bar; --oc-bar is the height, the series color comes from :nth-child.
  • Pie conic-gradient() with explicit stops; the donut cuts a hole with a radial mask.

In SVG

Tokens work as paint in inline SVG, so charts follow light and dark mode automatically.

Accessibility and keyboard

Accessibility

  • Charts are images to assistive technology: give each one role="img" and an aria-label that states the data, or provide a table.
  • Do not rely on color alone: label series directly or use the legend and a data table.

Keyboard

  • Not interactive.
