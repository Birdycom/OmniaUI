Dropzone

Clicking or tabbing to the invisible input works natively. Toggle .is-dragover from dragenter/dragleave for drag feedback. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/dropzone.html.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-dropzoneLabel wrapper. State: .is-dragover; disabled via the input.
input[type=file]The real input, stretched over the zone
.oc-dropzone-iconOptional icon
.oc-dropzone-hintSmall hint text (accepted types, size)
