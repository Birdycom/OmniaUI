Dropzone

Clicking or tabbing to the invisible input works natively. Toggle .is-dragover from dragenter/dragleave for drag feedback. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/dropzone.html.

import { useState } from "react"; import { Dropzone, Webicon } from "@birdycom/omniaui-react"; export function Example() { const [files, setFiles] = useState<File[]>([]); return ( <Dropzone accept=".pdf,.xml" multiple icon={<Webicon name="mdi:tray-arrow-up" />} hint="PDF or UBL XML, up to 10 MB" onFiles={setFiles}> <strong>Drop invoices here</strong> or click to choose{files.length > 0 && ` (${files.length} chosen)`} </Dropzone> ); } <script setup lang="ts"> import { ref } from 'vue' import { OcDropzone, OcWebicon } from '@birdycom/omniaui-vue' const files = ref<File[]>([]) </script> <template> <OcDropzone v-model="files" accept=".pdf,.xml" multiple hint="PDF or UBL XML, up to 10 MB"> <template #icon><OcWebicon name="mdi:tray-arrow-up" /></template> <strong>Drop invoices here</strong> or click to choose </OcDropzone> </template> <form method="post" action="/invoices" enctype="multipart/form-data"> @csrf <x-oc::dropzone name="invoices[]" accept=".pdf,.xml" multiple title="Drop invoices here" hint="PDF or UBL XML, up to 10 MB">or click to choose</x-oc::dropzone> </form> <?php namespace App\Livewire; use Livewire\Attributes\Validate; use Livewire\Component; use Livewire\WithFileUploads; class InvoiceUpload extends Component { use WithFileUploads; #[Validate(['invoices.*' => 'file|mimes:pdf,xml|max:10240'])] public array $invoices = []; public function updatedInvoices(): void { $this->validate(); foreach ($this->invoices as $invoice) { $invoice->store('invoices'); } } public function render() { return view('livewire.invoice-upload'); } } {{-- resources/views/livewire/invoice-upload.blade.php --}} <div> <x-oc::dropzone wire:model="invoices" accept=".pdf,.xml" multiple title="Drop invoices here" hint="PDF or UBL XML, up to 10 MB">or click to choose</x-oc::dropzone> <div wire:loading wire:target="invoices">Uploading…</div> </div>

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-dropzoneLabel wrapper. State: .is-dragover; disabled via the input.
input[type=file]The real input, stretched over the zone
.oc-dropzone-iconOptional icon
.oc-dropzone-hintSmall hint text (accepted types, size)
