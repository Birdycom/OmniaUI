Reference

Styles live in packages/ui/src/docs-ui.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-tocRoot nav, sticky, scrolls when too tall
.oc-toc-titleSmall heading above the list
.oc-toc-listThe ul; enables native scroll-spy
.oc-toc-linkLink to a heading. Current: :target-current, aria-current or .is-active
.oc-toc-item--subIndented item for a sub heading

Anatomy

  • Root nav.oc-toc: a landmark with aria-label="On this page". It is position: sticky so it stays in view when it lives in a column next to long content, and scrolls itself when the list is taller than the column.
  • Title .oc-toc-title: small uppercase label. Optional.
  • List ul.oc-toc-list: one li per heading. Add .oc-toc-item--sub to the li of an h3 to indent it.
  • Link a.oc-toc-link: points to the heading id (#install). The docs build creates the ids and the list from the h2/h3 elements of the page.

Active heading (scroll-spy without JavaScript)

The list sets scroll-target-group: auto, so browsers that support it mark the link of the heading currently in view with :target-current and the component highlights it. In other browsers nothing is highlighted, the links still work. If you prefer to control it yourself, set aria-current="true" (or .is-active) on the link, as the demo above does for "Install".

Accessibility, keyboard and responsive behaviour

  • It is a nav with its own label, so it is not confused with the main navigation.
  • Tab moves through the links and Enter jumps to the heading; use scroll-padding-top on the scroll container so the heading is not hidden under a fixed header, and scroll-behavior: smooth (wrapped in prefers-reduced-motion: no-preference) for animation.
  • Responsive: a table of contents is secondary navigation. On narrow screens hide it with @media (max-width: 1100px) { .oc-toc { display: none; } } or place it inside a <details> ("On this page") above the article.
