Skeleton

Grey placeholder shapes with a soft shimmer, shown while the real content loads, so the page does not jump. Mark the loading area with aria-busy="true". The shimmer stops for people who prefer reduced motion. All components.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-skeletonA placeholder with a shimmer. Modifiers: --circle (avatar), --title, --text (one line), --rect (image or block).
aria-busy="true"On the loading container; remove it when the content is there.
prefers-reduced-motionThe shimmer is switched off for people who prefer less motion.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <Skeleton variant="circle" /> <!-- Vue --> <OcSkeleton variant="title" /> <!-- Laravel Blade --> <x-oc::skeleton shape="text" />
