List toolbar

The bar above a list: a search field, the result count, a cards / table view toggle and action buttons. The toggle is a radio group; inside .oc-list-toolbar-scope it switches the visible view with :has(), no JavaScript. All components.

Search, count and view toggle

CSS component parts/app-list-toolbar.css

Click the two view icons. Each panel has data-view="cards" or data-view="table"; the checked radio's value decides which one shows. Search and filtering stay your app's job. Snippet: packages/ui/snippets/list-toolbar.html.

Bordered and sticky

--bordered frames the bar (nice above a card grid). --sticky keeps it at the top of its scroll container. On screens below 36rem the search field takes the whole first row.

Browser support

Without :has() both panels show; the toolbar itself works everywhere.
