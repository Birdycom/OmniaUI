Cookie consent

A cookie banner with categories (necessary, statistics, marketing) on popover="manual": it sits in the top layer, never blocks the page and slides in from the corner. "Customize" is a native <details> with the switch component. A small script remembers the choice and tells your page with an oc-consent event. Comes from the cookie banner of the Verdavita site. Install with npx omniaui add cookie-consent. All components.

Demo

Component snippets/cookie-consent.html v0.9.1

On this page the banner has data-oc-consent-manual, so it only opens with the button. On a real site it opens by itself until the visitor has chosen. Your choice is stored in localStorage under oc-consent.

Load scripts after consent

<script> document.addEventListener("oc-consent", (e) => { if (e.detail.statistics) loadAnalytics(); // your own loader if (e.detail.marketing) enableVideoEmbeds(); }); </script> <a href="#" data-oc-consent-open>Cookie settings</a> <!-- in the footer -->

Add a category by adding a .oc-cookie-consent__category row; the input name becomes the key in the stored choice. Use --bar for a full-width bar at the bottom.
