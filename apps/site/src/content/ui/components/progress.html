Progress

A bar that shows how far a task is: an upload, a quota or the steps of a form. Give it role="progressbar" with the values, so screen readers read the percentage. For a bar at the top of the page while it loads, see top progress. All components.

Demo

snippets/progress.html v0.4.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/progress.html.

Variants

--success, --warning and --danger on the bar, for quotas and health.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-progressThe track. Add role="progressbar", aria-valuenow, aria-valuemin, aria-valuemax and an aria-label.
.oc-progress-barThe filled part; set its width to the percentage. Modifiers: --success, --warning, --danger.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <Progress value={60} /> <!-- Vue --> <OcProgress :value="60" variant="success" label="Upload" /> <!-- Laravel Blade --> <x-oc::progress :value="60" variant="success" label="Upload" />
