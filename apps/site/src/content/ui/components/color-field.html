Color field

The native <input type="color"> plus a text field for the value. Keeping both in sync is the wrapper's job. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/color-field.html.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-color-fieldRow wrapper
input[type=color]Native picker swatch
.oc-inputText field with the value (monospaced)
