Spinner

A loading indicator drawn with a border ring and currentColor, so it matches the text or button it sits in. Respects prefers-reduced-motion. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/spinner.html.

Anatomy

  • Ring a single element: a translucent currentColor border with one solid side, rotated by @keyframes oc-spinner-rotate.
  • Size --oc-spinner-size also scales the border width.

In a button

The ring takes the button's text color. Mark the button aria-busy and disable it while loading.

Accessibility and keyboard

Accessibility

  • Give a standalone spinner role="status" and an aria-label; inside a button mark it aria-hidden="true" and let the button text speak.
  • With prefers-reduced-motion: reduce the rotation slows down instead of stopping, so progress stays visible.

Keyboard

  • Not interactive.
