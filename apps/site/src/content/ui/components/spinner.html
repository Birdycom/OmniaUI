Spinner

A loading indicator drawn with a border ring and currentColor, so it matches the text or button it sits in. Respects prefers-reduced-motion. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/spinner.html.

Four sizes; --primary and --muted change the color. Each panel shows one combination.

.oc-spinner--sm
Small (0.875rem): inside a button or next to a line of text.
.oc-spinner
Default size (1.25rem), in the text color.
.oc-spinner--lg.oc-spinner--primary
Large (2rem) in the primary color, for a panel that is loading.
.oc-spinner--xl.oc-spinner--muted
Extra large (3rem) and quiet, for a whole page or an empty state.

In a button

Mark the button aria-busy="true" and disable it while loading: the button draws the ring itself, in its own text color, and the label stays readable. A leading icon or .oc-spinner in the button is hidden then, so the ring never shows twice.

CSS featureRole
animationRotation, slowed under reduced motion

Anatomy

  • Ring a single element: a translucent currentColor border with one solid side, rotated by @keyframes oc-spinner-rotate.
  • Size --oc-spinner-size also scales the border width.

Accessibility and keyboard

Accessibility

  • Give a standalone spinner role="status" and an aria-label; inside a button mark it aria-hidden="true" and let the button text speak.
  • With prefers-reduced-motion: reduce the rotation slows down instead of stopping, so progress stays visible.

Keyboard

  • Not interactive.
