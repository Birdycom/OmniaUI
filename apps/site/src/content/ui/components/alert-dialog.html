Alert dialog

A <dialog class="oc-modal"> whose content carries a round status icon. The type is a modifier on the content element and tints the icon. All components.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon, title, message (body), footer buttons (secondary + primary).

Class / attributeDescription
dialog.oc-modalNative dialog from the modal component
.oc-modal-content.oc-modal-content--sm.oc-alert-dialogCentered content box
.oc-alert-dialog--success / --error / --warning / --info / --questionType modifier on the content element (sets the icon color)
.oc-alert-dialog-iconRound icon holder with a glyph (!, ✓, ?, i, ×)
.oc-modal-title / -body / -footerTitle, message and the buttons (secondary left, primary right)
