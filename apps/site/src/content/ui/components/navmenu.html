Site variant: .oc-navmenu--site

The menu in the header of this site: outlined pills with the current section marked by a primary colored border. Use it inside a Site header or any toolbar.

Keyboard: Tab through the links, Enter to follow. The list wraps onto more lines on narrow screens; for a collapsing menu use .oc-topbar--collapsible (CSS only, see Site header).

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-navmenuul row of items
.oc-navmenu--siteModifier on .oc-navmenu: outlined pill links (site header style)
.oc-navmenu-linkLink or button. State: aria-current="page" or .is-active
.oc-navmenu-link--caretAdds a chevron (trigger of a dropdown)
.oc-dropdown-menu[popover]Child menu, from the dropdown component
