Prose

Typography for long-form text that comes out of a CMS, a markdown renderer or a rich-text editor, where the HTML has no classes: headings, paragraphs, links, lists, quotes, code, tables, figures and rules. Wrap it in .oc-prose and it reads well in light and dark mode. Sizes --sm and --lg scale all spacing along. Based on the help and maintenance pages of the Korrekt app. Install with npx omniaui add prose. All components.

Planning a kitchen renovation

A new kitchen takes eight to twelve weeks from the first visit to the last cabinet handle. This guide explains every step, so you know what to expect and when we need you.

Before the first visit

Collect a few photos of kitchens you like and measure the room roughly. Exact measurements are not needed yet: our site manager does that during the visit. Read the preparation checklist if you want to be fully ready.

  • The budget range you have in mind, including appliances
  • Which walls, doors and windows can move, and which cannot
    • Load-bearing walls need a structural engineer
    • Moving a window needs a permit in most towns
  • Appliances you want to keep

From design to installation

  1. Site visit and measurements (week 1)
  2. Design and quote, with two revision rounds (weeks 2–3)
  3. Order and production of the cabinets (weeks 4–9)
  4. Installation, worktop and finishing (weeks 10–11)

The planning was clear from day one. We always knew who was coming and when, and the kitchen was ready a week early.

— Ann Dewitte, client in Ghent

How it works

  • Zero specificity: every rule is written as .oc-prose :where(h2), so it weighs as much as one class. A utility or component class on an element inside the text still wins without !important.
  • Vertical rhythm: elements get margin-block-start only when something comes before them (* + *); headings get more space above than below, so they stick to their section.
  • Readable width: max-inline-size: 68ch; add --full when the parent already limits the width.
  • Balanced text: headings use text-wrap: balance and paragraphs text-wrap: pretty (no lonely last words where supported).

Accessibility and keyboard

  • Keep the heading order in the content (one h1, then h2, h3); the styles do not change the semantics.
  • Links are underlined, not only colored, and get a visible focus ring. The link underline animation is off under prefers-reduced-motion: reduce.
  • Give tables a <caption> and images an alt. Long code lines scroll inside the <pre> instead of widening the page.
