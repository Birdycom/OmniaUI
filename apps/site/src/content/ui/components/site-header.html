Site header

Site header with brand, pill navigation, search and actions (for example the theme switch). This is the bar at the top of every OmniaCSS page: .oc-topbar contains the brand, a .oc-navmenu.oc-navmenu--site and an actions slot. All components.

Reference

Styles live in packages/ui/src/docs-ui.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription

.oc-topbar-brandBrand link
.oc-topbar-navWrapper of the navigation (hidden on mobile when collapsible)
.oc-navmenu--sitePill style navigation menu, used inside the bar

.oc-topbar-actionsRight side slot
.oc-topbar-toggle / .oc-topbar-burgerHidden checkbox and its label for the CSS-only mobile menu

Anatomy

  1. Bar header.oc-topbar: flex row with a bottom border and a translucent, blurred background (--ocm-header-bg). Default height --ocm-header-height (60px).
  2. Brand a.oc-topbar-brand: logo or name, usually linking home. A .oc-badge-version inside shows the release.
  3. Navigation nav.oc-topbar-nav > ul.oc-navmenu.oc-navmenu--site: the pill variant of the navigation menu. The current section has aria-current="page" (primary colored border).
  4. Icon link: put an inline SVG with .oc-navmenu-icon in a link and give the link an aria-label (GitHub, in the demo).
  5. Actions .oc-topbar-actions: right-aligned slot for the theme switch, a search field or a sign-in button.

Variants

  • .oc-topbar--fixed: position: fixed at the top of the viewport (the docs use it on pages with a scrolling content area). Add top padding or margin equal to --ocm-header-height to the content below.
  • .oc-topbar--collapsible: below 760px the navigation is hidden and a burger button toggles it. See below.
  • .oc-navmenu--site works on its own too, in any toolbar or footer.

Tokens: --ocm-header-height, --ocm-header-bg, --ocm-header-border. They are defined on :root by the layout module (oc-layout-module.css) and have defaults, so the component also works without it.

Collapse on mobile with CSS only

The burger is a visually hidden checkbox followed by a label. Under 760px .oc-topbar--collapsible hides .oc-topbar-nav, and :has(.oc-topbar-toggle:checked) shows it again as a full-width row below the brand. No JavaScript. Resize your window to see the burger in the demo. Without --collapsible the bar just wraps onto two lines on a narrow screen.

.oc-topbar--collapsible .oc-topbar-burger { display: inline-flex; } /* < 760px */ .oc-topbar--collapsible .oc-topbar-nav { display: none; order: 3; inline-size: 100%; } .oc-topbar--collapsible:has(.oc-topbar-toggle:checked) .oc-topbar-nav { display: block; }

Accessibility and keyboard

  • Use <header> for the bar and <nav aria-label="Main"> for the menu, so both landmarks are found by assistive technology.
  • aria-current="page" marks the current section; the border color change is not the only cue because it is also announced.
  • The burger checkbox is focusable (Space toggles it) and shows a focus ring on its label; give it an aria-label.
  • Icon-only links need an aria-label; decorative SVGs get aria-hidden="true".
