Password requirements

A live checklist under a "new password" field. Each rule turns green with a check mark when it is met. The list has aria-live="polite" and is linked to the field with aria-describedby, so screen readers hear the rules. Without JavaScript it is a static hint; a tiny script or the framework wrapper updates it while typing. All components.

Demo

Type in the field: the optional script below re-checks each rule. The markup is also available as the snippet packages/ui/snippets/password-requirements.html.

  • At least 8 characters
  • One uppercase letter
  • One number
  • One symbol

Inline

--inline puts short rules side by side. Here all states are static (set by the server).

  • 8+ characters
  • A-Z
  • 0-9
  • Symbol

Reference

Styles live in packages/ui/src/parts/forms-password-requirements.css. Colors are theme tokens (--oc-success, --oc-muted-foreground).

Class / attributeDescription
.oc-password-requirementsThe list (aria-live="polite"). Modifier: --inline.
.oc-password-requirementOne rule. Modifier: --met.
data-oc-password-forScript only: id of the password input to watch
data-min / data-patternScript only: minimum length, or a regular expression that must match

Optional script

One listener for every linked list on the page.

<script> document.addEventListener('input', (e) => { const list = e.target.id && document.querySelector(`[data-oc-password-for="${e.target.id}"]`); if (!list) return; for (const rule of list.querySelectorAll('.oc-password-requirement')) { const value = e.target.value; const met = rule.dataset.min ? value.length >= Number(rule.dataset.min) : new RegExp(rule.dataset.pattern).test(value); rule.classList.toggle('oc-password-requirement--met', met); } }); </script>

Framework wrappers

Pass the password; the wrapper checks the default rules (or your own rules: { label, test }).

<!-- React --> <PasswordRequirements password={password} /> <!-- Vue --> <OcPasswordRequirements :password="password" /> <!-- Laravel Blade (static, plus the script) --> <x-oc::password-requirements for="password" />
