Confirm dialog

A variant of the alert dialog. Add .oc-alert-dialog--confirm for a larger icon ring, a close button, an optional typed confirmation and a third "discard" action. It is a native <dialog> with a <form method="dialog">, so no JavaScript is needed. All components.

Reference

Adds to the alert dialog classes. Types: --success, --error, --warning, --info, --question. Slots: icon, title, message, typed field, footer buttons.

Class / attributeDescription
.oc-alert-dialog--confirmOn the content box: thin 80px icon ring, wider box, wrapping footer
.oc-alert-dialog-closeX button in the top corner (command="close")
form.oc-alert-dialog-form[method=dialog]Wraps body and footer; a submit closes the dialog with its value
.oc-alert-dialog-typedLabel + input with pattern and required
.oc-alert-dialog-confirmConfirm (submit) button; dimmed while the typed value is invalid
.oc-alert-dialog-discardThird action at the start of the footer

Browser support

The command / commandfor buttons open and close the dialog without script. In older browsers add a one-line click handler that calls showModal().
