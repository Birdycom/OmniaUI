Message

One chat bubble: incoming on the left with the avatar, outgoing on the right in the primary tint. It carries the sender name, the time, a "Read" receipt, a reply quote, attachments, and actions that appear on hover or keyboard focus. Consecutive messages of one sender group by themselves with :has(), and a date divider or system line separates the days. Comes from the question chat of the Korrekt app. Install with npx omniaui add message. All components.

Grouping without JavaScript

  • Mark follow-ups: when a message has the same sender as the one before it (and is sent within a few minutes), render it with oc-message--continued. That is one comparison in your template loop.
  • Name once: --continued hides .oc-message__sender, so the name only shows on the first bubble of a group.
  • Avatar once: .oc-message:has(+ .oc-message--continued) hides the avatar of every message that is followed by one of the same sender, so it ends up next to the last bubble. The space stays reserved, so the bubbles line up.
  • Corners: the small "tail" corner moves along the group in the same way.
  • Read receipt: show .oc-message__status--read on your last message once the other person opened the conversation, and a plain status ("Sent") before that.

Accessibility and keyboard

  • Give the list role="log" and an aria-label when new messages arrive while the page is open; screen readers then announce them politely.
  • Each message is an <article>; an aria-label with the sender and time helps when the visible name is hidden by the grouping.
  • The actions fade in on :hover and :focus-within, so Tab reveals them. Every icon button has an aria-label. On touch screens (hover: none) they are always visible.
  • Times use <time datetime>. Colors meet contrast in light and dark mode, and the "Read" receipt is a word, not only a color.
  • The fade is switched off under prefers-reduced-motion: reduce.
