Accordion

A vertically stacked set of interactive headings that each reveal a section of content. Built with OmniaCSS classes only; toggle by adding or removing .is-open on .oc-accordion-item (or use aria-expanded). No extra JS required for basic open/close; add your own script for single-open (accordion) or multi-open behaviour.

How it works

The accordion uses pure CSS for show/hide. Content is visible when the item has class .is-open or aria-expanded="true". The chevron icon rotates via CSS. Use a small script to toggle .is-open on the clicked item (and optionally close siblings for single-open behaviour).

Structure: .oc-accordion wraps one or more .oc-accordion-item; each item contains a .oc-accordion-trigger (button) and .oc-accordion-content (the panel).

<div class="oc-accordion" id="accordion-single"> <div class="oc-accordion-item is-open"> <button type="button" class="oc-accordion-trigger" onclick="accordionSingle(this)" aria-expanded="true">What are your shipping options?</button> <div class="oc-accordion-content"><p>We offer standard (5–7 days), express (2–3 days), and overnight shipping.</p></div> </div> <div class="oc-accordion-item"> <button type="button" class="oc-accordion-trigger" onclick="accordionSingle(this)" aria-expanded="false">What is your return policy?</button> <div class="oc-accordion-content"><p>You may return unused items within 30 days for a full refund.</p></div> </div> <div class="oc-accordion-item"> <button type="button" class="oc-accordion-trigger" onclick="accordionSingle(this)" aria-expanded="false">How can I contact customer support?</button> <div class="oc-accordion-content"><p>Email support@example.com or use the chat widget.</p></div> </div> </div> <script> function accordionSingle(trigger) { var item = trigger.closest('.oc-accordion-item'); var list = trigger.closest('.oc-accordion'); if (!item || !list) return; list.querySelectorAll('.oc-accordion-item').forEach(function (el) { if (el !== item) el.classList.remove('is-open'); }); item.classList.toggle('is-open'); trigger.setAttribute('aria-expanded', item.classList.contains('is-open')); } </script>

CSS-first — no JavaScript

Each item is a <details> with a <summary> trigger. Items sharing the same name open one at a time; ::details-content + interpolate-size animate the height.

Is it accessible?
Yes. It uses the native details/summary elements.
Does it need JavaScript?
No. Items with the same name open one at a time.

Reference

Class / attribute Description
.oc-accordion Wrapper; border, radius, overflow hidden
.oc-accordion--flush Modifier: no outer border/radius, edge-to-edge
.oc-accordion-item One heading + panel block; add .is-open to show content
.oc-accordion-trigger Button that toggles the panel; full width, flex. Chevron: CSS ::after by default, or add <span class="iconify oc-accordion-chevron size-4" data-icon="mdi:chevron-down" aria-hidden="true"></span> (Iconify + size-4)
.oc-accordion-trigger:disabled Muted text, dimmed chevron, no hover (native disabled)
.oc-accordion-content Panel content; visible when parent item has .is-open or aria-expanded="true"
.is-open On .oc-accordion-item: shows content and rotates chevron
aria-expanded On trigger: set true/false when toggling for accessibility
