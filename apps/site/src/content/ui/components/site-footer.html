Site footer bar

Slim footer bar with a version line and links, as at the bottom of every OmniaCSS page. For a large multi-column footer, use the footer block from Blocks. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/site-footer.html.

OmniaCSS v1 — modern CSS, utilities, components and blocks · Docs · GitHub

Anatomy and variants

  • footer.oc-footerbar: a centered flex row with a top border and a translucent blurred background.
  • .oc-footerbar--fixed: position: fixed to the bottom of the viewport (the docs do this). Reserve room so content is not covered: padding-bottom: var(--ocm-footer-height) on the page, or let your scroll container end above it.
  • Links are plain a elements and take --oc-primary.
  • Tokens: --ocm-footer-height (36px) and --ocm-footer-bg.

Accessibility and responsive behaviour

  • Use a real <footer>; it becomes a contentinfo landmark when it is a direct child of body.
  • Link color uses a theme token with sufficient contrast in both light and dark mode.
  • The text is centered and wraps naturally; on very narrow screens drop the descriptive part and keep the links.

Styles live in packages/ui/src/docs-ui.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.
