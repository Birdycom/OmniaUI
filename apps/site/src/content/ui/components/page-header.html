Page header

The top of an app page: an optional back link, the title, a subtitle, a meta row and the page actions. It is a lighter version of the module header block, as a component. The header is a size container, so it adapts to its own width, not the window. All components.

Full header

CSS component parts/app-page-header.css

From 36rem of header width the actions sit at the end of the title row. --bordered adds the line below. Snippet: packages/ui/snippets/page-header.html.

Small, in a narrow column

The same markup in a 20rem box: the actions wrap under the title because the container is narrow, even on a wide screen. --sm shrinks the title for sub pages. --sticky keeps the header on top while the page scrolls.

Reference

Slots: back, title, subtitle, meta, actions. Use an h1 for the title on a real page.

Class / attributeDescription
.oc-page-headerHeader (size container). Modifiers: --bordered, --sticky, --sm
.oc-page-header-backRow for an .oc-back-link
.oc-page-header-mainText block + actions (side by side from 36rem)
.oc-page-header-text / -title / -subtitle / -metaText column, title (may hold a badge), sub line, meta row
.oc-page-header-actionsButtons

Browser support

Without container queries the actions simply stay under the title.
