Form section

A long form in named parts that open and close. Native <details>: sections with the same name keep one open at a time. A section with an invalid field gets a red edge, also while it is closed, so an error is never hidden. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-form-sectionA <details>; same name on siblings = one open at a time.
.oc-form-section__summaryIcon, heading (title + hint), status and a chevron.
.oc-form-section__iconThe webicon of the section in a tinted square.
.oc-form-section__statusFree slot: a badge (Complete, 1 error), a count …
.oc-form-section__bodyThe fields in a responsive grid; .oc-form-section__wide spans the full row.
:user-invalid / [aria-invalid]A field that fails validation after the user touched it colors the section red.

Try it: open Contact, clear the e-mail field and leave it; the section turns red. No script.
