Form section

A long form in named parts that open and close. Native <details>: sections with the same name keep one open at a time. A section with an invalid field gets a red edge, also while it is closed, so an error is never hidden. All components.

Errors and warnings from your own checks v0.17.0

The red edge above comes from the browser (:user-invalid, aria-invalid). When your app checks more (a step without a location, a photo that is too big), set data-issue="error" or "warning" on the section: the edge and the icon take that color, also while the section is closed, so a problem is never hidden. .oc-form-section__count puts the number in the header. React and Vue: invalid and issues; Blade: invalid and :issues. data-issue also works on .oc-card.

module (data-module) gives the icon tile, the focus ring of the fields and a variant="module" badge the module colour. A section with an error or warning keeps its red or orange tile. Inside a data-module wrapper every section follows without the prop.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-form-sectionA <details>; same name on siblings = one open at a time.
.oc-form-section__summaryIcon, heading (title + hint), status and a chevron.
.oc-form-section__iconThe webicon of the section in a tinted square.
.oc-form-section__statusFree slot: a badge (Complete, 1 error), a count …
[data-issue="error|warning"]Your own check found something: red or orange edge and icon, also while closed (also on .oc-card). Prop invalid.
.oc-form-section__countThe number of problems in the header (role="img" + aria-label). Prop issues.
.oc-form-section__bodyThe fields in a responsive grid; .oc-form-section__wide spans the full row.
.oc-form-section--denseSmaller header, icon and body for a panel or side sheet. Prop dense (React, Vue, Blade).
open / defaultOpenOpen on the first render; the visitor opens and closes it after that. React and Vue: defaultOpen; Blade and Vue: open.
:user-invalid / [aria-invalid]A field that fails validation after the user touched it colors the section red.

Try it: open Contact, clear the e-mail field and leave it; the section turns red. No script.
