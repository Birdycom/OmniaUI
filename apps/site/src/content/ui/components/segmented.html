Segmented control

Radio inputs inside labels; :has(input:checked) highlights the active segment. Arrow keys, form submission and name grouping work natively. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/segmented.html.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: one .oc-segmented-item per option (radio input + label text).

Class / attributeDescription
.oc-segmentedGroup wrapper (role="radiogroup"). Modifiers: --block (full width), --sm.
.oc-segmented-itemLabel that wraps one radio input and its text
