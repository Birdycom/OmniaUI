Segmented control

Radio inputs inside labels; :has(input:checked) highlights the active segment. Arrow keys, form submission and name grouping work natively. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/segmented.html.

<Segmented aria-label="Period" options={[{ value: "month", label: "Month" }, { value: "quarter", label: "Quarter" }, { value: "year", label: "Year" }]} value={period} onChange={setPeriod} /> <OcSegmented v-model="period" label="Period" :options="[{ value: 'month', label: 'Month' }, { value: 'quarter', label: 'Quarter' }, { value: 'year', label: 'Year' }]" /> <x-oc::segmented name="period" label="Period" value="month" :options="['month' => 'Month', 'quarter' => 'Quarter', 'year' => 'Year']" /> <?php namespace App\Livewire; use Livewire\Component; class Revenue extends Component { public string $period = 'month'; public function render() { return view('livewire.revenue'); } } {{-- resources/views/livewire/revenue.blade.php --}} <div> <x-oc::wire.segmented model="period" live label="Period" :options="['month' => 'Month', 'quarter' => 'Quarter', 'year' => 'Year']" /> <p>Revenue per {{ $period }}.</p> </div>

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: one .oc-segmented-item per option (radio input + label text).

Class / attributeDescription
.oc-segmentedGroup wrapper (role="radiogroup"). Modifiers: --block (full width), --sm.
.oc-segmented-itemLabel that wraps one radio input and its text
