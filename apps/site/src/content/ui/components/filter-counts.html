Filter counts

Choose a view of a list (for example Active, Deleted or All) from tiles that also show how many items each view holds. The tiles are radio inputs inside labels; the checked tile gets its accent color. No JavaScript: submit the form or listen to change. All components.

Demo

snippets/filter-counts.html v0.6.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/filter-counts.html.

Compact

--compact turns the tiles into small pills ("Active 128") for a toolbar above a table. The hint is hidden.

Reference

Styles live in packages/ui/src/parts/forms-filter-counts.css. The tone is one variable, --oc-filter-accent, set by the tone modifiers.

Class / attributeDescription
.oc-filter-countsGroup (<fieldset> or role="radiogroup"). Modifier: --compact.
.oc-filter-counts-itemTile around one radio. Tones: --success, --destructive, --muted (default primary).
.oc-filter-counts-valueThe count
.oc-filter-counts-labelName of the view
.oc-filter-counts-hintShort description (hidden in --compact)

Framework wrappers

options is a list of { value, label, count, hint?, tone? }.

<!-- React --> <FilterCounts aria-label="View" value={view} onChange={setView} options={[{ value: "active", label: "Active", count: 128, tone: "success" }]} /> <!-- Vue --> <OcFilterCounts v-model="view" label="View" :options="views" compact /> <!-- Laravel Blade --> <x-oc::filter-counts name="view" value="active" :options="[['value' => 'active', 'label' => 'Active', 'count' => 128]]" />
