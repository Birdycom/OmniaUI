Alpha tabs

An "All + A to Z" letter bar to filter a long list, such as a dictionary or contacts. Each letter is a link (?letter=B) or a button. On small screens the bar scrolls sideways with scroll snapping. All components.

Demo

Plain HTML and CSS; each example shows its markup in the HTML tab.

Letter bar

The current letter has aria-current="true". Letters without entries get aria-disabled="true" (and no href). Snippet: packages/ui/snippets/alpha-tabs.html. In your app every letter is a link such as ?letter=b; in this preview they go nowhere. The row scrolls sideways when it does not fit: scroll it to reach Z, or hover and Tab through the letters.

Wrap, small and plain

--wrap lets the letters wrap onto more rows. --sm makes them smaller and --plain removes the frame. Here the items are buttons, for in-page filtering with your own script. Click a letter: it is filled in and the list shows only the products that start with it. This one example needs the few lines of script in the HTML tab, because filtering a list is up to your own code.

Reference

Slots: one item per letter. Render only the letters you need, or all of them with the empty ones disabled.

Class / attributeDescription
nav.oc-alpha-tabsLetter bar. Modifiers: --wrap, --sm, --plain
.oc-alpha-tabs-itemOne letter (link or button)
.oc-alpha-tabs-item--allWider "All" item with a divider
aria-current="true" / .is-activeCurrent letter
aria-disabled="true" / disabledNo entries for this letter

Browser support

Scroll snapping and the thin scrollbar are enhancements; the bar scrolls in every browser.
