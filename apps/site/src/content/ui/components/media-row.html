Media row

A compact horizontal media item: a small Media thumb, a two-line title and meta text, with an optional menu. Use it for "up next" sidebars, search results and playlists. The numbered playlist variant counts with CSS and marks the current item. All components.

Numbered playlist

.oc-media-row-list--numbered on an <ol> adds a number column from a CSS counter. aria-current="true" tints the row and swaps the number for a play mark.

Accessibility

  • Use a real list (<ul> / <ol>) with an aria-label; screen readers announce "list, 3 items".
  • aria-current="true" tells assistive tech which item plays now; the play mark has the alternative text "Now playing".
  • One link per row (the title). The menu button needs an aria-label.
