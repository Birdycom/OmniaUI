Command

Styling for a search field plus grouped, selectable results. Put it in a dialog.oc-modal for a palette. Filtering and aria-selected are driven by the wrapper component (set hidden on non-matching items). All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/command.html.

The look of a command palette: a search field and grouped results, with the selected row, a shortcut and a disabled item. Typing does not filter here; the wrapper component hides the items that do not match.
