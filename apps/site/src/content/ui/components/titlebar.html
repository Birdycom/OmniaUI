Title bar

The top bar of a frameless desktop window (Electron, Tauri) or a widget: a title, an optional subtitle and compact icon buttons. You move the window by dragging the bar; buttons, links and fields in it stay clickable. Once the body scrolls, the bar gets a hairline and a light surface, with a scroll-driven animation and no JavaScript. Pairs with glass. All components.

Electron and Tauri

The bar sets app-region: drag; the window has to be frameless for it to matter.

// Electron (main process) new BrowserWindow({ frame: false, transparent: true, backgroundMaterial: "acrylic" /* Windows 11 */ }); // Tauri (tauri.conf.json, app.windows[0]) { "decorations": false, "transparent": true }

The close and minimize buttons call your own code (window.close(), an IPC message, getCurrentWindow().minimize()). Tauri also reads data-tauri-drag-region: add it to .oc-titlebar if your Tauri version ignores app-region.

Reference

Styles live in packages/ui/src/parts/app-titlebar.css. Inside a .oc-glass sheet the bar uses the glass hairline and surfaces.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <TitlebarWindow> <Titlebar title="TokenTally" subtitle="Usage"> <TitlebarButton label="Close" close onClick={() => window.close()}>✕</TitlebarButton> </Titlebar> <TitlebarBody>…</TitlebarBody> </TitlebarWindow> <!-- Vue --> <OcTitlebar title="TokenTally" subtitle="Usage"><OcTitlebarButton label="Close" close @click="close">✕</OcTitlebarButton></OcTitlebar> <!-- Blade --> <x-oc::titlebar title="TokenTally" subtitle="Usage"><x-oc::titlebar-button label="Close" close>✕</x-oc::titlebar-button></x-oc::titlebar>
