Fact list

Key / value facts for a product or project page: platform, stack, license, status. It is the marketing variant of the definition list: a semantic <dl>, label left and value right. All components.

Demo

Each row is a div with a dt and a dd. Snippet: packages/ui/snippets/fact-list.html.
