Fact list

Key / value facts for a product or project page: platform, stack, license, status. It is the marketing variant of the definition list: a semantic <dl>, label left and value right. All components.

Demo

Each row is a div with a dt and a dd. Snippet: packages/ui/snippets/fact-list.html.

Reference

Base card in showcase.css, modifiers in packages/ui/src/parts/site-fact-list.css. Need a titled panel with a footer? Use the definition list. Slots: rows (label + value).

Class / attributeDescription
.oc-fact-listThe dl: card with a line between rows
div > dt + ddOne row: label (muted) and value (bold, right)
--plainNo card, only the lines
--compactTighter rows
--stackedValue below the label (long values)
--accentValues in the element accent (.oc-accent--*)
