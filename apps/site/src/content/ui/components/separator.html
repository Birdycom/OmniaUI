Separator

A visual divider between content. .oc-separator works on <hr> or a <div>, horizontally or vertically, and .oc-separator-text puts a label in the middle (“or”). All components.

Anatomy

  • Plain hr.oc-separator: a 1px line in --oc-border.
  • Vertical --vertical on an inline element inside a flex row.
  • Labeled .oc-separator-text draws a line on both sides of its text with ::before/::after.

Vertical and with label

A vertical separator stretches to the height of a flex row.

Accessibility and keyboard

Accessibility

  • <hr> has the separator role already. For purely decorative lines use role="none" or a CSS border instead.
  • Set aria-orientation="vertical" on vertical separators that carry the role.

Keyboard

  • Separators are not interactive and not focusable.

Reference

Styles live in packages/ui/src/components-extra.css (extensions) and components.css (base). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.
