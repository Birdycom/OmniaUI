Recovery codes

Shown once after enabling two-factor authentication. Copy/download are wrapper actions. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/recovery-codes.html.

Click a code list to select it. Download .txt saves the codes as a file (a data: link, no script); Copy all needs the one line of script in its onclick, because only script can write to the clipboard.

Icons, copied feedback and print v0.17.0

The warning starts with an alert icon and the buttons carry icons (copy, download, print), all Omnia webicons. After Copy all the button says copiedLabel ("Copied") for two seconds and a hidden live region announces it. print adds a Print button that prints only the codes (a hidden frame, not the whole page). icons={false} leaves the icons out.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-recovery-codesPanel (warning tint)
.oc-recovery-codes-title / -warningHeading and explanation
.oc-recovery-codes-listTwo-column monospace grid (selectable with one click)
.oc-recovery-codes-actionsButton row. data-oc-recovery="copy|download|print" wires a button to the optional script.
.oc-recovery-codes-warning iconAn svg before the text (mdi:alert-outline) takes the warning color (0.17.0).
data-copied-label + .oc-recovery-codes-labelThe copy button shows the copied label (default "Copied") for 2s; .oc-recovery-codes-icon-copy / -copied swap on .is-copied (0.17.0). Prop copiedLabel.
.oc-recovery-codes-statusVisually hidden role="status" live region that announces the copied label (0.17.0).
print, printLabel, icons (props)A Print button that prints only the codes; icons on the buttons and the warning (default on) (0.17.0). React also exports printRecoveryCodes(codes, title).
