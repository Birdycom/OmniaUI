Scrim

A calm fade over a picture: from a color at one edge to transparent, so a caption or a title on top of the image stays readable. Put it as a child element in any positioned box with an image, or let the box draw it itself. Plain CSS, no JavaScript. Hero media uses the same tokens for its scrim. All components.

Demo

snippets/scrim.html v0.17.0

Put .oc-scrim inside a positioned box (the utility relative) after the image, and give the text on top .oc-scrim-content.

Caption on a photo v0.17.0

.oc-scrim--dark fades from near black at the bottom to transparent, so light text on it passes AA. --oc-scrim-size sets how far up the fade reaches.

Sides and the page background v0.17.0

Without --dark the scrim takes the page background, so a picture fades into the page (light and dark mode). .oc-has-scrim draws the scrim as ::after on the box itself: no extra element. The side modifiers say where it is strongest: bottom (default), --top, --start, --end, or --full for one even layer.

Reference

Styles live in packages/ui/src/parts/media-scrim.css. The default color is the page background, so the scrim follows light and dark mode.

Class / tokenDescription
.oc-scrimThe layer: a child of a positioned box with an image; click-through, aria-hidden
.oc-has-scrimThe same scrim as ::after on the box itself (it becomes position: relative)
--top / --start / --endWhere the scrim is strongest (default: bottom). Start and end follow the text direction
--fullOne even layer over the whole picture
--darkNear black instead of the page background, for light text
.oc-scrim-contentText above the scrim (z-index: 2, relative unless a position utility says otherwise)
--oc-scrim-colorScrim color (default var(--oc-background))
--oc-scrim-strengthOpacity at the strongest edge, 0 to 1 (default 0.85). Hero media reads it too
--oc-scrim-sizeHow far the fade reaches (default 60%). Hero media reads it too, as a length past the text

The scrim is decorative (aria-hidden). Check the contrast of the text on it: with light text use --dark and raise --oc-scrim-strength on bright photos.

Framework wrappers

The same markup and classes as React, Vue and Blade components.
