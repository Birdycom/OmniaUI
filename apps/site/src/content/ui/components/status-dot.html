Status dot

A small light that shows the live state of a job, an AI agent, a sync or a server: working (a ring pulses), waiting, done, error or idle. Always with the state in words next to it; the dot only adds the color. Plain CSS. For a version notice see the version banner. All components.

Reference

Styles live in packages/ui/src/parts/app-status-dot.css. Colors are theme tokens, so the dot follows light and dark mode.

Class / attributeDescription
.oc-status-dot8 px dot with a soft ring; muted without a tone
--working / --waiting / --done / --error / --idlePrimary (the ring pulses) / warning / success / destructive / muted. No pulse with reduced motion.
--sm / --lg6 px / 10 px
--oc-status-dot-colorToken: any color for the dot and its ring
.oc-statusRow: dot + .oc-status__text (one line, cuts off with …) + .oc-status__meta (right, tabular numbers)
aria-hidden="true" / role="img" aria-labelHide the dot when the text says the state; label it when it stands alone

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React (a dot alone gets role="img" and the label) --> <StatusDot tone="working" label="Working" /> <Status tone="done" meta="12 min">Done · 3 files changed</Status> <!-- Vue --> <OcStatusDot tone="working" label="Working" /> <OcStatus tone="done" meta="12 min">Done · 3 files changed</OcStatus> <!-- Blade --> <x-oc::status-dot tone="working" label="Working" /> <x-oc::status tone="done" meta="12 min">Done · 3 files changed</x-oc::status>
