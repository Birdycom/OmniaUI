Phone input

A country dial code (native <select>) and the national number (type="tel") inside one frame. Mobile keyboards show digits, autofill fills the number, and the browser checks the pattern. The React and Vue wrappers add digit grouping and return one value like +32470123456. All components.

Invalid and small

Set aria-invalid="true" on the number (server error), or let :user-invalid mark a wrong pattern after typing. --sm makes it compact.

Reference

Styles live in packages/ui/src/parts/forms-phone-input.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-phone-inputFrame around both parts. Modifiers: --sm, --error.
.oc-phone-input-dialNative select with the dial codes
.oc-phone-input-numberThe national number (type="tel", autocomplete="tel-national")
aria-invalid="true" / :user-invalidRed frame on the whole control

Framework wrappers

Same markup and classes. The wrappers group the digits while typing (470 12 34 56) and emit the full value without spaces.

<!-- React --> <PhoneInput value={phone} onChange={setPhone} countries={[{ dial: "+32", label: "BE +32" }]} /> <!-- Vue --> <OcPhoneInput v-model="phone" /> <!-- Laravel Blade --> <x-oc::phone-input name="phone" dial="+32" :value="old('phone')" />
