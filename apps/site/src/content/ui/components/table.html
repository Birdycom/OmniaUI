Table

Semantic HTML tables styled with the OmniaCSS theme tokens: borders, header background and a row hover, in light and dark mode. Use .oc-table for data tables and the expandable table to show a few rows with a CSS-only "Show more" toggle.

Data table

Add .oc-table to a <table>. Wrap it in .oc-table-wrap when it can be wider than the screen: the wrapper scrolls horizontally instead of the page.

Column widths

.oc-table uses table-layout: fixed, so a width utility on a header cell fixes that column (.w-10, .w-perc-1/3, …); the other columns share the rest.

Expandable table (CSS only)

Show the first rows and hide the rest behind a toggle: rows with .oc-expandable-table__row-more stay hidden until the checkbox inside the toggle label is checked (:has()). This is the table used for every class reference in these docs.
