Quantity

Minus, the number and plus in one frame. Without a script it is a normal number input (the browser's keyboard and arrows); with form-extras.js the buttons step within min, max and step and switch off at the limits. All components.

Quantity v0.12.6

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-quantityThe frame. --sm for a 2rem field in tables and carts.
.oc-quantity__inputA native type="number" with min, max, step and name; the spinners are hidden.
[data-oc-step="-1"] / [data-oc-step="1"]The minus and plus buttons (.oc-quantity__step); with form-extras.js they change the value and fire input and change.

Script: npx omniaui copy-js form-extras puts oc-form-extras.js in public/js; load it with <script type="module" src="/js/oc-form-extras.js"></script>. In React or Vue the component keeps the value itself.
