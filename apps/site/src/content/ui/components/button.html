Toggle button ("Show more")

.oc-btn--toggle turns a label + checkbox into a button that swaps its text and reveals extra content, with CSS only. The same mechanism powers the "Show more" under every table on this site, see Expandable table.

Which buttons OmniaCSS itself uses

The documentation site, blocks and components are built with the same classes. This is where each variant is used, so you can pick the same pattern for the same job.

ClassUsed in OmniaCSS for
.oc-btnPrimary action: block call-to-actions (hero, pricing, auth "Sign in"), modal confirm.
.oc-btn--secondaryQuiet action: every "Show more / Show less" toggle under the reference tables (most used).
.oc-btn--outlineTriggers that open something: dropdown and popover buttons, modal "Open", demo controls.
.oc-btn--gradient + .oc-btn--glassShowcase / landing pages: hero primary (gradient pill) and secondary (glass pill) - see the homepage.
.oc-btn--ghostToolbar and icon actions without a frame (close buttons, pagination arrows).
.oc-btn--destructive / .oc-btn--successConfirm dialogs (delete / save).
.oc-btn--sm / .oc-btn--lg / .oc-btn--iconCompact toolbars and pagination / hero call-to-actions / icon-only buttons.
