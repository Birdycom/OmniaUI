Tree

A nested list of folders and items. Folders are native <details>, so they open and close without JavaScript. Long names scroll sideways, while the action column stays pinned to the end edge with position: sticky. All components.

Tree with sticky actions

CSS component parts/app-tree.css

The box is 18rem high (--oc-tree-height) and scrolls. Scroll sideways on the long file name: the rename button stays visible. The current item has aria-current="true" on its link. Snippet: packages/ui/snippets/tree.html.

Quiet and flush

.oc-tree--quiet shows the actions only on hover or keyboard focus. .oc-tree--flush drops the frame, for use inside a card or sidebar. A row can also carry .is-selected.

Reference

Custom properties: --oc-tree-height, --oc-tree-indent (1rem), --oc-tree-row (2rem). Colors are theme tokens.

Class / attributeDescription
.oc-treeScroll box with a card frame. Modifiers: --flush, --quiet
.oc-tree-headRoot row that sticks to the top
ul.oc-tree-listList; nested lists indent one step
details.oc-tree-node + summary.oc-tree-rowFolder; the chevron turns when open
div.oc-tree-rowLeaf row. States: aria-current="true" (row or label link), .is-selected, .is-muted
.oc-tree-icon / -label / -countIcon, name (never wraps; may be a link), count
.oc-tree-actionsButtons pinned to the end edge (sticky)

Browser support

Everything here is widely supported; :has() is only used for the selected state of a leaf link.
