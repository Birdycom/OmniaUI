Price

How shops and quotes show a price: the amount, an optional old price and discount badge, a VAT note and the other amount (incl. or excl. VAT). Tabular digits, so prices line up in lists and tables. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-priceThe block: __main line, then __note and __alt below.
.oc-price__amountThe price (bold, tabular digits, never wraps).
.oc-price__oldThe old price, struck through. Add an .oc-badge in __main for the discount.
.oc-price__note / __altA quiet note ("excl. VAT") and the other amount ("€ 121,00 incl. VAT").
.oc-price--sm / --lg / --saleSmaller or larger amount; --sale colors the amount red.
.oc-price--inline / --endAmount and note on one line (lists); right aligned (also automatic in a td[data-numeric]).

Format the numbers in your code (or let the React, Vue and Blade components do it with the locale and currency).
