Browser frame

Fake browser chrome (traffic lights, address pill) around a screenshot, a video or live HTML. Made for portfolio cards, product shots and docs. Variants: minimal, dark chrome and a 3D tilt that straightens on hover. All components.

Demo

Component snippets/browser-frame.html v0.6.0

Plain HTML and CSS. Swap the placeholder for an <img> of your screenshot; it is cropped from the top.

Minimal, dark, tilt and live content

--minimal keeps only the dots; --dark darkens the chrome in both themes; --tilt adds a 3D angle that straightens on hover. With --auto the view takes the height of live content, here a Card.

Accessibility

  • Use <figure> + <figcaption> when the frame shows a screenshot; give the image real alt text.
  • The dots, lock and action glyphs are decorative (<i>, an empty alternative text on the lock, aria-hidden on the actions). The address is plain text.
  • The tilt only animates under prefers-reduced-motion: no-preference and is removed entirely under reduce.
