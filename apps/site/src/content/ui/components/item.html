Item

A flexible row for lists of things: media on the left, title and description in the middle, actions on the right. Use it for settings rows, file lists, notifications and search results. It can be a div, li or a link. All components.

Anatomy

  • Root .oc-item: wraps on narrow screens, the content basis is 14rem.
  • Media .oc-item-media with --icon or --image.
  • Content title (weight 500) and a muted description.
  • Actions right aligned buttons or a chevron.

Accessibility and keyboard

Accessibility

  • Make the whole row a link (a.oc-item) when it navigates; do not nest interactive elements inside that link.
  • For lists use <ul>/<li class="oc-item"> so the count is announced.
  • Decorative icons: aria-hidden="true".

Keyboard

  • Link items are focusable with Tab and show a focus ring; actions are ordinary buttons.
