Particle field

A background canvas with slowly drifting points and thin lines between neighbours, like a network. The colors come from CSS (the accent colors), so a theme switch recolors it. It pauses when the tab is hidden; with reduce motion it draws one still frame. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
canvas.oc-particlesFixed behind the page (z-index -1). color = points and lines, border-color = a second point color.
.oc-particles--localFills a positioned parent instead of the viewport.
data-count / data-speed / data-linkNumber of points (110), drift speed (0.35) and the line distance in px (115).
initParticles(canvas, options)From @birdycom/omniaui/particles.js; returns a stop function.

React <ParticleField local count={70} />, Vue <OcParticleField local :count="70" />, Blade <x-oc::particle-field local /> (with the script).

Script: npx omniaui copy-js particles puts oc-particles.js in public/js; load it with <script type="module" src="/js/oc-particles.js"></script>.
