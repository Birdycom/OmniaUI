Data table

The list table from Korrekt and OmniaDesk. One toolbar (title, gear menu, search, trash and archive pills, table or cards), the table in a rounded frame, and a footer with the count, rows per page and page numbers. Search, sort, pages, column width, row drag and bulk actions run in the browser. All components.

Reference

Put .oc-data-table around the toolbar, the table and the footer. Load data-table.js once. The script wires every table on the page.

PieceWhat it does
.oc-data-table-searchFilters rows as you type. Enter fires oc-datatable-search (barcode scanners).
[data-oc-filter]Active only, including trash, trash only, archive only. Reads data-oc-status on the row.
.oc-table-sortSorts the column. Numeric columns use data-oc-sort="numeric" and data-oc-value.
[data-oc-page-size] / [data-oc-pager]Rows per page and the numbered pager. The count is [data-oc-summary].
.oc-column-menuShow or hide a column. The checkbox data-col is the column number.
.oc-data-table-resizeDrag to set the column width. Widths are remembered for this table id.
.oc-sortable-row-gripDrag a row by the grip. Fires oc-datatable-reorder.
[data-oc-view]table or grid. Cards are built from the rows on the current page.
[data-oc-density]comfortable or compact (tighter rows).
[data-oc-bulk]export, duplicate, archive, restore, delete, clear. Fires oc-datatable-bulk with the selected keys.
[data-oc-export] / [data-oc-import]Download the filtered rows as CSV, or pick a file (oc-datatable-import).
data-oc-hrefClick the row to open that URL. Clicks on buttons and inputs stay on the control. Ctrl-click opens a new tab.
data-oc-live="true"The demo updates rows in the page. Leave it off in an app and handle the event yourself.

React, Vue and Laravel

The wrappers render this markup and start the same script. onBulk in React receives the action and the selected keys.

<!-- React --> <DataTable title="Articles" columns={columns} rows={rows} onBulk={onBulk} /> <!-- Vue --> <OcDataTable title="Articles" :columns="columns" :rows="rows" /> <!-- Laravel Blade --> <x-oc::data-table title="Articles" :columns="$columns" :rows="$rows" />
