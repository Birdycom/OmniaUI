Counter

An animated number built with a registered custom property (@property) and a CSS counter: the browser animates the value, no JavaScript needed. Optionally it starts when the number scrolls into view.

Demo

snippets/counter.html

Plain HTML and CSS. Set the target with --oc-counter-to. The markup is also available as the snippet packages/ui/snippets/counter.html.

Prefix and suffix

--oc-counter-prefix and --oc-counter-suffix add text around the number (as CSS strings); --oc-counter-from and --oc-counter-duration change the start and the speed.

Start when visible

.oc-counter--on-view starts the animation when the number scrolls into view (scroll-driven animation); browsers without it show the end value.

Reference

Styles live in packages/ui/src/components.css.
