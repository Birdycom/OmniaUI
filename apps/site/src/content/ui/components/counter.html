Counter

An animated number built with a registered custom property (@property) and a CSS counter: the browser animates the value, no JavaScript needed. Optionally it starts when the number scrolls into view.

Demo

snippets/counter.html

Plain HTML and CSS. Set the target with --oc-counter-to. The markup is also available as the snippet packages/ui/snippets/counter.html.

The number counts up from 0 to 1250 once, when the page loads. Reload the page to see it again, or use the next examples.

Prefix and suffix

--oc-counter-prefix and --oc-counter-suffix add text around the number (as CSS strings); --oc-counter-from and --oc-counter-duration change the start and the speed.

--oc-counter-suffix: '%'
Text after the number, as a CSS string.
--oc-counter-prefix: '€ '
Text before the number: a currency sign.
--oc-counter-from: 10
Counts down from 10 to 0, over 3 seconds (--oc-counter-duration).

Start when visible

.oc-counter--on-view starts the animation when the number scrolls into view (scroll-driven animation); browsers without it show the end value.

import { Counter } from "@birdycom/omniaui-react"; export function Example() { // onView is the default: the count starts when the number scrolls into view return <Counter to={1250} suffix="+" className="font-2" />; } <script setup lang="ts"> import { OcCounter } from "@birdycom/omniaui-vue"; </script> <template> <!-- on-view is the default: the count starts when the number scrolls into view --> <OcCounter :to="1250" suffix="+" class="font-2" /> </template> {{-- on-view is the default: the count starts when the number scrolls into view --}} <x-oc::counter :to="1250" suffix="+" class="font-2" /> <?php namespace App\Livewire; use Livewire\Component; class CounterStartOnView extends Component { public function render() { return view('livewire.counter-start-on-view'); } } {{-- resources/views/livewire/counter-start-on-view.blade.php --}} <div> {{-- on-view is the default: the count starts when the number scrolls into view --}} <x-oc::counter :to="1250" suffix="+" class="font-2" /> </div>

Reference

Styles live in packages/ui/src/components.css.

Class / propertyDescription
.oc-counterThe number. Put it on an empty element; the value is drawn with a CSS counter.
.oc-counter--on-viewStarts when the element scrolls into view.
--oc-counter-to / --oc-counter-fromEnd and start value (whole numbers; start defaults to 0).
--oc-counter-prefix / --oc-counter-suffixText before and after the number, as a CSS string ('€ ', '%').
--oc-counter-durationLength of the animation.
