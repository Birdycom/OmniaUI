Aspect ratio

A box that keeps a fixed ratio for images, video and embeds, with presets and a custom property. For a one-off use the aspect-* utilities; this component adds the clipping, background and fill behaviour. All components.

Platform features used

CSS featureRole
aspect-ratioReserves space before the media loads (no layout shift)
object-fitMedia covers the box

Anatomy

  • Box aspect-ratio: var(--oc-aspect) on a block that takes the width of its container (set inline-size or let it fill).
  • Content a direct img, video, iframe, svg or picture fills the box with object-fit: cover.

Accessibility and keyboard

Accessibility

  • The ratio box is presentational; keep alt text on images and title on iframes.

Keyboard

  • Not interactive.
