Combobox

An input with a listbox of suggestions, with or without an icon in front of each option. The CSS draws the field, the chevron and the list, and opens the list while the wrapper has focus. Filtering, keyboard selection and the ARIA bookkeeping come from the React, Vue or Blade component, or from the small script oc-combobox.js. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/combobox.html.

Click the field: the list opens while the field has focus, with Laravel marked as chosen and Svelte disabled. Hover the options. Typing does not filter here: filtering and choosing need the wrapper component or your own script.

Catalog mode v0.17.0

For long lists that live on the server: customers, products, ledger codes. The customer field searches while you type (here a fake server that answers after 300 ms; the list shows a loading row meanwhile and an older answer never overwrites a newer one), gives numeric ids, starts with a row that clears the choice and ends with a Manage customers link outside the listbox. It sits in a small scrolling box and uses portal: the list moves to document.body so the box does not cut it off. The unit field is local, uses emoji and the ledger look, and offers what you typed when nothing matches exactly (type week). Options can have a description, an image or an emoji.

In a header bar: ghost, header size, icon only v0.17.2

A combobox in an app header (a workspace, a language, a view) should not look like a form field. triggerVariant="ghost" (.oc-combobox--ghost) drops the border, the shadow and the margin: muted text that gets fuller on hover and focus, with a light background (tinted with data-module when there is one; the focus ring is an outline in that colour). size="header" (.oc-combobox--header) makes it compact: 36px high and as wide as its label, between 6.5rem and 14rem, with the label cut off with an ellipsis; the default size="full" fills its box. iconOnly (with size="header", .oc-combobox--icon-only) is a square 36x36 button without label or chevron. It shows triggerLabel (a short code such as "NL", .oc-combobox-code), else the icon, image or emoji of the chosen option, else a dots icon. Give an icon-only trigger a name with triggerAriaLabel (or label). A header combobox puts its list in document.body (portal, on by default with size="header"), at least 12rem wide, so the bar does not cut it off. It works with variant="ledger" too.

Anatomy

  • Input the existing .oc-input with extra end padding for the chevron.
  • List absolutely positioned under the field; hidden with visibility/opacity so it can fade, shown on :focus-within or [data-open] (use data-open="false" to force it closed after a choice).
  • Options need tabindex="-1" so clicking one keeps focus inside the wrapper and the list does not close before the click lands.

Accessibility and keyboard

Accessibility

  • Follow the ARIA combobox pattern: role="combobox" on the input, aria-expanded, aria-controls and aria-activedescendant pointing at the active option.
  • The wrapper must filter the list, move [data-active]/aria-activedescendant with the arrow keys, set aria-selected and write the chosen label into the input.
  • Catalog mode: the listbox gets aria-busy="true" while results load; the clear and custom rows have role="option"; the manage link sits in a footer outside the role="listbox", so the listbox only holds options.
  • If you only need to pick one value from a short list, a native select is simpler and more accessible.

Keyboard

  • ↓/↑ move the active option, Enter selects, Esc closes, Home/End jump (implemented by the wrappers and oc-combobox.js).
  • The clear row and the "use what I typed" row are options too: the arrow keys reach them and Enter chooses them.

Framework wrappers

The wrappers filter, move with the keyboard and set aria-selected, aria-activedescendant and aria-expanded themselves. options is a list of { value, label, icon?, description?, image?, emoji?, disabled? }; icon is a webicon name (mdi:…, flag:…) or, in React, any node. name adds a hidden input for forms. Catalog mode (0.17.0): valueType="number", onSearch (Vue @search) + searchDelay + loading + selected, clearLabel, manageHref / manageLabel / onManage, allowCustomFromSearch + customLabel + onCustom, portal, variant="ledger", module. Livewire: <x-oc::wire.combobox model="customerId" search="searchCustomers"> sets the property and asks a component method for the results.
