Combobox

An input with a listbox of suggestions. The CSS draws the field, the chevron and the list, and opens the list while the wrapper has focus. Filtering, keyboard selection and the ARIA bookkeeping belong to the wrapper component (Vue, React, Blade) or about 40 lines of your own script. All components.

Anatomy

  • Input the existing .oc-input with extra end padding for the chevron.
  • List absolutely positioned under the field; hidden with visibility/opacity so it can fade, shown on :focus-within or [data-open] (use data-open="false" to force it closed after a choice).
  • Options need tabindex="-1" so clicking one keeps focus inside the wrapper and the list does not close before the click lands.

Accessibility and keyboard

Accessibility

  • Follow the ARIA combobox pattern: role="combobox" on the input, aria-expanded, aria-controls and aria-activedescendant pointing at the active option.
  • The wrapper must filter the list, move [data-active]/aria-activedescendant with the arrow keys, set aria-selected and write the chosen label into the input.
  • If you only need to pick one value from a short list, a native select is simpler and more accessible.

Keyboard

  • ↓/↑ move the active option, Enter selects, Esc closes, Home/End jump (all implemented by the wrapper).
