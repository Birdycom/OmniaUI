Native select

The real <select>, themed. .oc-select styles the closed control in every browser; add .oc-select--custom and browsers with appearance: base-select also theme the picker popup (rounded panel, hover color, check mark) while keeping all native behaviour. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/native-select.html.

Reference

Styles live in packages/ui/src/components-extra.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Anatomy

  • Closed control .oc-select: border, radius, chevron.
  • Picker with @supports (appearance: base-select) the ::picker(select) popup becomes stylable: panel, option:hover, option::checkmark and ::picker-icon.
  • Fallback unsupported browsers ignore the block and show the platform picker; the select keeps working.

Accessibility and keyboard

Accessibility

  • A native select keeps keyboard, type-ahead, mobile pickers and form integration. Prefer it to custom listboxes whenever the options are plain text.
  • Always pair with a <label>.

Keyboard

  • Space/Enter/↓ open; arrow keys and type-ahead choose; Esc closes.
