Section block

Herbruikbaar section-component met header (titel, badges, beschrijving), content (hoofdinhoud) en footer. Twee manieren: default met alleen OmniaCSS-utilityclasses, of met de component-classes uit oc-components.css (.oc-section, .oc-section-header, enz.).

Reference (default)

Utilityclasses: border, border-solid, border-stormblue-100, border-b / border-t, p-2, flex, flex-wrap, align-items-center, gap-1, round-3, bg-duskblue-100, bg-shallowblue-mix-30. Badges blijven oc-badge-source / oc-badge-version voor consistentie.

Section block (component)

Component v0.2.5

Zelfde layout met .oc-section, .oc-section-header, .oc-section-content, .oc-section-footer. Kopieer de code hieronder om een section in je eigen pagina te gebruiken.

Preview

Hieronder een minimale section met alleen header, content en footer (zoals deze pagina).

Section titel

_example.scss v0.2.5

Korte beschrijving van de section.

Inhoud van de section. Hier komt de hoofdcontent (preview, code, tabellen, etc.).

Footer titel

Optionele footer met extra info of links.

Code

Kopieer deze markup; pas titels, badges en inhoud aan.

<section class="oc-section" id="my-section"> <div class="oc-section-header"> <h2 class="oc-section-header__title">Section titel</h2> <span class="oc-section-header__badge-source oc-badge-source">Source</span> <span class="oc-section-header__badge-version oc-badge-version">v0.2.5</span> <p class="oc-section-header__desc">Korte beschrijving.</p> </div> <div class="oc-section-content"> <p>Hoofdinhoud van de section.</p> </div> <div class="oc-section-footer"> <h2 class="oc-section-footer__title">Footer</h2> <p class="oc-section-footer__desc">Optionele footer.</p> </div> </section>

Reference

Classes in oc-components.css: .oc-section (wrapper), .oc-section-header (grid: title, badges, desc), .oc-section-content (padding), .oc-section-footer (border-top). Zie ook de .oc-preview-rij in Sample block voor gebruik in een component-pagina.
