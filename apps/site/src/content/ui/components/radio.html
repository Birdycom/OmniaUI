Radio group

Native radio inputs with the theme accent. .oc-radio styles the input; .oc-radio-group and .oc-radio-item lay out the choices, optionally as selectable cards using :has(:checked). All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/radio.html.

Plan

Anatomy

  • Group a <fieldset> with a <legend> (or role="radiogroup" + label).
  • Item label.oc-radio-item wrapping an input.oc-radio sharing one name.
  • Card --card outlines the label and highlights the checked option through :has(:checked).

Descriptions and card style

Put a <small> in the label for a description; --card turns each option into a selectable card.

Accessibility and keyboard

Accessibility

  • Native radios give you grouping, roving focus and form submission for free.
  • Use a fieldset/legend so the question is read before the options.

Keyboard

  • Tab enters the group on the checked radio.
  • ↑ ↓ ← → move and select; Space selects the focused radio.

Reference

Styles live in packages/ui/src/components-extra.css (extensions) and components.css (base). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.
