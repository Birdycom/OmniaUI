Media card

A feed card for a video: a Media thumb, the channel avatar, a two-line title, meta text and an overflow menu. The title link covers the whole card, so the card is one big click target; the menu opens a Dropdown with the popover attribute. All components.

Accessibility and keyboard

  • One link per card (the title): screen readers hear the title once, not a separate "thumbnail" link. The focus ring is drawn around the whole card.
  • The avatar is decorative (aria-hidden) when the channel name is in the meta line.
  • The menu button needs an aria-label ("More actions"). Esc closes the popover menu.

Reference

Styles live in packages/ui/src/parts/media-card.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.
