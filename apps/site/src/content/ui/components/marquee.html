Marquee

An endless strip of chips for technologies, clients or features. A CSS animation moves the track; it pauses on hover and keyboard focus. With prefers-reduced-motion the strip stands still and simply wraps, so every item stays readable. All components.

Demo

Render the items twice: the copy keeps the loop seamless and has aria-hidden="true", so screen readers read the list once. Snippet: packages/ui/snippets/marquee.html.

The tags scroll on their own and fade out at both edges. Hover the strip to pause it; with reduced motion it stands still.

Class / attributeDescription
.oc-marqueeClipping wrapper with soft edges; give it an aria-label
.oc-marquee__trackThe moving row (items + an aria-hidden copy)
.oc-marquee__itemOne chip
--reverse / --slow / --fastDirection and speed presets
--plain / --no-fadeText without pills / no fade at the edges
--oc-marquee-durationCustom loop time (default 40s)
