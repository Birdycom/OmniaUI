Marquee

An endless strip of chips for technologies, clients or features. A CSS animation moves the track; it pauses on hover and keyboard focus. With prefers-reduced-motion the strip stands still and simply wraps, so every item stays readable. All components.

Demo

Render the items twice: the copy keeps the loop seamless and has aria-hidden="true", so screen readers read the list once. Snippet: packages/ui/snippets/marquee.html.
