Reference (preview-component)

Class / VariableDescription
.oc-previewWrapper: flex, wrap, gap. Combine with .preview for doc container (border, bg).
.oc-preview-rowRichting: items naast elkaar (row). Gebruik samen met gap-* (bijv. gap-3.5).
.oc-preview-colRichting: items onder elkaar (column). Gebruik samen met gap-* (bijv. gap-2).
.oc-preview__titleOptionele sectietitel boven een preview-blok.
.oc-preview__itemÉén item: flex column, align center. Content = div, tekst, img; stijl met Omnia classes.
.oc-preview__labelLabel boven content; optioneel Omnia classes voor font/kleur (bijv. font-clamp-0.7 font-monospace text-mistblue mb-0.5).
.oc-preview__item_content-leftItem met content links uitgelijnd (bijv. voor font-demo’s).
Utilities in __itemBijv. round-*, border, bg-darkorange-mix-30, font-1–font-3, text-dodgerblue-50.
