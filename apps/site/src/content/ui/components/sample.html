Sample Block

A small layout for documentation: .oc-preview places labelled samples next to or under each other, such as border radii or font sizes. Each item can hold anything (a box, a line of text, an image); colors and sizes come from OmniaCSS utilities.

Reference

Styles live in packages/ui/src/components.css.

ClassDescription
.oc-previewThe wrapper: flex, wrap and a gap. Add a gap-* utility to change the spacing.
.oc-preview-row / .oc-preview-colItems next to each other / under each other.
.oc-preview__titleOptional title above a preview.
.oc-preview__itemOne sample: label above, content centered.
.oc-preview__item_content-leftOne sample aligned to the start, for text.
.oc-preview__labelSmall monospace label above the content.
