Definition list

A semantic <dl> in a titled panel. Two columns from 40rem, stacked below; long values wrap instead of overlapping the label. All components.

Glossary v0.14.1

.oc-dl--glossary on the dl for a term and its explanation: the term bold, the explanation normal text, and both start on the same line. Term column --oc-dl-term-width (30%).

Numbered v0.17.0

.oc-dl--numbered on the dl puts a counter above each term: 01, 02, 03 (a CSS counter with decimal-leading-zero, in the muted color with tabular figures). The numbers are not in the HTML, so screen readers read the terms as they are. It works with --glossary, and with --flush on a dl without a panel (a list of services on a page). Start at another number with style="counter-reset: oc-dl 4".

Stat list v0.18.0

.oc-dl--stat turns the rows into a score or cost breakdown: label left and value right on one row (also on a phone), the values in tabular numbers, an optional sublabel (.oc-dl-sub) and a total row (.oc-dl-row--total) with a stronger line above it. It works inside a panel or on its own. Wrappers: StatList, OcStatList, <x-oc::stat-list>.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: title, description, rows (term + detail), footer.

Class / attributeDescription
.oc-dl-panelPanel wrapper (role="region")
.oc-dl-title / -descriptionPanel heading and note
.oc-dlThe dl
.oc-dl-rowdiv grouping one term and detail
.oc-dl-term / .oc-dl-detaildt / dd
.oc-dl-footerOptional footer (actions)
.oc-dl--glossaryOn the dl: term bold in the foreground, explanation normal and muted, first lines on one line. Wrappers: glossary prop.
.oc-dl--stat0.18.0: a stat list: label and value on one row (also narrow), values in tabular numbers, aligned to the end. Wrappers: StatList / OcStatList / <x-oc::stat-list> with items and total.
.oc-dl-sub0.18.0: a small muted line under the label of a stat row.
.oc-dl-row--total0.18.0: the total row of a stat list: bold, a 2px line above it.
.oc-dl--numberedOn the dl: a counter (01, 02, ...) above each term, muted, tabular figures. Wrappers: numbered prop.
.oc-dl--flushOn the dl: no margin and no line above it, for a list without a title above it. Inside .oc-prose the rows keep their own spacing and the dd is not indented; glossary terms hyphenate (hyphens: auto, set lang on the page).
