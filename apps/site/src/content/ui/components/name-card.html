Name card

A collapsible card for one part of a quote or a plan: the name with a pencil to rename it, an optional amount and a delete button in the header, the content below. Native <details>; the small script adds the inline rename. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-name-cardThe card: a <details>; open shows the content.
.oc-name-card__headThe <summary>: chevron, name, rename, meta, amount and actions on one line.
.oc-name-card__title / __meta / __amountName (cut with an ellipsis), a quiet extra ("6 articles") and the amount (tabular numbers, pushed right).
.oc-name-card__actionsButtons on the right, e.g. a soft destructive delete.
[data-oc-rename]With form-extras.js: the pencil turns the name into an input; Enter or leaving the field saves (oc-namecard-rename event with the name), Escape cancels.
.oc-name-card__bodyThe content. Name cards inside it are the parts of a title (quieter surface).
.oc-name-card--totalThe amount of this card in the primary color (a total).

Script: npx omniaui copy-js form-extras puts oc-form-extras.js in public/js; load it with <script type="module" src="/js/oc-form-extras.js"></script>. In React or Vue call initFormExtras(element) from @birdycom/omniaui/form-extras.js after mount.
