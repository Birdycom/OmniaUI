Busy overlay

A modal "please wait" box for long requests: saving a form with photos, an import, an upload. As a modal <dialog closedby="none"> it makes the page inert, so nothing gets clicked twice, and Esc does not close it. It fades in after 300 ms, so quick requests never flash. Comes from the save overlay of the Verdavita admin. Install with npx omniaui add busy-overlay. All components.

Demo

Component snippets/busy-overlay.html v0.9.1

The demo button opens the overlay and closes it after three seconds. In a real form, data-oc-busy="dialog id" on the <form> opens it when the form is submitted; the next page replaces it.

In a form

<form class="oc-form-group" data-oc-busy="oc-busy-overlay-demo" action="/photos" method="post" enctype="multipart/form-data"> <label class="oc-dropzone"> <input type="file" name="photos[]" accept="image/*" multiple> <span><strong>Choose photos</strong> to upload</span> <span class="oc-dropzone-hint">They are resized to 600px and 1080px after saving</span> </label> <button class="oc-btn" type="submit">Save</button> </form> <dialog class="oc-busy-overlay" id="oc-busy-overlay-demo" closedby="none" aria-labelledby="oc-busy-overlay-demo-title" aria-describedby="oc-busy-overlay-demo-text"> <span class="oc-spinner" role="status" aria-label="Busy"></span> <h2 class="oc-busy-overlay__title" id="oc-busy-overlay-demo-title">Saving…</h2> <p class="oc-busy-overlay__text" id="oc-busy-overlay-demo-text">The photos are being processed. This can take a minute; please keep this page open.</p> </dialog> <script> // Open the busy overlay of a form when it is submitted (the submit event only fires when the form is valid). document.addEventListener("submit", (e) => { const id = e.target.dataset?.ocBusy; if (id) document.getElementById(id)?.showModal(); }); </script>

The submit event only fires after the browser's own validation, so the overlay never appears for an invalid form. With fetch(), call dialog.close() when the request is done. For a known percentage, put an .oc-progress in place of the spinner.

Reference

Styles live in packages/ui/src/parts/app-busy-overlay.css. Colors are Omnia theme tokens only.

Class / attributeDescription
dialog.oc-busy-overlay[closedby=none]The overlay: modal, page inert, Esc does nothing
.oc-spinner / .oc-progressActivity, or progress when you know the percentage
.oc-busy-overlay__title / __textWhat happens and how long it may take
form[data-oc-busy]Opens the dialog with that id on submit (script in the snippet)
