Image zoom

A fixed-ratio window around a large image. Pick a zoom level and pan by scrolling, dragging on touch or with the arrow keys. The levels are radio buttons read with :has(); the image simply gets wider than its window, so the browser's own scrolling does the panning. No JavaScript. All components.

Zoom

Fixed level, square window

Without a toolbar: .oc-image-zoom--200 (or style="--oc-zoom: 2.5") sets the level, --square the window ratio. Useful for a "detail" crop next to the full image.

How it works

  • Viewport keeps a ratio (--oc-image-zoom-ratio, default 16 / 9) and has overflow: auto.
  • Canvas has the same ratio and inline-size: calc(100% * var(--oc-zoom)). At 2× it is twice as wide and twice as high, so the viewport scrolls in both directions.
  • Levels: .oc-image-zoom:has(input[value="2"]:checked) sets --oc-zoom: 2. Supported radio values: 1, 1.5, 2, 3, 4.
  • Using real size instead of transform: scale() means the scroll area is always correct and the image stays sharp (the browser picks the pixels at the new size).

Accessibility and keyboard

  • The toolbar is a role="radiogroup" of real radio buttons: Tab into it, ←/→ change the level.
  • The viewport has tabindex="0", role="region" and a label, so the arrow keys pan it.
  • Keep alt text on the image. The size change only animates under prefers-reduced-motion: no-preference.
