Date field

A date picker for planning: calendar icon | line | date, and the ISO week at the end when it matters (planning, deliveries). The date is a native <input type="date">, so the picker, keyboard and locale come from the browser. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-date-fieldThe frame around icon, input and week; focus ring on the frame.
.oc-date-field__iconThe calendar icon zone with a line after it.
input.oc-date-field__input[type=date]The native date input (value YYYY-MM-DD).
output.oc-date-field__weekWith form-extras.js: the ISO week of the date, "Week 45". Template: data-oc-week="W{week} · {year}". Hidden without a date.
.oc-date-field--sm2rem high (also inside .oc-density-compact).
isoWeek(date)Exported from form-extras.js: { week, year } after ISO 8601 (week 1 holds the first Thursday).

The ISO week year can differ from the calendar year: 3 January 2021 is week 53 of 2020, 30 December 2024 is week 1 of 2025.
