Terminal log

A console window for live output: traffic-light title bar, a "Live" status dot, time-stamped lines with colored levels and a prompt with a blinking cursor. It is always dark, in both themes, thanks to color-scheme: dark. The cursor stops blinking with reduced motion. All components.

Accessibility and keyboard

  • role="log" (with aria-live="polite") makes screen readers read new lines without stealing focus. Use it only for output that really streams.
  • The level is real text ("warn", "error"), not only a color, so the meaning survives for color-blind users and screen readers.
  • tabindex="0" on the body lets keyboard users scroll a long log with the arrow keys.
  • The traffic lights are decorative <i> elements without content.
