Theme switch

A system / light / dark switch built with radio inputs, color-scheme, light-dark() tokens and :has(): the whole page follows without JavaScript. Inside an element with .oc-theme-scope the switch themes only that element, as in the demo below.

Remembering the choice

Switching is CSS only, but CSS cannot remember a choice between page loads. Persistence is an optional enhancement: a few lines store the value in localStorage and restore it as data-theme on load. Without them the page starts in "System" (the OS preference). These docs use exactly this script.

<script> /* optional: persistence only, the switch itself needs no JS */ try { const t = localStorage.getItem("oc-theme"); if (t && t !== "system") document.documentElement.dataset.theme = t; } catch {} addEventListener("change", (e) => { if (e.target.name === "oc-theme") try { localStorage.setItem("oc-theme", e.target.value); } catch {} }); </script>

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-theme-switchThe segmented group (a <fieldset> with three radio labels).
input[name="oc-theme"]Values system, light and dark. A checked light or dark sets color-scheme on :root.
.oc-theme-scopeOn any element: a switch inside it themes only that element (previews, embedded widgets).
<html data-theme="light|dark">A fixed theme without a switch, or the value restored by the optional script.
