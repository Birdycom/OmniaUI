Theme switch

System / light / dark switch built with radio inputs, color-scheme, light-dark() tokens and :has() — the whole page follows without JavaScript.

Usage

Pick a theme: every component token is light-dark(light, dark), so the page switches instantly. Use <html data-theme="light|dark"> for a fixed theme.

 /* shipped in components.css: pure CSS, no JavaScript */ :root:has(.oc-theme-switch input[value="light"]:checked) { color-scheme: light; } :root:has(.oc-theme-switch input[value="dark"]:checked) { color-scheme: dark; }

Remembering the choice

Switching is CSS-only. CSS alone cannot remember a choice between page loads, so persistence is an optional progressive enhancement: a few lines that store the selected value in localStorage and restore it as data-theme on load. Without them the page simply starts in "System" (the OS preference) again. The docs site uses exactly this enhancement.

<script> /* optional: persistence only, the switch itself needs no JS */ try { const t = localStorage.getItem("oc-theme"); if (t && t !== "system") document.documentElement.dataset.theme = t; } catch {} addEventListener("change", (e) => { if (e.target.name === "oc-theme") try { localStorage.setItem("oc-theme", e.target.value); } catch {} }); </script>
