Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon, title (+ trailing badge), description, footer.

Class / attributeDescription
.oc-launcherCard (link or button). State: aria-current="true" / .is-active, aria-disabled="true".
.oc-launcher-iconTinted icon tile
.oc-launcher-titleTitle (may contain a badge)
.oc-launcher-descriptionMuted description
.oc-launcher-footerOptional footer text (e.g. why it is disabled)
