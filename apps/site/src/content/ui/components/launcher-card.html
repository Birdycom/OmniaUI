A footer only while disabled v0.17.0

The same card can be open for one user and closed for another. disabledFooter is the footer that shows only while the card is disabled (why it is off), in place of the normal footer, so one card in your code covers both states. Left: open, right: disabled. Blade: disabled-footer or the slot disabledFooter; Vue also the slot disabled-footer.

Module colour v0.17.0

On a hub every card can carry the colour of its module: module (data-module) tints the icon tile, and the hover and current border (aria-current, middle card) take the module colour. Cards inside a data-module wrapper follow without the prop.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon, title (+ trailing badge), description, footer.

Class / attributeDescription
.oc-launcherCard (link or button). State: aria-current="true" / .is-active, aria-disabled="true".
.oc-launcher-iconTinted icon tile
.oc-launcher-titleTitle (may contain a badge)
.oc-launcher-descriptionMuted description
.oc-launcher-footerOptional footer text (e.g. why it is disabled)
disabledFooter (Blade disabled-footer)Footer shown only while the card is disabled, in place of footer: why it is off. Vue and Blade also as a slot.
