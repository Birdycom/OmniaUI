Column menu

A popover with one checkbox per table column. Unchecking a box hides that column. The hiding is pure CSS: :has() on a wrapper reads the checkboxes and hides the matching th and td cells. All components.

Hide columns without JavaScript

CSS component parts/app-column-menu.css

Wrap the menu and the table in .oc-column-menu-scope. Give each checkbox data-col="n", where n is the column number (1 to 10). Open "Columns" and toggle E-mail or Phone. Snippet: packages/ui/snippets/column-menu.html.

Locked columns and reset

A column that must stay visible gets disabled checked; it shows muted and cannot be clicked. The list is a <form>, so a native <button type="reset"> restores the default columns. To remember the choice between visits, save the checkbox states in your app (the wrappers accept a columns list with checked).

Browser support

Hiding needs :has(). Without it all columns stay visible, which is a safe fallback.
