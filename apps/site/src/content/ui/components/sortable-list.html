Sortable list

A list whose items you put in order: drag the grip with a finger, pen or mouse (pointer events, so it works on a tablet), or pick an item up with Space and move it with the arrow keys. A drop line shows where it lands, every move is announced, and the list reports the new order. All components.

Markup and CSS, with sortable-list.js for the behaviour. The markup is also the snippet packages/ui/snippets/sortable-list.html.

Route order v0.18.0

Drag a grip, or tab to it and press Space, then the arrow keys, then Space again (Escape puts it back). The arrow buttons move one step for people who do not drag. In an ol the positions follow the new order on their own. The list fires oc-reorder with { from, to, order }; React and Vue get the new array back.

Reference

Styles in packages/ui/src/parts/app-sortable-list.css, behaviour in packages/ui/src/sortable-list.js. The grip is the one of the Sortable row.

Class / attributeDescription
ul|ol.oc-sortable-list[data-oc-sortable]The list. ol shows the positions (1., 2., ...) from a CSS counter.
li.oc-sortable-item[data-id]One item. data-id goes into the new order; data-label is the name in the announcements (default the text).
button.oc-sortable-row-gripThe grip: drag it (mouse, pen, touch), or Space / Enter to pick up, arrows or Home / End to move, Space to drop, Escape to cancel. Gets aria-pressed.
.oc-sortable-item__bodyThe content of the row.
.oc-sortable-item__arrows + [data-oc-move="up|down"]Optional buttons that move one step. Prop arrows.
.oc-sortable-item--grabbedPicked up with the keyboard: primary border and tint.
.oc-sortable-item--draggingThe original place while dragging: faded and dashed.
.oc-droplineThe line where the item lands (an li outside the counter).
.oc-drag-ghostThe copy that follows the pointer: slightly tilted, a normal shadow (no tilt with reduced motion).
oc-reorder eventOn the list after every move: detail = { from, to, order, id }.
data-oc-reorder-call="method"Livewire: calls that method of the component around the list with the new order. Blade prop reorder; prop name adds hidden inputs name[] for a plain form.
bindSortableList(list, { move, onReorder, messages })From @birdycom/omniaui/sortable-list.js. move: false leaves the DOM alone (frameworks). messages: texts of the live region with {label}, {pos}, {count}.

Wrappers: React <SortableList items onReorder renderItem getKey ordered arrows> (and moveItem(items, from, to)), Vue <OcSortableList v-model:items> with slot item, Blade <x-oc::sortable-list :items>. The list does not scroll its container while you drag: keep long lists short or use the arrow keys.

Browser support

Pointer events work with mouse, pen and touch in all current browsers.
