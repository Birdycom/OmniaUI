Static menu

The dropdown menu without a popover: it fills its box, so it can be a tray menu in its own small window or a menu inside a panel. Items can have a check column, a muted hint on the right, group titles and a red item. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-dropdown-menu--staticNo popover or position: the menu is shown and fills its container.
.oc-dropdown-menu--flatNo border, radius, shadow or background: the window around it is the frame.
.oc-dropdown-checkA 20px check column at the start of an item; shows ✓ when the item has aria-checked="true".
.oc-dropdown-hintMuted text on the right (a shortcut, a time).
.oc-dropdown-labelGroup title; small capitals in a static menu.
.oc-dropdown-item--destructiveRed item (Quit, Delete).

Give check items role="menuitemcheckbox" and toggle aria-checked in your code. React <MenuStatic> with <DropdownItem checked hint>, Vue <OcMenuStatic> with <OcDropdownItem :checked hint>, Blade <x-oc::menu-static>.
