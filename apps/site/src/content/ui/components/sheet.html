Sheet

A modal panel that slides in from an edge. Opens with invoker commands, closes with Esc, the close button or a click on the backdrop (closedby="any"). Also the mobile container for the sidebar. All components.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: header (title, description), body (default), footer, trigger button outside the dialog.

Class / attributeDescription
dialog.oc-sheetThe dialog. Side modifiers: --left, --top, --bottom (default right).
.oc-sheet-contentPanel. Modifier: --wide.
.oc-sheet-header / -title / -descriptionHeading area
.oc-sheet-bodyScrolling content
.oc-sheet-footerAction row
.oc-sheet-closeClose button (command="close")
