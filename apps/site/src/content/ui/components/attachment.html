Attachment

A file chip or an image preview for chat messages and composers. The icon tile shows the extension and is tinted per type (PDF, document, sheet, archive, image); the chip shows the name, the size and, in a composer, a remove button. Upload progress and errors are states on the same chip. Comes from the attachment picker of the Korrekt question chat. Install with npx omniaui add attachment. All components.

Accessibility and keyboard

  • A chip that opens or downloads the file is a link (<a href download>); in a composer it is a plain div with a remove <button>. The link and the button are separate tab stops.
  • The extension tile is decorative (aria-hidden="true"): the file name already says the type. Image previews need alt text.
  • Remove buttons need an aria-label with the file name ("Remove Floor plan kitchen.pdf"), so a list of them stays clear.
  • Put role="status" on the size text while uploading, so progress and errors are announced. The error state uses words as well as color.
