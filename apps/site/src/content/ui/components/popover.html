Popover

Free-form content in the top layer, tethered to its trigger. For lists of actions use the dropdown component. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/popover.html.

Click Dimensions: a small panel with fields opens next to the button. Escape or a click outside closes it.

Dimensions

Compound API, side and align v0.17.0

Leave out trigger and build the popover from parts: PopoverTrigger opens it (it is also the anchor), PopoverContent is the panel with side (top, right, bottom, left), align (start, center, end) and sideOffset, and PopoverAnchor positions the panel against another element. The open state can be controlled with open + onOpenChange (Vue v-model:open); Escape and a click outside report back. In the HTML, data-side and data-align set the position. Blade: <x-oc::popover id> with .trigger and .content; model ties the open state to a Livewire property.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-popover[popover]The panel. Sizes: --sm, --lg.
.oc-popover-title / -textOptional heading and body text
button[popovertarget]Trigger
[data-side] / [data-align]Position of the panel (0.17.0): top, right, bottom (default), left; start (default), center, end. --oc-popover-offset sets the gap (default 4px). Styles in parts/app-compound-overlays.css.
React PopoverTrigger, PopoverContent, PopoverAnchor, PopoverCloseCompound popover (0.17.0) inside <Popover> without trigger: open / defaultOpen / onOpenChange on the root, asChild on trigger and anchor, side, align, sideOffset on the content. The anchor uses CSS anchor positioning (anchor-name / position-anchor), with a measured fallback in browsers without it. Vue: OcPopoverTrigger, OcPopoverContent, OcPopoverAnchor in OcPopover (v-model:open). Blade: <x-oc::popover.trigger> and .content (side, align, offset), model on the root for Livewire.
