Demo panel

Demo panel: the frame every example on this site lives in. A live preview on top, the code below, or both behind tabs. .oc-demo works without any build step; the docs build only fills in the code block for you. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/demo-panel.html.

<button class="oc-btn">Save</button>
<button class="oc-btn oc-btn--outline">Cancel</button>

Reference

Styles live in packages/ui/src/docs-ui.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Stacked variant (what the docs use)

Without --tabs the panel shows Demo, the preview, Code and the code block under each other. On this site you write <oc-demo title="Buttons">...</oc-demo> and the build produces exactly this markup, generating the highlighted code from the preview when you do not provide it:

<div class="oc-demo"> <h4 class="oc-preview__title">Demo - Buttons</h4> <div class="oc-demo__preview">...live markup...</div> <h4 class="oc-preview__title">Code - Buttons</h4> <div class="oc-code-block">...</div> </div>

Anatomy

  • .oc-demo: bordered, softly tinted panel.
  • .oc-demo__preview: the stage, with the page background so the example is judged on a neutral surface. Items flow in a wrapping flex row; modifiers --tall (min-height 20rem, overflow visible for popovers) and --center.
  • .oc-demo__tablist + .oc-demo__tab: segmented control made of two radio inputs. The first radio shows the preview, the second shows .oc-demo__code. Selection is read with :has().

Accessibility and responsive behaviour

  • Radios are native: Arrow keys move between Preview and Code, Tab enters and leaves the group. The checked tab is marked with a surface and a shadow, not only color.
  • Both panels stay in the DOM, so the code can be selected and found with browser search only while visible; use the stacked variant when the code must always be reachable.
  • The preview scrolls horizontally when an example is wider than the panel instead of breaking the page.
