Link arrow

A text link with an arrow that slides on hover and keyboard focus. For "Read more", "All projects" or back links. The arrow is a CSS pseudo-element, so the link text stays clean. All components.

Demo

Hover or tab to the links. Snippet: packages/ui/snippets/link-arrow.html.

An arrow after the text that slides right on hover and focus.

.oc-link-arrow--back

.oc-link-arrow--external
An arrow up and to the right, for a link to another site.
