Copy field

For secrets, API keys and links. Copying needs one line of script (navigator.clipboard.writeText); the CSS provides the .is-copied state. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/copy-field.html.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-copy-fieldWrapper
.oc-copy-field-valueRead-only <input readonly> (or <output>)
.oc-copy-field-buttonCopy button; add .is-copied for 2s feedback

Optional script

The only behaviour that needs JavaScript. Drop it in once per page, or implement the same in your framework wrapper.

<script> document.addEventListener('click', async (e) => { const btn = e.target.closest('.oc-copy-field-button'); if (!btn) return; await navigator.clipboard.writeText(btn.parentElement.querySelector('.oc-copy-field-value').value); btn.classList.add('is-copied'); setTimeout(() => btn.classList.remove('is-copied'), 2000); }); </script>
