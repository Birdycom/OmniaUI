Link row

A row of links under a feature or product card: the docs, a store page, the source. Links to another site get an arrow by themselves, links to GitHub the GitHub mark, links on your own site no icon. Plain CSS. For one "Read more" link see the link arrow. All components.

Tones and sizes

--accent takes the color of an .oc-accent--* parent (as on the product cards), --muted is quieter; --sm and --lg set the size.

Reference

Styles live in packages/ui/src/parts/site-link-row.css. The icons are CSS masks in the text color.

Class / attributeDescription
.oc-link-rowA <ul> of links that wraps, in the primary color
a[href^="https://"]Gets the arrow: a link to another site
a[href*="github.com"]Gets the GitHub mark instead of the arrow
--accent / --mutedAccent of an .oc-accent--* parent / muted text that brightens on hover
--sm / --lgSizes

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <LinkRow tone="accent" links={[{ href: "/docs", label: "Docs" }, { href: "https://github.com/acme/app", label: "Source" }]} /> <!-- Vue --> <OcLinkRow :links="[{ href: '/docs', label: 'Docs' }, { href: 'https://github.com/acme/app', label: 'Source' }]" /> <!-- Blade --> <x-oc::link-row :links="[['href' => '/docs', 'label' => 'Docs'], ['href' => 'https://github.com/acme/app', 'label' => 'Source']]" />
