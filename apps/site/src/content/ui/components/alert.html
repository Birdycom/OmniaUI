Alert

A message in the flow of the page: info, success, warning or danger. Use role="status" for neutral news and role="alert" for errors that need attention now. For a message that floats over the page, use a toast. All components.

Demo

snippets/alert.html v0.4.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/alert.html.

Heads up!

You can add components with the OmniaUI CLI: npx omniaui add alert.

Variants

--info, --success, --warning and --danger color the border, the title and the background with theme tokens.

Inline v0.12.3

--inline is a short tinted message right under a field or a form: an error or a hint, without the box spacing. With --danger the text takes the danger color too.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-alertThe box. Modifiers: --info, --success, --warning, --danger.
--inlineCompact message under a field or form (smaller text and padding). Link it with aria-describedby.
.oc-alert-titleBold first line (any heading level that fits the page).
.oc-alert-descriptionThe message text.
role="status" / role="alert"Screen readers announce alert at once, status politely.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <Alert variant="success" title="Saved">Your changes have been saved.</Alert> <Alert variant="danger" inline role="alert">Enter an amount of 0 or more.</Alert> <!-- Vue --> <OcAlert variant="success" title="Saved">Your changes have been saved.</OcAlert> <OcAlert variant="danger" inline>Enter an amount of 0 or more.</OcAlert> <!-- Laravel Blade --> <x-oc::alert variant="success" title="Saved">Your changes have been saved.</x-oc::alert> <x-oc::alert variant="danger" inline>Enter an amount of 0 or more.</x-oc::alert>
