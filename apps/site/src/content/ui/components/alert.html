Alert

A message in the flow of the page: info, success, warning or danger. Use role="status" for neutral news and role="alert" for errors that need attention now. For a message that floats over the page, use a toast. All components.

Alarm: must be seen v0.17.0

For a message that someone has to see now, such as a team asking for help or a payment that failed. With data-state="new" it gets a thick edge in its tone and a slow pulsing ring, until someone presses Seen. Your app then sets data-state="seen": the alarm stays, but calm, until it is closed. Give a new alarm role="alert", so screen readers say it at once. .oc-alert-icon puts an icon in a soft circle on the left, and .oc-alert-actions puts the buttons on the right (under the text when there is no room). Press Seen on the first alarm. With reduced motion the ring stays still. Sound is up to your app: browsers only play it after the user has clicked something on the page.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-alert--alarm[data-state=new|seen]Urgent message: new = thick edge and a pulsing ring (role alert), seen = calm. React / Vue / Blade alarm
.oc-alert-icon / .oc-alert-body / .oc-alert-actionsIcon in a soft circle on the left, the text, buttons on the right. Prop icon, actions
.oc-alertThe box. Modifiers: --info, --success, --warning, --danger.
--inlineCompact message under a field or form (smaller text and padding). Link it with aria-describedby.
.oc-alert-titleBold first line (any heading level that fits the page).
.oc-alert-descriptionThe message text.
role="status" / role="alert"Screen readers announce alert at once, status politely.
