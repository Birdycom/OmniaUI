Stat card

A compact KPI tile for a dashboard strip: an icon tile, a big number and a small label, with an optional trend chip. Make the card an <a> to link to the list behind the number. All components.

Demo

Plain HTML and CSS; each example shows its markup in the HTML tab.

KPI row

.oc-stat-card-grid fits as many cards per row as there is room for (at least 12rem each). The third card is a link with --accent: "needs attention". Snippet: packages/ui/snippets/stat-card.html.

Tones and trends

--warning and --success recolor the icon tile; --stripe adds a colored start edge. Trend chips: --up (green) and --down (red). A <button> card works too, e.g. to set a filter.

41-8%New leads

Reference

Slots: icon, value, label, trend. Tone color: --oc-stat-card-color.

Class / attributeDescription
.oc-stat-card-gridResponsive grid for a row of cards
.oc-stat-cardCard (div, or a / button with hover lift)
.oc-stat-card--accent / --success / --warningTone (accent = needs attention)
.oc-stat-card--stripeColored start edge
.oc-stat-card-iconTinted icon tile
.oc-stat-card-body / -value / -labelText column, big number, label
.oc-stat-card-trend--up / --downTrend chip after the value

Browser support

Tints use relative color syntax (oklch(from ...)) on top of the theme tokens.
