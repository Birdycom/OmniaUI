Drawer

A bottom sheet on <dialog> with a drag-handle look, for mobile-style actions and forms. Opens with an invoker command, no JavaScript. On wide screens use --center for a centered panel. For side panels use the sheet. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/drawer.html.

Anatomy

  • Dialog dialog.oc-drawer fills the viewport in the top layer and aligns the panel to the bottom; the backdrop blurs the page.
  • Handle a purely visual bar that signals the panel is a sheet. Swipe-to-dismiss is not included (it needs pointer-event script); tap outside, Esc and buttons close it.
  • Entrance @starting-style slides the panel up on open.

Accessibility and keyboard

Accessibility

  • showModal() via command="show-modal" traps focus, makes the page inert and restores focus on close.
  • Label the dialog with aria-labelledby; keep the handle aria-hidden.
  • Provide a visible close/cancel button; closedby="any" adds tap-outside as a convenience.

Keyboard

  • Esc closes; Tab cycles inside the dialog.
