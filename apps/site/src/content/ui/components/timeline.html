Timeline

A vertical timeline for company history, release notes or a project log. Every entry gets a dot on the line; the latest one can be marked as current. Pure CSS, colors from the element accent. All components.

Plain HTML and CSS. Below each demo: the markup that builds it, also available as the snippet packages/ui/snippets/timeline.html.

Reference

Styles live in packages/ui/src/parts/site-timeline.css (on top of the base line in showcase.css). Slots: date, title, text per item.

Class / attributeDescription
.oc-timelineThe ol / ul with the vertical line. Modifiers: --lg (more space), --accent (accent line)
.oc-timeline__itemOne entry with a dot. Modifier --current: filled dot with a ring
.oc-timeline__dateYear or date (<time> for real dates)
.oc-timeline__title / __textEntry heading and description
<li><strong><span>Simple form without item classes (no dots)
.oc-accent--*Accent for the dots, dates and the accent line
