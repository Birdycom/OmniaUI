Toast

Notification cards stacked in a fixed corner container. Variants set the status color. .oc-toast--auto fades the toast out after --oc-toast-duration (default 6s) without JavaScript; a wrapper removes it from the DOM or on close. All components.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon, title, description, close.

Class / attributeDescription
.oc-toast-containerFixed stack (bottom right). Modifiers: --top, --static (in-flow, for docs).
.oc-toastOne notification (role="status"; use role="alert" for errors). Variants: --success, --error, --warning, --info. --auto = CSS auto-dismiss.
.oc-toast-iconStatus glyph
.oc-toast-bodyText column
.oc-toast-title / -descriptionHeading and optional text
.oc-toast-closeDismiss button
