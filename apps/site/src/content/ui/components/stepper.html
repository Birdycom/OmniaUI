Stepper

An ordered list of steps with automatic numbering. Completed steps show a check and stay clickable; upcoming steps are disabled. The active step has aria-current="step". All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/stepper.html.

import { useState } from "react"; import { Stepper } from "@birdycom/omniaui-react"; const steps = [ { label: "Company", meta: "1/4" }, { label: "Invoicing", meta: "2/4" }, { label: "Banking", meta: "3/4" }, { label: "Team", meta: "4/4" }, ]; export function Example() { const [current, setCurrent] = useState(1); // 0-based: earlier steps are done and clickable, later ones disabled return <Stepper aria-label="Setup steps" steps={steps} current={current} onStepChange={setCurrent} />; } <script setup lang="ts"> import { ref } from "vue"; import { OcStepper } from "@birdycom/omniaui-vue"; const steps = [ { label: "Company", meta: "1/4" }, { label: "Invoicing", meta: "2/4" }, { label: "Banking", meta: "3/4" }, { label: "Team", meta: "4/4" }, ]; const current = ref(1); // 0-based: earlier steps are done and clickable, later ones disabled </script> <template> <OcStepper v-model="current" label="Setup steps" :steps="steps" /> </template> {{-- current is 1-based; the "n/total" meta text is added for you --}} <x-oc::stepper label="Setup steps" :steps="['Company', 'Invoicing', 'Banking', 'Team']" :current="2" /> <?php namespace App\Livewire; use Livewire\Component; class SetupWizard extends Component { public array $steps = ['Company', 'Invoicing', 'Banking', 'Team']; public int $step = 2; // 1-based, earlier steps are done public function next(): void { $this->step = min($this->step + 1, count($this->steps)); } public function render() { return view('livewire.setup-wizard'); } } {{-- resources/views/livewire/setup-wizard.blade.php --}} <div> <x-oc::stepper label="Setup steps" :steps="$steps" :current="$step" /> {{-- … the form of the current step, whose submit calls next() --}} </div>

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

.oc-stepperol wrapper. Modifier: --horizontal.
