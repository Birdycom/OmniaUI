Stepper

An ordered list of steps with automatic numbering. Completed steps show a check and stay clickable; upcoming steps are disabled. The active step has aria-current="step". All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/stepper.html.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-stepperol wrapper. Modifier: --horizontal.
.oc-stepper-itemStep (button). Modifiers: --done, --active (or aria-current="step"); default = upcoming (add disabled).
.oc-stepper-labelStep title
.oc-stepper-metaOptional small text (e.g. 2/4)
