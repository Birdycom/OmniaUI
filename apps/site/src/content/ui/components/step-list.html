Step list

A compact numbered list of steps for inside a card or a disclosure: how to remove a finding, the steps per service, what a scan does. One row per step, the number on the left, the text on the right. Inside a severity card the numbers take its color. For the large process section of a website, use the steps in Showcase (.oc-steps). All components.

Reference

Styles live in packages/ui/src/parts/data-step-list.css.

Class / attributeDescription
ol.oc-step-listOne column, gap 0.6rem, 0.875rem text. Every li is a row: the number (a CSS counter, display font) on the left, the text on the right. Links and <strong> work in the text.
--oc-step-list-colorColor of the numbers. Default: the color of the severity card around it (--oc-severity-color), else primary.
.oc-step-list--smTighter rows (0.4rem) and 0.8125rem text, for a dense panel.
style="counter-reset: oc-step-list 3"Start at another number: the first step is then 4.

React <StepList items={[…]} size="sm" /> (or <li> children), Vue <OcStepList :items> (or the default slot), Blade <x-oc::step-list :items="[…]" /> (or the slot).
