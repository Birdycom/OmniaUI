Password input

Wrapper with an overlaid toggle button. The button flips the input type; the optional script below does that without a framework. Use aria-pressed for the state. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/password-input.html.

Click Show to read what you typed, Hide to cover it again. Flipping the input type needs the few lines of script in the HTML tab (the same as the optional script below).

const [password, setPassword] = useState(""); <FormField label="Password"> <PasswordInput autoComplete="current-password" value={password} onChange={(e) => setPassword(e.target.value)} /> </FormField> <script setup lang="ts"> import { ref } from 'vue' import { OcFormField, OcPasswordInput } from '@birdycom/omniaui-vue' const password = ref('') </script> <template> <OcFormField label="Password" v-slot="f"> <OcPasswordInput :id="f.id" v-model="password" autocomplete="current-password" /> </OcFormField> </template> <x-oc::password-input label="Password" id="password" name="password" autocomplete="current-password" /> <?php namespace App\Livewire; use Livewire\Attributes\Validate; use Livewire\Component; class PasswordField extends Component { #[Validate('required|min:8')] public string $password = ''; public function save(): void { $this->validate(); } public function render() { return view('livewire.password-field'); } } {{-- resources/views/livewire/password-field.blade.php --}} <form wire:submit="save"> <x-oc::password-input label="Password" id="password" wire:model="password" autocomplete="current-password" :error="$errors->has('password')" /> @error('password') <p class="oc-field-error">{{ $message }}</p> @enderror </form>

Optional script

The only behaviour that needs JavaScript. Drop it in once per page, or implement the same in your framework wrapper.

<script> document.addEventListener('click', (e) => { const btn = e.target.closest('.oc-input-reveal-button'); if (!btn) return; const input = btn.parentElement.querySelector('input'); const show = input.type === 'password'; input.type = show ? 'text' : 'password'; btn.setAttribute('aria-pressed', String(show)); btn.textContent = show ? 'Hide' : 'Show'; }); </script>
