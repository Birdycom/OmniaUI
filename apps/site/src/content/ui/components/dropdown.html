Dropdown

A menu that opens from a button. The recommended version needs no JavaScript: the menu is a native popover opened with popovertarget, closes on outside click or Esc, lives in the top layer (never clipped by a parent) and is placed next to its button with CSS anchor positioning.

Demo

Plain HTML and CSS; each example shows its markup in the HTML tab.

CSS-first dropdown (recommended)

Button with popovertarget="id" + <div class="oc-dropdown-menu" id="id" popover>. Items are links or buttons with .oc-dropdown-item; group them with .oc-dropdown-label and .oc-dropdown-separator.

Class toggle (for existing scripts) v0.17.0

If your app already toggles classes, wrap button + menu in .oc-dropdown and add .is-open. This menu is positioned inside the page, so give its container enough room (it is not in the top layer). The components do this with mode="toggle": React open / onOpenChange, Vue v-model:open, Blade open plus a small script (or :script="false" and trigger-attributes for Livewire). An item click, a click outside and Esc close it.

Radio group v0.17.2

One choice out of a few (sort by, density, view). Items get role="menuitemradio" and aria-checked; the checked one shows a dot. The group keeps the value: React DropdownRadioGroup value onValueChange + DropdownRadioItem value, Vue OcDropdownRadioGroup v-model + OcDropdownRadioItem, Blade <x-oc::dropdown.radio-group> with value and items (or .radio-item with :checked). Like check items, radio items keep the menu open (keepOpen={false} closes it). The older DropdownItem radio checked keeps working.

Side, align and your own trigger v0.18.0

side (top, right, bottom, left) and align (start, center, end) place the menu, like a popover: data-side and data-align on .oc-dropdown-menu (default bottom start; it still flips when there is no room, and the toggle mode uses fixed places). React triggerAsChild and Vue trigger-as-child put the wiring (popovertarget, or the toggle click) on your own trigger element instead of an outline button. React DropdownItem asChild and Vue OcDropdownItem as-child render your router link (or <a>) as the item, with the icon, description and hint around its text; a click closes the menu. Blade: side and align on <x-oc::dropdown>; a trigger slot is your own element with popovertarget, and <x-oc::dropdown.item href wire:navigate> is already a link.

Blade: your own trigger v0.18.0

React triggerAsChild and Vue trigger-as-child add popovertarget to your trigger element for you. Blade cannot: the trigger slot reaches <x-oc::dropdown> as finished HTML, so the component prints it as it is and adds or merges nothing. Without an id the menu also gets a new random id (oc-menu- and six characters) on every render, which your button cannot know. So give the dropdown a fixed id and put the same value in popovertarget on your own button (in a loop: one id per row, such as customer-menu-1, customer-menu-2; see the Livewire tab). With Livewire a fixed id also stays the same on every re-render.

mode="toggle" has no popover and needs no popovertarget: a click on any <button> outside the menu toggles .is-open. Give your button aria-expanded="false" and aria-controls so the script keeps aria-expanded up to date; with :script="false" put wire:click on your own button (trigger-attributes only reaches the default button).
