Dropdown

A menu that opens from a button. The recommended version needs no JavaScript: the menu is a native popover opened with popovertarget, closes on outside click or Esc, lives in the top layer (never clipped by a parent) and is placed next to its button with CSS anchor positioning.

Demo

Plain HTML and CSS; each example shows its markup in the HTML tab.

CSS-first dropdown (recommended)

Button with popovertarget="id" + <div class="oc-dropdown-menu" id="id" popover>. Items are links or buttons with .oc-dropdown-item; group them with .oc-dropdown-label and .oc-dropdown-separator.

Class toggle (for existing scripts)

If your app already toggles classes, wrap button + menu in .oc-dropdown and add .is-open. This menu is positioned inside the page, so give its container enough room (it is not in the top layer).

My Account
<div class="oc-dropdown"> <button class="oc-btn oc-btn--outline">Options</button> <div class="oc-dropdown-menu">…</div> </div> <!-- your script: dropdown.classList.toggle("is-open") -->

Reference

Styles live in packages/ui/src/components-extra.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription

popovertargetOn the button: opens/closes the menu with that id
.oc-dropdown-itemMenu item (link or button)
.oc-dropdown-labelSmall group heading
.oc-dropdown-separatorDivider line
