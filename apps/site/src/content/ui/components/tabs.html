Tabs

Switch between panels without JavaScript. A hidden radio input in every tab holds the state and :has() shows the panel at the same position, so the browser handles clicks, keyboard (arrow keys) and form state. Line tabs by default, with pill and vertical variants. All components.

Class-toggle tabs (for existing scripts) v0.17.0

When a script already manages the state, use buttons with role="tab" and set aria-selected="true" (or .is-active) on the active tab and .is-active on its panel. Compound API v0.17.0

Build the tabs from parts instead of a tabs array: TabsList, TabsTrigger and TabsContent in React (OcTabsList, OcTabsTrigger, OcTabsContent in Vue, <x-oc::tabs.list>, .trigger, .content in Blade). Leave out tabs and the root switches to this mode. The value is controlled with value + onValueChange (Vue v-model, Blade active); arrow keys, Home and End move between the enabled tabs. Underneath it is the class-toggle markup above, so panels can hold anything, including forms. In Livewire, wire:model on <x-oc::tabs> makes every trigger set the property.

Framework wrappers

By default all three render the CSS-only tab set (radio inputs), so tabs also work before JavaScript has loaded. With mode="buttons" they render the class-toggle tabs.

<!-- React (variant: pill or vertical; mode="buttons": class-toggle tabs; items take icon, count, countTone, disabled) --> <Tabs name="account" tabs={[{ value: "account", label: "Account", content: <AccountForm /> }, { value: "password", label: "Password", content: <PasswordForm /> }]} /> <!-- Vue: one named slot per tab value --> <OcTabs name="account" :tabs="[{ label: 'Account', value: 'account' }, { label: 'Password', value: 'password' }]"> <template #account>…</template> <template #password>…</template> </OcTabs> <!-- Laravel Blade (variant: pill or vertical; mode="buttons" + /js/oc-tabs.js; a tab may be [label, icon, count, tone, disabled]) --> <x-oc::tabs name="account" :tabs="['Account', 'Password']" variant="pill"> <x-oc::tabs.panel>…</x-oc::tabs.panel> <x-oc::tabs.panel>…</x-oc::tabs.panel> </x-oc::tabs> <!-- Compound (0.17.0): leave out tabs; value / onValueChange (Vue v-model, Blade active + model / wire:model) --> <Tabs value={tab} onValueChange={setTab}><TabsList><TabsTrigger value="a">A</TabsTrigger></TabsList><TabsContent value="a">…</TabsContent></Tabs> <OcTabs v-model="tab"><OcTabsList><OcTabsTrigger value="a">A</OcTabsTrigger></OcTabsList><OcTabsContent value="a">…</OcTabsContent></OcTabs> <x-oc::tabs name="t" active="a"><x-oc::tabs.list><x-oc::tabs.trigger value="a">A</x-oc::tabs.trigger></x-oc::tabs.list><x-oc::tabs.content value="a">…</x-oc::tabs.content></x-oc::tabs>
