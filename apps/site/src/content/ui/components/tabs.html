Tabs

Switch between panels without JavaScript. A hidden radio input in every tab holds the state and :has() shows the panel at the same position, so the browser handles clicks, keyboard (arrow keys) and form state. Line tabs by default, with pill and vertical variants. All components.

Class-toggle tabs (for existing scripts)

When a script already manages the state, use buttons with role="tab" and set aria-selected="true" (or .is-active) on the active tab and .is-active on its panel. The small script below does exactly that; the same classes work with .oc-tab-list--pill.

 <script> // Tabs with data-oc-tabs: a click selects the tab and shows the panel named in aria-controls. document.addEventListener('click', (e) => { const tab = e.target.closest('[data-oc-tabs] [role="tab"]'); if (!tab || tab.disabled) return; for (const other of tab.parentElement.querySelectorAll('[role="tab"]')) { const on = other === tab; other.setAttribute('aria-selected', String(on)); document.getElementById(other.getAttribute('aria-controls'))?.classList.toggle('is-active', on); } }); </script>

Styles live in packages/ui/src/components.css. The CSS-only version supports up to six tabs per set.

.oc-tabsetWrapper of the CSS-only tabs: the tab list first, then one .oc-tab-panel per tab in the same order.
.oc-tab-listRow of tabs (role="tablist"). Modifiers: --pill, --vertical.

.oc-tab-panelA panel. In .oc-tabset the panel at the position of the checked tab shows.

Framework wrappers

All three render the CSS-only tab set (radio inputs), so tabs also work before JavaScript has loaded.

<!-- React --> <Tabs name="account" tabs={[{ value: "account", label: "Account", content: <AccountForm /> }, { value: "password", label: "Password", content: <PasswordForm /> }]} /> <!-- Vue: one named slot per tab value --> <OcTabs name="account" :tabs="[{ label: 'Account', value: 'account' }, { label: 'Password', value: 'password' }]"> <template #account>…</template> <template #password>…</template> </OcTabs> <!-- Laravel Blade (variant: pill or vertical) --> <x-oc::tabs name="account" :tabs="['Account', 'Password']" variant="pill"> <x-oc::tabs.panel>…</x-oc::tabs.panel> <x-oc::tabs.panel>…</x-oc::tabs.panel> </x-oc::tabs>
