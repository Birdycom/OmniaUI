Menubar

A horizontal bar of menus (File, Edit, View). Each trigger is a button with popovertarget; each menu is the regular dropdown menu, so sub-menus, check items and shortcuts work unchanged. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/menubar.html.

Reference

Styles live in packages/ui/src/components-extra.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Anatomy

  • Bar .oc-menubar: bordered flex row; triggers highlight while their popover is open (:has(+ :popover-open)).
  • Trigger a button whose popovertarget points to the menu. The menu is anchored to it by the invoker relationship.
  • Menus are the dropdown-menu panels; the browser provides light dismiss and Esc.

Accessibility and keyboard

Accessibility

  • Roles: menubar > menuitem triggers with aria-haspopup="menu"; the menus use role="menu".
  • Native popover gives focus return and light dismiss. The full ARIA menubar pattern (arrow keys between menus and items, hover-to-switch) is wrapper responsibility: a ~30 line script or the Vue/React/Blade wrappers.

Keyboard

  • Tab and Enter/Space open a menu; Esc closes it and returns focus.
  • With the optional script: ←/→ switch menus, ↓/↑ move through items, letters jump to an item.
