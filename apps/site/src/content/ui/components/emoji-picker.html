Emoji picker

A compact grid of emoji buttons in a popover that floats above its trigger. Opening, closing, Esc and click-outside come from the popover attribute; anchor positioning keeps it next to the button. A small optional script inserts the emoji into a field. Pairs with the Chat composer. All components.

Inline panel

.oc-emoji-picker--inline without the popover attribute: the same grid, always visible (a reaction bar, a settings field).

How it works

  • Popover: the trigger has popovertarget; the panel has popover. That gives open / close, Esc and light dismiss without a script.
  • Position: the trigger is the implicit anchor, position-area: block-start span-inline-end puts the panel above it and position-try-fallbacks flips it when there is no room. Browsers without anchor positioning center the popover.
  • Inserting text is script work: the optional handler uses setRangeText() at the cursor and fires an input event, so framework bindings see the change.
  • The groups have sticky labels while the panel scrolls.

Accessibility and keyboard

  • Every emoji is a real <button>: Tab walks the grid, Enter / Space picks. Screen readers announce the emoji name ("thumbs up").
  • The trigger needs an aria-label ("Insert emoji"); the panel an aria-label too.
  • The open animation and hover scale only run under prefers-reduced-motion: no-preference.
