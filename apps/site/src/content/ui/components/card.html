Card

A surface that groups related content: a header with title and description, the content and a footer with actions. Every part is optional. Use .oc-card--sm for compact cards in lists and dashboards.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-card-background, --oc-card-foreground, --oc-card-border), so everything follows light and dark mode.

ClassDescription
.oc-cardThe surface: background, border and radius.
.oc-card--smCompact: less padding in header, content and footer.
.oc-card-headerTitle and description, stacked.
.oc-card-titleThe heading (any heading level that fits the page).
.oc-card-descriptionMuted line under the title.
.oc-card-actionInside the header: placed in the top-right corner.
.oc-card-contentThe body.
.oc-card-footerActions in a row.
.oc-card-link / .oc-card-textA text link in the primary color / muted body text.

Framework wrappers

React exports one component per part; Vue and Blade take title, description and size props with a footer slot.

<!-- React --> <Card> <CardHeader><CardTitle>Create project</CardTitle><CardDescription>Deploy in one click.</CardDescription></CardHeader> <CardContent>…</CardContent> <CardFooter><button className="oc-btn">Deploy</button></CardFooter> </Card> <!-- Vue --> <OcCard title="Create project" description="Deploy in one click."> … <template #footer><button class="oc-btn">Deploy</button></template> </OcCard> <!-- Laravel Blade --> <x-oc::card title="Create project" description="Deploy in one click." size="sm"> … <x-slot:footer><button class="oc-btn">Deploy</button></x-slot:footer> </x-oc::card>
