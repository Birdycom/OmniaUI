Reference

Class Description
.oc-card Card wrapper
.oc-card--sm Compact card with less padding
.oc-card-header Header area (title + description)
.oc-card-title Card heading
.oc-card-description Muted subtitle text
.oc-card-action Positioned top-right action (absolute)
.oc-card-content Main body content
.oc-card-footer Bottom action area
