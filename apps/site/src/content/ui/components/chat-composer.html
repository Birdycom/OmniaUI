Chat composer

The message box of a chat: a textarea that grows while you type, a row of tool buttons and a round send button, all in one rounded frame with a focus ring. The send button dims itself while the field is empty, with CSS only. Add an Emoji picker to the tools. All components.

How it works

  • Growing field: field-sizing: content with a max-block-size. Browsers without it keep the rows height and scroll.
  • Empty state: .oc-chat-composer:has(.oc-chat-composer__input:placeholder-shown) dims the send button. This needs a placeholder. required on the textarea stops an empty submit by keyboard.
  • Focus: :focus-within draws the ring on the whole frame, not on the bare textarea.
  • Enter to send is app logic: listen for Enter without Shift and call form.requestSubmit().

Accessibility and keyboard

  • Give the textarea a label; .oc-visually-hidden keeps it for screen readers only.
  • Icon buttons need an aria-label ("Attach a file", "Send").
  • The send button is a real type="submit" button, so the form also works without script.
