Version banner

A small "new version available - reload" chip, for single-page apps that keep running an old build in an open tab. The reload is a plain link with href="", which loads the current page again. All components.

In the app header

CSS component parts/app-version-banner.css

Place it at the end of the header or breadcrumb row. Below 40rem the long text is replaced by the short one. It has role="status", so screen readers announce it when it appears. Snippet: packages/ui/snippets/version-banner.html.

When to show it

Keep the chip hidden by default. Your app compares its own build number with a small version.json on the server (every few minutes or when the tab gets focus) and removes hidden when they differ. The React and Vue wrappers take a version prop and render nothing when it is empty.
