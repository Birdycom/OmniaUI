Collapsible section

A native <details> that looks like a card. Use open for the default state. Unlike the accordion, sections are independent. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/collapsible.html.

General information

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon, title (summary), content (default).

Class / attributeDescription
details.oc-collapsibleRoot. Modifier: --dense (compact paddings).
summaryHeader row with .oc-collapsible-icon + .oc-collapsible-title; the chevron is CSS
.oc-collapsible-contentBody with a top border
