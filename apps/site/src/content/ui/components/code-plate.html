Code plate

A QR code or a barcode on its own white plate, with a caption on the plate. The plate is always light, so the code scans in either theme and prints well, and the caption travels with the code onto a photo, a screenshot or paper. Put any code inside: an <img> or <svg> from your QR library, or the OmniaUI barcode. All components.

Demo

snippets/code-plate.html v0.16.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/code-plate.html.

The plate is always white with a dark code (color-scheme: light), so phones scan it in the light and the dark theme. The caption sits on the plate itself: on a photo, a screenshot or a print of only the code, the label is still there. Switch the theme of this page: the plates stay the same. The last one is the small size for a list.

Reference

Styles live in packages/ui/src/parts/app-mode-badge.css. The plate uses fixed palette colors (white plate, dark text); the caption takes the mode colors --oc-mode-test / --oc-mode-live.

Class / attributeDescription
figure.oc-code-plateThe white plate, always light (color-scheme: light). Set its width; the code inside fills it.
.oc-code-plate__captionThe caption under the code, on the plate: uppercase, bold, centred
data-mode="test | live | both"The caption in the mode colors; both takes two spans in the caption
--smSmall plate for a code of about 72 to 96px (a list of codes)
@media printThe caption colors are printed (print-color-adjust: exact)

Accessibility

  • Give the code image an alt that says what it opens, including the mode ("QR code to join the test round").
  • The caption is real text; keep it short (one or two words), it does not wrap.

Framework wrappers

The code goes in as children (a slot in Vue and Blade). caption, mode (test, live, both: without a caption, both shows the two words), size="sm".

<!-- React --> <CodePlate mode="live" caption="Live"><img src={qr} alt="QR code to join the live round" /></CodePlate> <!-- Vue --> <OcCodePlate mode="both"><img :src="qr" alt="QR code to join Company 1" /></OcCodePlate> <!-- Laravel Blade --> <x-oc::code-plate mode="test" caption="Test"><img src="{{ $qr }}" alt="QR code to join the test round"></x-oc::code-plate>
