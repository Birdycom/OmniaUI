Spec list

The specifications of a product in groups (dimensions, electrical, package …): a label and a value per row, digits in columns. Two columns of groups when the list is wide enough, one with --stack. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-spec-listThe list (a container): groups side by side from 40rem wide. --stack keeps one column.
.oc-spec-group / __titleA group and its title (small caps, an optional icon).
dl.oc-spec-group__rows > .oc-spec-rowThe rows: a <div> with <dt> (label) and <dd> (value; a <small> inside is a quiet unit or note).
