Tooltip

A short hint that appears above an element on hover and on keyboard focus. The text comes from the data-tooltip attribute and CSS draws it; no JavaScript. Keep it short and never put essential information only in a tooltip (touch screens have no hover). For richer content, use a hover card or a popover. All components.

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/tooltip.html.

Icon buttons

The most common use: explain an icon-only button. The button keeps its own aria-label for screen readers.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-tooltipWrapper around the element that gets the hint.
data-tooltip="…"The hint text, drawn above the element on :hover and :focus-within.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <Tooltip content="Saved to your library"><Button variant="outline">Hover me</Button></Tooltip> <!-- Vue --> <OcTooltip text="Saved to your library"><OcButton variant="outline">Hover me</OcButton></OcTooltip> <!-- Laravel Blade --> <x-oc::tooltip text="Saved to your library"><x-oc::button variant="outline">Hover me</x-oc::button></x-oc::tooltip>
