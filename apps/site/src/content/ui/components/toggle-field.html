Toggle field

A settings row: title, description and a switch. The whole row is a <label>, so clicking the text flips the switch. Inside it, the switch is a <span class="oc-switch">, because a label inside a label is not valid HTML. No JavaScript. All components.

Demo

snippets/toggle-field.html v0.6.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/toggle-field.html.

Card, reverse and disabled

--card draws a box whose border turns primary while on. --reverse puts the switch first (here together with --card). A disabled switch dims the row.

Reference

Styles live in packages/ui/src/parts/forms-toggle-field.css; the switch itself comes from components.css.

Class / attributeDescription
.oc-toggle-fieldThe row (a <label>). Modifiers: --card, --reverse.
.oc-toggle-field-textText block
.oc-toggle-field-labelTitle
.oc-toggle-field-descriptionMuted help text; link it with aria-describedby
span.oc-switchThe switch (checkbox with role="switch" + .oc-switch-track)

Framework wrappers

The wrappers link the description with aria-describedby for you.

<!-- React --> <ToggleField label="Email notifications" description="Get a message..." checked={on} onChange={(e) => setOn(e.target.checked)} /> <!-- Vue --> <OcToggleField v-model="on" label="Email notifications" description="Get a message..." card /> <!-- Laravel Blade --> <x-oc::toggle-field name="notify" label="Email notifications" description="Get a message..." checked />
