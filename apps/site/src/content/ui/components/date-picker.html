Date picker

A button that opens a calendar in a popover and shows the chosen date. Zero-JavaScript alternative: a native date input with the themed .oc-input. The popover gives top layer, light dismiss and Esc; the date logic is yours. The demo includes a small script that renders the month, steps months, picks a day and handles the calendar keys. All components.

Anatomy

  • Trigger an outline button; show the selected date (or a placeholder with data-empty).
  • Panel the popover component with --calendar, so the calendar is the panel.
  • Native option input[type=date] uses the platform picker; it inherits color-scheme, so text and picker follow the page theme.

Accessibility and keyboard

Accessibility

  • The popover content is a dialog-like widget: set aria-haspopup="dialog" on the trigger and label the calendar.
  • Always offer typing a date (an input) for users who do not want to pick from a grid.

Keyboard

  • Enter opens, Esc closes and returns focus; calendar keys as on the calendar page.
