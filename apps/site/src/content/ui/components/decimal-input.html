Decimal input

A text field for numbers written the local way, like 1.234,56. type="number" does not accept thousands separators, so this uses type="text" with inputmode="decimal" (numeric keyboard) and a pattern. The React and Vue wrappers format the value on blur with Intl.NumberFormat and give you a real number. All components.

With a unit, and invalid

.oc-decimal-field puts a unit inside the frame. Type letters in the second field and leave it: the pattern check marks it red.

Reference

Styles live in packages/ui/src/parts/forms-decimal-input.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-decimal-inputAdd to .oc-input: right-aligned tabular digits. Modifier: --start.
.oc-decimal-fieldOptional frame around the input and a unit
.oc-decimal-field-unitUnit text after the value
pattern[0-9.]*(,[0-9]{1,2})? for comma decimals; swap . and , for dot decimals

Framework wrappers

The value is a number (or null when empty). locale and decimals control the display.

<!-- React --> <DecimalInput value={amount} onValueChange={setAmount} locale="nl-BE" decimals={2} unit="m²" /> <!-- Vue --> <OcDecimalInput v-model="amount" locale="nl-BE" :decimals="2" /> <!-- Laravel Blade --> <x-oc::decimal-input name="amount" value="1.234,56" unit="m²" />
