Avatar

A round picture of a person or company: initials, or a photo with an alt text. Four sizes and an overlapping group for teams. All components.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

Class / attributeDescription
.oc-avatarThe circle. Holds initials or an <img> (cropped with object-fit: cover). Modifiers: --sm, --lg, --xl.
.oc-avatar-groupOverlapping row of avatars.
img[alt]Give a photo an alt with the name; initials need none.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <Avatar size="lg" src="/team/serge.jpg" alt="Serge Cools" /> <!-- Vue --> <OcAvatar size="lg">SC</OcAvatar> <!-- Laravel Blade --> <x-oc::avatar size="lg" :src="$user->photo_url" :alt="$user->name">{{ $user->initials }}</x-oc::avatar>
