Accordion accent

A variant of the accordion: every item becomes its own card with a colored edge at the start. Add .oc-accordion--accent to the accordion. Items stay native <details>, so it still needs no JavaScript. All components.

Accent cards

CSS variant parts/app-accordion-accent.css

The first item uses the default primary accent. The second uses the existing .oc-accent--violet preset. The third uses the semantic .oc-accordion-item--warning. The open item gets a tinted head. Snippet: packages/ui/snippets/accordion-accent.html.

One color for all items, flush

Put a preset (.oc-accent--green, --cyan, --orange, ...) or .oc-accordion--success / --warning / --danger on the accordion to color every item. With --flush only the accent edge stays. Any Omnia token works through --oc-accordion-accent.

Reference

Uses the accordion markup unchanged. Also works with the older .is-open / aria-expanded script hooks.

Class / attributeDescription
.oc-accordion--accentSeparate item cards with a 3px colored start edge
.oc-accent--blue / cyan / green / orange / red / violet / yellowColor preset on the accordion or one item
.oc-accordion-item--success / --warning / --dangerSemantic color for one item
.oc-accordion--success / --warning / --dangerSemantic color for all items
--oc-accordion-accentCustom property: any Omnia color token
.oc-accordion-accent-metaSmall accent-colored label at the end of the trigger

Browser support

Same as the accordion; the tints use relative color syntax.
