Reading

A small measured value (57 °C, 1.2 GHz) in tabular numbers, as a pill next to another value. The level colors it: cool (muted), warm (warning) or hot (destructive). Your code picks the level, for example warm from 70 °C and hot from 85 °C. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-readingThe pill: small, bold, tabular numbers, muted by default.
.oc-reading--cool / --warm / --hotMuted, warning or destructive color.
--oc-reading-colorAny other color token.
.oc-meter-row__value .oc-readingInside the value of a meter row it gets a little room on its left.

React <Reading level="warm">, Vue <OcReading level="warm">, Blade <x-oc::reading level="warm">.
