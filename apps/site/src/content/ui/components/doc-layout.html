Document layout

For a privacy policy, terms of use or a manual: a table of contents in a side column next to the text. From 64rem the column is sticky and stops under the sticky site header; on a phone it stacks above the text and scrolls away with it. A link in the table of contents jumps to its heading without hiding it under the header. All components.

Sticky offset

--oc-sticky-offset is where sticky parts stop: .oc-doc-layout__aside, .oc-toc and .oc-page-header--sticky. It is also the scroll padding of the page, so a heading you jump to stays clear of the header. With an .oc-site-header outside <main> it follows the header on its own: --oc-site-header-height (4.5rem) plus 1rem. Another header: set it yourself.

:root { --oc-sticky-offset: 5rem; }  /* your own header of 4rem + 1rem air */
.oc-site-header { --oc-site-header-height: 5rem; }  /* only when your .oc-site-header is taller */

Current heading in every browser

The table of contents highlights the heading you are reading with :target-current, without a script. Browsers that do not have it yet get the same highlight from toc.js: it does nothing where :target-current works, and elsewhere puts aria-current="true" on the link of the last heading above 35% of the window (data-oc-toc-line="0.25" on the .oc-toc moves that line). In every browser it also scrolls a table of contents that is taller than its column, so the current link stays in view.

npx omniaui copy-js toc
<script type="module" src="/js/oc-toc.js"></script>

// or in a bundle
import { initToc } from "@birdycom/omniaui/toc.js";
initToc(document);

Reference

Styles live in packages/ui/src/parts/site-doc-layout.css, docs-ui.css (table of contents) and parts/site-prose.css.

Class / attributeDescription
.oc-doc-layoutGrid of the side column (--oc-doc-aside, 17rem) and the text; stacked below 64rem with the side column first. Gap --oc-doc-gap (2rem 4rem).
.oc-doc-layout--endSide column on the right on a wide screen (still first on a phone).
.oc-doc-layout__asideSide column: from 64rem sticky at --oc-sticky-offset, at most the window height minus the offset, scrolls itself. A .oc-toc inside it is not sticky itself.
.oc-doc-layout__mainThe text column (min-inline-size: 0, so wide tables and code scroll inside it).
--oc-sticky-offsetWhere sticky parts stop, and the scroll padding of the page. Default 0, or the site header height + 1rem.
.oc-toc-group-labelLabel above a group of links: a <p> between two .oc-toc-lists, or an <li> inside one list. The whole .oc-toc is one scroll-target group, so only one link lights up.
.oc-prose--ruledA line under every h2 of the prose.
toc.js (oc-toc.js)initToc(scope): aria-current on the link of the current heading where :target-current is missing, and the current link kept in view in a long table of contents.
