Gallery

One large photo and thumbnails to switch, as on a product page. Every thumbnail is a label with a radio, so clicks, arrow keys and screen readers work without a script; :has() shows the photo at the same position (up to eight). All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-galleryThe gallery (a container): __stage with one figure.oc-gallery__slide per photo, then __thumbs.
fieldset.oc-gallery__thumbsThe thumbnails: one label.oc-gallery__thumb per photo with a radio (same name) and an image with alt text. The first photo shows when none is checked.
.oc-gallery__badgeA badge on the photo ("-20%", "New").
.oc-gallery--sideThumbnails in a column on the left once the gallery is 32rem wide or more.
--oc-gallery-ratio / --oc-gallery-fit / --oc-gallery-thumbPhoto ratio (default 4 / 3), contain or cover, thumbnail size (4rem).

Use your own images; give each thumbnail a short alt text, it is the name of the radio.
