Toast stack

A stacking variant of the toast: notifications overlap with the newest in front and older ones peeking out above; hovering or focusing the stack expands it into a list. Pure CSS, driven by :nth-last-child(). All components.

Anatomy

  • Stack the container becomes a one-cell grid; every toast sits in the same cell and is offset with translate, scale and opacity from --oc-stack-depth.
  • Expand :hover and :focus-within switch the container to a column; buried toasts become readable and clickable.
  • Order append new toasts at the end of the container: :nth-last-child(1) is the front.

Accessibility and keyboard

Accessibility

  • Each toast keeps role="status" (or alert for errors) so new ones are announced when added.
  • Buried toasts hide their content visually and from pointer events until the stack is hovered or focused; keep the container focusable (tabindex="0") so keyboard users can expand it.
  • Motion is disabled with prefers-reduced-motion. Do not auto-dismiss messages users must read.

Keyboard

  • Tab into the stack expands it; the dismiss button is a normal button.
