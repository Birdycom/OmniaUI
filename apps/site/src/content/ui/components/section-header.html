Section header

Header for a content section: a title with optional badges (source, SCSS file, page file, version) on one row and a short description below. A CSS grid keeps the badges next to the title and the version badge at the far right. Every section of these docs uses it.

Demo

Plain HTML and CSS. Put a heading with .oc-section-header__title, the badges you need and a .oc-section-header__desc paragraph inside one div.oc-section-header. Badges you leave out simply take no space.

Justify Content

CSS class _alignment.scss justify-content.html v0.2.0

Aligns flex or grid items along the main axis. Generated from the $justifycontent map as .justify-{key}.

ClassDescription
.oc-section-headerGrid wrapper: row 1 = title + badges, row 2 = description
.oc-section-header__titleTitle (any heading level)
.oc-section-header__badge-source + .oc-badge-sourceSource badge (cyan), e.g. "CSS class"
.oc-section-header__badge-scss + .oc-badge-source-scssSCSS file badge (orange)
.oc-section-header__badge-file + .oc-badge-source-filePage / file badge (magenta)
.oc-section-header__badge-version + .oc-badge-versionVersion badge (green), always at the right
.oc-section-header__descDescription below the title row
.oc-docs-section / .oc-section-contentSection card and its body
