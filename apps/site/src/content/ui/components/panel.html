Panel

A panel frames one important part of a page: a contact form, a call to action, a feature with a list. It has the card background, the strong border and a large radius, and keeps room above it when a link jumps to it (#form). --glow adds a soft radial light in a corner. All components.

Reference

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
.oc-panelThe panel: padding clamp(1.5rem, 4vw, 2.5rem) (--oc-panel-padding), --oc-border-strong, radius 1.2 × --oc-radius-lg, scroll-margin-top from --oc-scroll-offset (6rem).
.oc-panel--glowA soft light in the top start corner in --oc-panel-glow-color (brand 1); --oc-panel-glow-at moves it.
.oc-panel--glow-endThe light in the top end corner.
.oc-panel--glow-bothTwo lights: brand 1 top start and brand 3 bottom end (call to action).

The contact form block puts its form in a panel with a glow.
