Top progress

A thin loading bar at the very top of the window, on a native <progress> element. Without a value it is indeterminate (a sliding segment); with value and max it fills up. All components.

Demo

Plain HTML and CSS; each example shows its markup in the HTML tab.

Indeterminate and determinate

In a real page the bar is fixed to the top of the window. These demos add --static, so the bar stays inside the preview. Snippet: packages/ui/snippets/top-progress.html.

Colors and size

Tone modifiers use the theme tokens. --lg makes the bar 4px high. You can also set --oc-top-progress-color to any Omnia color token.

Usage in an app

Put one bar at the start of <body> with the hidden attribute. Remove hidden when a page load or request starts, add .is-done when it ends (the bar fades out), then set hidden again. The React and Vue wrappers do this with a single active prop.

<progress class="oc-top-progress" aria-label="Loading page" hidden></progress>

Reference

Custom properties: --oc-top-progress-color, --oc-top-progress-height. Give the bar an aria-label.

Class / attributeDescription
progress.oc-top-progressBar fixed to the top of the window. No value = indeterminate
value + maxDeterminate fill
.oc-top-progress--success / --warning / --danger / --brandColor
.oc-top-progress--lg4px instead of 3px
.oc-top-progress--staticIn the normal flow (inside a card, header or demo)
.is-done / hiddenFade out / remove

Browser support

The progress element and :indeterminate work everywhere. With reduced motion the slide runs slower.
