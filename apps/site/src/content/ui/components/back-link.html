Back with a fallback v0.17.0

A detail page is often opened from a filtered list, but also from a bookmark or a mail. With a fallback the link goes back in the history when the visitor came from this site (same-origin referrer, or more than one history entry), so the filters and the scroll position stay. Otherwise it follows the fallback address and can show a fuller label. React and Vue do it themselves; plain HTML and Blade need oc-back-link.js (npx omniaui copy-js). Left: came from the list. Right: opened directly.

Your own back action and router link v0.18.0

React onBack: a plain click runs your own back action (close a panel, navigate(-1)) instead of following the link; Ctrl/Cmd/Shift and middle click still open the href in a new tab. as renders your router link with the back-link classes (to and other props fall through). Vue: @back and as (RouterLink). Plain HTML and Blade: with oc-back-link.js a click on a [data-oc-back] link first fires a cancelable oc-back event; call preventDefault() in a listener to run your own action.

Blade has no callback prop. A Blade component is rendered on the server and cannot hold a JavaScript function, so <x-oc::back-link> has no onBack. Listen for the oc-back event instead: with Alpine (included in Livewire) x-on:oc-back.prevent="panelOpen = false" cancels the navigation and runs your expression (see the Blade tab). The event only fires on a link with fallback-href (that adds data-oc-back) and with oc-back-link.js on the page. In Livewire you can also skip the event and put wire:click.prevent on a plain link, as in the Livewire tab.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-back-linkAnchor styled as an outline button with a leading arrow
[data-oc-back]With oc-back-link.js: a click goes back in the history when the visitor came from this site; otherwise the link follows its href (the fallback). Ctrl/Cmd-click still opens the href in a new tab. React and Vue: fallbackHref; Blade: fallback-href.
data-oc-fallback-labelThe label while the link goes to the fallback (e.g. "Back to Products" where the history label is "Back"). React and Vue: fallbackLabel; Blade: fallback-label.
oc-back event With oc-back-link.js: fired (bubbling, cancelable) on a plain click of a [data-oc-back] link; preventDefault() replaces the navigation with your own action. React: onBack; Vue: @back.
as React and Vue: render your router link (Link, RouterLink) with the back-link classes; to and other props fall through.
