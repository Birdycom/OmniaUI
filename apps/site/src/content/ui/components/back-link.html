Back link

A link that says where it goes. The arrow comes from CSS; the label is yours. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/back-link.html.

A link back to the list a detail page came from. Hover it or Tab to it: the background and the focus ring show it is a link. In this preview it goes nowhere.
