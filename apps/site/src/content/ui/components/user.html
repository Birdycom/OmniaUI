User info

Avatar plus two text lines. Used in sidebar footers, menus and member lists. Hides the text inside a collapsed sidebar. All components.

Demo

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/user.html.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-userFlex row wrapper
.oc-avatarAvatar from the avatar component (initials or img)
.oc-user-textText column
.oc-user-nameName (truncates)
.oc-user-emailSecondary line (truncates)
