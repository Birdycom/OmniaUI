Forms & Inputs

Compose forms with the .oc-field wrapper: a label, the control and an optional description or error. .oc-input-group adds a prefix or suffix. For the separate controls see Native select, Radio and Toggle field.

Class / attributeDescription

.oc-checkbox / .oc-radioCheckbox and radio in the theme colors.
