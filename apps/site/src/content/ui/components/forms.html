Class / attributeDescription
.oc-fieldWrapper: label, control and message stacked. --horizontal puts the label beside the control.
.oc-field-labelThe label.
.oc-field-description / .oc-field-errorHelp text / error message under the control.
.oc-inputText input; also on <textarea>.
.oc-selectNative select.
.oc-checkbox / .oc-radioCheckbox and radio in the theme colors.
.oc-switch + .oc-switch-trackA checkbox drawn as an on/off switch.
.oc-input-group + .oc-input-addonInput with a prefix or suffix.
aria-invalid="true"Error color on the control.
.oc-formThe fields of a form in one grid with one gap (--oc-form-gap, 1.1rem). aria-busy="true" dims the submit button while it sends.
.oc-form--filledFields with a fill, the strong border, more room and a 3px focus ring: sets the field tokens below.
--oc-input-bg, --oc-input-border, --oc-input-padding, --oc-input-radius, --oc-input-sizeField tokens of .oc-input and .oc-select; a theme or a form variant sets them.
--oc-ring-width / --oc-ring-alphaFocus ring around a field: width (2px) and strength of --oc-ring (25%).
.oc-textareaTextarea that only grows downwards; --oc-textarea-min is its minimum height (80px, 9rem in a filled form).
.oc-field-label__hintMuted, normal weight addition in a label: (optional).
.oc-form-actions + .oc-form-noteSubmit button with a short note next to it (privacy); the note wraps under the button on a narrow form.
.oc-honeypotA field for bots, off screen for people (not display:none). Give it aria-hidden="true", the input tabindex="-1".
