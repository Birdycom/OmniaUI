Mask and validation v0.17.0

An input can format while you type (mask: iban, bic, vat, phone or a pattern where 9 is a digit, A a letter and * anything) and check its value when you leave it (validationType: iban with the mod-97 check and the length per country, bic, vat for BE and NL, email, phone). The caret stays behind the character you typed. A wrong value gets aria-invalid and the field shows the validationMessage; it goes away as soon as the value is right. Type an IBAN with one wrong digit and press Tab. Prefixes and units stay in an input group. Plain HTML and Blade use the small script oc-input-mask.js (npx omniaui copy-js input-mask).

Ledger fields v0.17.0

variant="ledger" on a field (or on Input, Select, Textarea, Combobox and InputGroup) gives the compact bookkeeping look for invoice lines and other dense forms: about 2rem high, tabular figures, a lightly tinted fill, a thin border and a small muted label. The focus colour follows the module colour (module="green" sets data-module, see Module colour) and falls back to the theme ring.
