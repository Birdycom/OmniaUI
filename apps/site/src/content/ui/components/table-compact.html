Table compact

A variant of the table for inside cards and side panels: small text, striped rows and no outer cell borders, because the card already gives the frame. Wrap a normal table.oc-table in .oc-table-compact. All components.

Inside a card

CSS variant parts/app-table-compact.css

Numbers use data-numeric from the table component. The tfoot row becomes a bold total. Snippet: packages/ui/snippets/table-compact.html.

Bordered and plain

--bordered gives the table its own frame when it is not inside a card. --plain removes stripes and the header background for very dense lists. A cell with data-wrap may wrap; all others stay on one line.

Reference

Works with the existing table extras (data-numeric, aria-selected rows, .oc-table-sort).

Class / attributeDescription
.oc-table-compactWrapper around table.oc-table; scrolls sideways when needed
.oc-table-compact--borderedOwn rounded frame
.oc-table-compact--plainNo stripes, no header background
[data-numeric] / [data-wrap]Right aligned numbers / cell may wrap
tfootBold total row with a stronger line above
.oc-table-compact-mutedMuted secondary text in a cell

Browser support

Plain table CSS; the selectors used are supported everywhere.
