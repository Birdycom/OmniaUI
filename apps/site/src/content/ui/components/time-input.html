Time input

A 24-hour time field (HH:mm) that looks the same in every locale. It is a short text field with a pattern and a <datalist> of suggested slots. For booking forms, the slot list shows the times as radio chips. No JavaScript; the wrappers add the colon while typing (0930 → 09:30). All components.

Time picker: slots in a popover v0.18.0

With slotsPopover the slots open in a native popover under a clock button (.oc-time-picker, popovertarget, the same way as the breadcrumb menu) instead of the browser's datalist: the same list in every browser. Picking a slot fills the field and closes the popover; typing (0930 → 09:30) keeps working. Plain HTML and Blade: oc-form-extras.js puts the picked slot into the field with input and change events, so wire:model sees it.

Reference

Styles live in packages/ui/src/parts/forms-time-input.css. Prefer the native type="time" picker? See Date picker; it shows AM/PM in some locales.

Class / attributeDescription
.oc-time-inputAdd to .oc-input: narrow centered field; red on :user-invalid
pattern + list([01][0-9]|2[0-3]):[0-5][0-9] and the id of a <datalist>
.oc-time-slotsSlot grid (role="radiogroup"). Modifier: --sm.
.oc-time-slotLabel with one radio and the time text
.oc-time-picker The field, a clock button (.oc-btn--icon with popovertarget) and the slots (.oc-time-slots) in a native popover (.oc-popover). Wrappers: slotsPopover / slots-popover, slotsLabel (default "Choose a time"). Plain HTML and Blade need oc-form-extras.js to fill the field.

Framework wrappers

slots fills the datalist. The value is always HH:mm or an empty string.

<!-- React --> <TimeInput value={time} onChange={setTime} slots={["08:00", "08:30", "09:00"]} aria-label="Start" /> <!-- Vue --> <OcTimeInput v-model="time" :slots="['08:00', '08:30']" aria-label="Start" /> <!-- Laravel Blade --> <x-oc::time-input name="start" value="08:30" :slots="['08:00', '08:30']" />
