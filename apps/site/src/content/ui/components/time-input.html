Time input

A 24-hour time field (HH:mm) that looks the same in every locale. It is a short text field with a pattern and a <datalist> of suggested slots. For booking forms, the slot list shows the times as radio chips. No JavaScript; the wrappers add the colon while typing (0930 → 09:30). All components.

Demo

snippets/time-input.html v0.6.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/time-input.html.

Slot list

Radio chips in a grid. The checked slot is primary; a disabled slot is struck through (already booked). Arrow keys move between slots.

Framework wrappers

slots fills the datalist. The value is always HH:mm or an empty string.

<!-- React --> <TimeInput value={time} onChange={setTime} slots={["08:00", "08:30", "09:00"]} aria-label="Start" /> <!-- Vue --> <OcTimeInput v-model="time" :slots="['08:00', '08:30']" aria-label="Start" /> <!-- Laravel Blade --> <x-oc::time-input name="start" value="08:30" :slots="['08:00', '08:30']" />
