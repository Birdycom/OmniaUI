Expandable table and toggle button

Show more / Show less: a table that displays its first rows and reveals the rest with a button, plus the generic toggle button .oc-btn--toggle behind it. Both are pure CSS (a hidden checkbox and :has()). This is how every reference table on this site works. All components.

How it works

  1. The toggle is a label styled as a button (.oc-btn) around a visually hidden checkbox. Clicking the label, or pressing Space while the checkbox has focus, toggles it. A focus ring is drawn around the label.
  2. The wrapper reads the state with :has(.oc-expandable-table__toggle:checked): rows marked __row-more change from hidden to visible and the dimmed row returns to full opacity.
  3. The two spans (__more / __less) swap the label text from the same state.
  4. If a table has no __row-more rows, the button is hidden automatically.

Rule of thumb on this site: show nine rows, dim the tenth, hide the rest. With a script you can set .is-expanded on the wrapper instead of using the checkbox.

Generic toggle button

.oc-btn--toggle is the same idea for any content: put it in a .oc-showmore container together with .oc-showmore__extra elements. Combine it with any button variant (--outline, --secondary, --ghost) and size. It is listed on the Button page too.

Accessibility and responsive behaviour

  • The control is a native checkbox, so its checked state is exposed to assistive technology; the visible text changes between "Show more" and "Show less".
  • Hidden rows use display: none, so they are removed from the tab order and not read until revealed.
  • Wide tables scroll inside their container; the --full wrap stretches the button to the table width, which also makes a large touch target on phones.
