Checklist

Compact rule list (password requirements) or a card variant with rows that hold actions (onboarding). State per item: .is-done or aria-checked="true". Add a visually hidden text for screen readers if the state changes live. All components.

Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/checklist.html.

  • One uppercase letter
  • One number

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.
