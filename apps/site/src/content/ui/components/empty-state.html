Locked: opens later v0.17.0

For content that opens later: when you are in a zone, after you scan a code, at a set time. .oc-empty--locked gives a dashed frame and puts the icon in the brand color, .oc-empty-meta says what is left, and the buttons offer another way in. React and Vue: locked (a lock icon unless you pass one) and meta; Blade the same.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-empty--locked + .oc-empty-metaContent that opens later: dashed frame, the icon in the brand color, a pill with what is left. Prop locked, meta
.oc-emptyCentered column wrapper
.oc-empty-iconRound icon holder (glyph, emoji or inline SVG)
.oc-empty-titleHeading
.oc-empty-textExplanation
.oc-empty-actionsRow for buttons (optional)
