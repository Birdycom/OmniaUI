Project card

A portfolio card: a small browser-like window with the screenshot, then the project type, name, sector and a "View" link. The whole card is one link. Without an image the preview shows an accent gradient. All components.

Demo

Hover: the card lifts, the border takes the accent and the arrow moves. Snippet: packages/ui/snippets/project-card.html.

Reference

Styles live in packages/ui/src/parts/site-project-card.css. The card is self-contained: it needs no other frame component. Use <img class="oc-project-card__shot" alt="…"> for a real screenshot.

Class / attributeDescription
.oc-project-cardThe card (an a). Modifier --flat: edge-to-edge preview
.oc-project-card__frame / __barPreview window and its title bar (three i dots)
.oc-project-card__shotScreenshot img, or an empty element for the gradient placeholder
.oc-project-card__bodyText column
__type / __name / __meta / __moreBadge, title, sector line, "View" with arrow
.oc-accent--*Accent for badge, dot, hover border and placeholder
