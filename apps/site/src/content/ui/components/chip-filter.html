Chip filter

Rounded filter chips above a list or grid. Use checkboxes to pick several filters, radios to pick one. :has(input:checked) highlights the chip, and the inputs submit with the form. No JavaScript. All components.

Demo

snippets/chip-filter.html v0.6.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/chip-filter.html.

One choice, small, scrolling

Radios give a single choice (arrow keys move between chips). --sm makes them compact; --scroll keeps them on one line that scrolls sideways on small screens.

Reference

Styles live in packages/ui/src/parts/forms-chip-filter.css. For a joined pill switcher, see Segmented control.

.oc-chip-filter-itemPill label around one checkbox or radio
.oc-chip-filter-countOptional count bubble; primary when the chip is checked

Framework wrappers

With multiple the value is an array (checkboxes); without it a single string (radios).

<!-- React --> <ChipFilter multiple aria-label="Type" value={types} onChange={setTypes} options={[{ value: "video", label: "Video", count: 24 }]} /> <!-- Vue --> <OcChipFilter v-model="mode" label="Scan mode" :options="modes" size="sm" /> <!-- Laravel Blade --> <x-oc::chip-filter name="type" multiple :value="['video']" :options="['video' => 'Video', 'audio' => 'Audio']" />
