Upgrade banner

A soft callout for users on a free plan: what the limits are, how much they used, and a way to upgrade. Usage is shown with a native <meter> element. All components.

Demo

Plain HTML and CSS; each example shows its markup in the HTML tab.

Free plan with usage

The warning tone is friendly, not alarming. The dismiss button is optional: your app sets hidden on the banner and remembers the choice. Snippet: packages/ui/snippets/upgrade-banner.html.

Reference

Slots: icon, title, plan, text, usage, actions. Tone: --oc-upgrade-color.

Class / attributeDescription
.oc-upgrade-bannerCallout. Modifiers: --premium, --compact. State: hidden
.oc-upgrade-banner-iconIcon in the tone color
.oc-upgrade-banner-body / -title / -plan / -textText column, title row, plan pill, explanation
.oc-upgrade-banner-usage + meter.oc-upgrade-banner-meterUsage row with a native meter
.oc-upgrade-banner-actionsUpgrade button and secondary link
.oc-upgrade-banner-dismissOptional close button in the corner

Browser support

The meter styling uses engine pseudo-elements; unsupported engines show the default meter.
