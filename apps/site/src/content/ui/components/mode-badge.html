Mode badge

Shows at a glance whether something belongs to the test round, the live round, or both: a code, a link, a QR code, a set of settings. The colors are fixed (amber for test, green for live) and the same in the light and the dark theme, so they also read on a photo or a print. Pair it with the accent card and the code plate. All components.

Your own mode colors v0.16.1

The two mode colors and the text on them are tokens: --oc-mode-test, --oc-mode-live and --oc-mode-ink. Set them on :root for the whole app, or on any parent for one part of it: the badges, the accent cards with data-tone="test" or "live" (border and band) and the caption of a code plate all follow. Here they are pink and cyan for the part inside the frame only. Keep the ink above 4.5:1 on both colors.

Reference

Styles live in packages/ui/src/parts/app-mode-badge.css. The mode colors are tokens: --oc-mode-test, --oc-mode-live and --oc-mode-ink (the dark text on both).

Class / attributeDescription
.oc-mode-badge[data-mode]The badge: test (amber), live (green), both (two child spans, each in its own color). Uppercase, bold, letter-spaced.
--sm / --lgSmaller (in a list of codes) or larger (in the band of an accent card)
--oc-mode-test / --oc-mode-live / --oc-mode-inkThe two mode colors (default --color-orange-20 and --color-green-10) and the text on them (--color-duskblue-90); also used by .oc-card--accent[data-tone="test|live"] and .oc-code-plate[data-mode]. Set them on :root or on any parent (example)
@media printprint-color-adjust: exact: the colors are printed, not dropped

Accessibility

  • The mode is a word in the badge, not only a color, so it reads without color vision and in forced colors (where the badge gets a border).
  • The dark text on amber and on green is above 7:1.

Framework wrappers

mode (test, live, both), size (sm, md, lg) and the words: labels in React and Vue, test / live in Blade.

<!-- React --> <ModeBadge mode="live" size="lg" labels={{ test: "Test", live: "Live" }} /> <!-- Vue --> <OcModeBadge mode="both" size="sm" /> <!-- Laravel Blade --> <x-oc::mode-badge mode="test" />
