Theming

Components use CSS variables with a background/foreground naming pattern. Override :root for light mode, .dark for dark mode, or create a custom theme class.

/* Custom theme example */ .my-theme { --oc-primary: #7c3aed; --oc-primary-foreground: #ffffff; --oc-radius: 0.75rem; } /* Apply to any container */ <div class="my-theme"> <button class="oc-btn">Purple theme</button> </div>

Token reference

VariablePurpose
--oc-backgroundPage/container background
--oc-foregroundDefault text color
--oc-primaryPrimary accent (buttons, links)
--oc-primary-foregroundText on primary background
--oc-secondarySecondary/muted accent
--oc-mutedMuted surface color
--oc-muted-foregroundMuted text color
--oc-destructiveDestructive/error color
--oc-borderDefault border color
--oc-inputInput border color
--oc-ringFocus ring color
--oc-radiusGlobal border radius
