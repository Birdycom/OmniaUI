Theming

Every component reads semantic tokens such as --oc-primary and --oc-border. Each token is a light-dark(light, dark) pair, so dark mode needs no extra classes. Override the tokens on :root to re-theme the whole page, or on any element to theme only that part.

Demo

The same buttons and input twice: on the right the tokens are overridden on the container with Omnia palette colors. Switch the site theme to see both follow light and dark mode.

Page-wide override

Load your overrides after the OmniaUI CSS. Use palette tokens (--color-*) inside light-dark() so both modes stay in the Omnia palette.

/* the whole page */ :root { --oc-primary: light-dark(var(--color-purple-40), var(--color-purple-10)); --oc-radius: 0.75rem; } /* one part of the page */ .checkout { --oc-primary: light-dark(var(--color-green-60), var(--color-green-2)); }

Reference

The tokens come from @birdycom/omniacss (dist/oc-theme.css, generated from tokens/semantic.json).

TokenDescription
--oc-background / --oc-foregroundPage background and body text.
--oc-card / --oc-popoverCards and panels / menus and popovers.
--oc-muted / --oc-muted-foregroundSubtle surfaces / secondary text.
--oc-primary / --oc-primary-foregroundMain accent (buttons, links, focus) / text on it.
--oc-secondary, --oc-accentQuieter accents (follow --oc-muted by default).
--oc-destructive, --oc-success, --oc-warningStatus colors, each with a -foreground partner.
--oc-border, --oc-border-strong, --oc-inputBorders and input outlines.
--oc-ring, --oc-focus-widthFocus ring color and width.
--oc-hover, --oc-pressed, --oc-selected, --oc-row-altInteraction states and striped rows.
--oc-radiusBase corner radius; components derive theirs from it.
