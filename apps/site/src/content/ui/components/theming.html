Theming

Every component reads semantic tokens such as --oc-primary and --oc-border. Each token is a light-dark(light, dark) pair, so dark mode needs no extra classes. Override the tokens on :root to re-theme the whole page, or on any element to theme only that part.

Demo

The same buttons and input twice: on the right the tokens are overridden on the container with Omnia palette colors. Switch the site theme to see both follow light and dark mode.

Page-wide override

Load your overrides after the OmniaUI CSS. Use palette tokens (--color-*) inside light-dark() so both modes stay in the Omnia palette.

/* the whole page */ :root { --oc-primary: light-dark(var(--color-purple-40), var(--color-purple-10)); --oc-radius: 0.75rem; } /* one part of the page */ .checkout { --oc-primary: light-dark(var(--color-green-60), var(--color-green-2)); }

A whole site from tokens v0.13.0

A company site can have no CSS of its own: a theme file with tokens, the opt-in element base @birdycom/omniacss/base.css (body, headings, lists, focus and selection in @layer omnia, so every class still wins) and the OmniaUI components and blocks. The tokens below set the type, the buttons, the backdrop, the footer and the width of the blocks.

@import "@birdycom/omniacss/base.css"; :root { color-scheme: dark; /* an always-dark site */ --oc-brand-1: var(--color-skycyan-60); --oc-primary: var(--oc-brand-1); --oc-font-display: "Segoe UI Variable Display", system-ui, sans-serif; --oc-subtle-foreground: var(--color-mistblue-95); --oc-body-size: 1.0625rem; /* base.css */ --oc-body-leading: 1.65; --oc-container: 1440px; /* .oc-container and the blocks */ --oc-block-gap: 1.25rem; --oc-btn-weight: 600; --oc-btn-lg-padding: 0.85rem 1.4rem; --oc-backdrop-1: var(--color-blue-60); --oc-footer-cols: 1.5fr repeat(4, 1fr); --oc-footer-cols-md: 4; }

Reference

The color and font tokens come from @birdycom/omniacss (dist/oc-theme.css, generated from tokens/semantic.json); the component tokens (buttons, fields, footer …) are read by OmniaUI with a default.

TokenDescription
--oc-background / --oc-foregroundPage background and body text.
--oc-card / --oc-popoverCards and panels / menus and popovers.
--oc-muted / --oc-muted-foregroundSubtle surfaces / secondary text.
--oc-primary / --oc-primary-foregroundMain accent (buttons, links, focus) / text on it.
--oc-secondary, --oc-accentQuieter accents (follow --oc-muted by default).
--oc-destructive, --oc-success, --oc-warningStatus colors, each with a -foreground partner.
--oc-border, --oc-border-strong, --oc-inputBorders and input outlines.
--oc-ring, --oc-focus-widthFocus ring color and width.
--oc-hover, --oc-pressed, --oc-selected, --oc-row-altInteraction states and striped rows.
--oc-radiusBase corner radius; components derive theirs from it.
--oc-subtle-foregroundThird text level, dimmer than muted: taglines, meta lines, the bottom bar of a footer (v0.13.0).
--oc-font-displayFont of display titles, word marks and key figures; the sans font by default (v0.13.0).
--oc-btn-weight, --oc-btn-lg-size, --oc-btn-lg-padding, --oc-btn-gradient-inkWeight of every button, size and padding of .oc-btn--lg, text color on .oc-btn--gradient (dark ink for a light accent) (v0.13.0).
--oc-body-size, --oc-body-leading, --oc-heading-*, --oc-scroll-offset, --oc-selectionElement base (@birdycom/omniacss/base.css, opt-in): body text, headings, room under a sticky header, selection color (v0.13.0).
.oc-skip-link / .oc-iconSkip link for keyboard users / inline icon of 1.25em (1.1em in a button) (v0.13.0).
