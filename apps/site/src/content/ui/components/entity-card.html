Entity card

A framed square cell with a picture, glyph or icon, next to a detail column: eyebrow, title, description and a small list of facts. Use it for dictionary entries, symbols, collection items or products. It stacks by itself in narrow containers (container query). All components.

Accessibility

  • A decorative glyph gets aria-hidden="true" when the title already names it; a meaningful picture keeps its alt.
  • Facts are a description list (<dt> / <dd>), so screen readers pair each key with its value.
  • To make the whole card a link, wrap the title text in an <a>; keep other links in the footer.
