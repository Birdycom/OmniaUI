Affix input

The price and margin fields from the article form. Add .oc-input-group--affix and the symbol (€, %, @) sits in its own column, with a divider, on the left. The value stays left-aligned next to it. Barcode uses the same column for its icon. All components.

Error and disabled

Reference

Styles live in packages/ui/src/parts/forms-affix-input.css; the base group comes from components.css. Colors are theme tokens (--oc-*).

Class / attributeDescription
.oc-input-group--affixAdd to .oc-input-group: one frame, symbol in a column with a divider
.oc-input-group--endOptional. Right-aligns the value
.oc-input-group--errorRed frame (also via aria-invalid or :user-invalid)
.oc-input-addonThe symbol column. Before the input = left (€, %, @). After it = right

Framework wrappers

variant picks the symbol, type and inputmode for you: currency (€), percent (%) or email (@). Or pass your own prefix / suffix.

<!-- React --> <AffixInput variant="currency" value={price} onChange={(e) => setPrice(e.target.value)} /> <!-- Vue --> <OcAffixInput v-model="vat" variant="percent" /> <!-- Laravel Blade --> <x-oc::affix-input variant="email" name="email" />
