Table actions

Row actions for a data table: a few small icon buttons, or one "more" button that opens a menu. Both live in the existing td.oc-table-actions cell. The menu is a native popover, so it needs no JavaScript. All components.

Icon actions

CSS component parts/app-table-actions.css

Use icon actions when a row has two or three actions. Each icon needs an aria-label (screen readers) and a title (tooltip). The tone modifier only colors the hover state, except --destructive, which is always red. Snippet: packages/ui/snippets/table-actions.html.

Overflow menu

With more actions, or on narrow screens, use one .oc-table-actions-more trigger and a .oc-dropdown-menu[popover]. The menu opens toward the start edge, because the column sits at the end of the row. The trigger stays highlighted while the menu is open.

Reference

Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: icon actions, or the trigger plus menu items.

Class / attributeDescription
td.oc-table-actionsActions cell from the table component (end aligned, no wrap)
.oc-table-actions--iconsTighter gap for a row of icon actions
.oc-table-actions-iconSquare icon action (a or button). State: disabled / aria-disabled="true"
.oc-table-actions-icon--primary / --success / --destructiveTone of the action
.oc-table-actions-more[popovertarget]Overflow trigger with three CSS dots
.oc-dropdown-menu[popover]The overflow menu (dropdown component)

Browser support

The menu needs the popover attribute. Anchor positioning places it next to the trigger; without it the menu still opens.
