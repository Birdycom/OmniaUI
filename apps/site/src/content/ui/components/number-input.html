Number input

A native input type="number" between a minus and a plus button. min, max and step come from the input itself; the buttons call stepDown() / stepUp(), so the limits are always respected. Without JavaScript the field still works with the arrow keys. All components.

Demo

snippets/number-input.html v0.6.0

Plain HTML and CSS plus the small script below. The markup is also available as the snippet packages/ui/snippets/number-input.html.

Full width, small and disabled

--block stretches the field, --sm is for tables and toolbars. A disabled field dims the whole control. Type a value above max to see :user-invalid.

Reference

Styles live in packages/ui/src/parts/forms-number-input.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-number-inputFrame around buttons and field. Modifiers: --block, --sm, --error.
.oc-number-input-stepMinus / plus button with data-oc-step="-1" or "1"
.oc-number-input-fieldThe type="number" input; native spinners are hidden

Optional script

One listener for all number inputs on the page. It also fires input and change, so forms and frameworks notice the new value.

<script> document.addEventListener('click', (e) => { const btn = e.target.closest('.oc-number-input-step'); if (!btn) return; const input = btn.parentElement.querySelector('.oc-number-input-field'); if (!input || input.disabled) return; btn.dataset.ocStep === '-1' ? input.stepDown() : input.stepUp(); input.dispatchEvent(new Event('input', { bubbles: true })); input.dispatchEvent(new Event('change', { bubbles: true })); }); </script>

Framework wrappers

The wrappers handle the buttons themselves and disable minus / plus at the limits.

<!-- React --> <NumberInput value={qty} onChange={setQty} min={0} max={99} aria-label="Quantity" /> <!-- Vue --> <OcNumberInput v-model="qty" :min="0" :max="99" aria-label="Quantity" /> <!-- Laravel Blade --> <x-oc::number-input name="qty" :value="2" min="0" max="99" aria-label="Quantity" />
