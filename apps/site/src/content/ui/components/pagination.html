Pagination

Page numbers for a long list or table. Plain links (?page=2), so every page has its own URL and works without JavaScript; the current page is marked with aria-current="page". All components.

Many pages, previous and next

With many pages, show the first, the last and a window around the current page; a <span class="oc-pagination-item"> with "…" marks the gap (the Laravel component does this for you). Previous and next are ordinary items with an aria-label.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so the numbers follow light and dark mode. In a real app the links point to ?page=2.

Class / attributeDescription
nav.oc-paginationThe row of pages. Give it aria-label="Pagination".
a.oc-pagination-itemOne page (a square box with a border; accent background on hover, focus ring on keyboard focus). A <button> works too when the page changes without navigation.
[aria-current="page"]The current page: primary background.
span.oc-pagination-itemThe "…" gap for skipped pages: no border, muted. Add aria-hidden="true".
li.oc-pagination-item.is-active > aOlder list markup (<ul class="oc-pagination"> with buttons or links) keeps working.

Framework wrappers

React and Vue render every page; with a click handler (or without hrefFor in Vue) they change the page without navigating. The Blade component takes a Laravel paginator and adds the "…" gaps.

<!-- React --> <Pagination page={page} pageCount={12} onPageChange={setPage} /> <!-- Vue --> <OcPagination v-model="page" :pages="12" /> <!-- Laravel Blade (a paginator, or current + total + url) --> <x-oc::pagination :paginator="$invoices" /> <x-oc::pagination :current="7" :total="24" url="/invoices?page=%d" />
