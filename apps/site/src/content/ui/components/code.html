Code block

Reusable syntax-highlighted code display. Use pre.code with code inside; the Code-block is part of @birdycom/omniaui (Omnia Dark theme, line numbers). The docs build highlights code ahead of time (no script in the page); in your own project wrap tokens in the same .hl-* spans or render them on the server. Same styling in docs, blocks and components. Full reference in Docs.

Reference

Class / VariableDescription
pre.codeWrapper for the code block (dark bg, mono font)
.hl-tag / .tagHTML tag names
.hl-attr / .attrHTML attribute names
.hl-string / .valAttribute values, strings
.hl-comment / .cmtComments
.hl-prop / .propCSS property names
.hl-valueCSS property values
.clsClass names in code (e.g. CSS selector)
--oc-syntax-*CSS variables for colors (bg, fg, tag, attr, string, keyword, etc.)

How to build this block

Markup: <pre class="code"><code>...escaped HTML...</code></pre>. Use the component markup .oc-code-block → .oc-code-block__gutter + pre.code-preview, with .hl-tag, .hl-attr, .hl-string spans around the tokens.

<!-- CSS (in head) --> <link rel="stylesheet" href="path/to/oc-code-syntax.css"> <!-- Code block: escape < > as &lt; &gt; --> <pre class="code"><code>&lt;div class="oc-block-hero"&gt; &lt;span class="oc-block-hero-badge"&gt;New&lt;/span&gt; &lt;h1&gt;Headline&lt;/h1&gt; &lt;/div&gt;</code></pre> <!-- No script needed: the spans are part of the markup -->
