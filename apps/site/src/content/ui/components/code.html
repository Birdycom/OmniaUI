Code block

Syntax-highlighted code with line numbers in the Omnia Dark theme, the same on light and dark pages. Tokens are wrapped in .hl-* spans ahead of time (at build time or on the server), so the page needs no highlighting script. Full syntax theme in the OmniaCSS docs.

Demo

Plain HTML and CSS: a gutter with line numbers next to pre.code-preview; the colors come from the .hl-* spans.

In your own project

Load the stylesheet and wrap tokens in the same spans; escape < and > inside the code.

<link rel="stylesheet" href="node_modules/@birdycom/omniaui/dist/code-block.css"> <pre class="code-preview"><code><span class="hl-tag">&lt;h1&gt;</span>Headline<span class="hl-tag">&lt;/h1&gt;</span></code></pre>

Reference

Styles live in packages/ui/src/code-block.css. The block always uses the dark syntax theme (color-scheme: dark), also on light pages.

Class / variableDescription
.oc-code-blockWrapper: gutter and code side by side, border and radius.
.oc-code-block__gutterA <pre> with the line numbers (aria-hidden).
pre.code-previewThe code itself: monospace, keeps spaces and line breaks, scrolls sideways.
.hl-tag, .hl-attr, .hl-string, .hl-commentHTML tokens.
.hl-prop, .hl-value, .hl-number, .hl-unitCSS tokens.
.hl-keyword, .hl-variable, .hl-function, .hl-operatorScript tokens (JS, PHP, Python).
--oc-syntax-*The theme colors (--oc-syntax-bg, -fg, -tag, -string, …), from Omnia palette tokens.
--oc-code-block-tab-sizeTab width (default 2).
