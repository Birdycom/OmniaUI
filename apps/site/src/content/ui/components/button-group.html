Button group

Joins several buttons into one segmented control: shared borders, rounded outer corners only. It is the existing .oc-btn-group, now registered with its own snippet, a vertical modifier and a text addon. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/button-group.html.

Anatomy

  • Root .oc-btn-group: display: inline-flex; give it role="group" and an aria-label.
  • Buttons .oc-btn in any variant. Borders overlap by 1px so the seam is a single line; the focused button is raised so its ring is not clipped.
  • Text cell .oc-btn-group-text: muted cell for a value that belongs to the group.

Vertical and with text

--vertical stacks the buttons; .oc-btn-group-text adds a non-interactive cell.

Accessibility and keyboard

Accessibility

  • Use role="group" with a label so assistive technology announces the buttons as one control.
  • For a single-choice switch use the segmented control; for pressed state use the toggle group.

Keyboard

  • Tab moves between the buttons, Space/Enter activates.

Reference

Styles live in packages/ui/src/components-extra.css (extensions) and components.css (base). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.
