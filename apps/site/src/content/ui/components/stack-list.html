Class / attributeDescription
.oc-stack-listThe ul. Modifiers: --neutral (no tint), --sm
.oc-stack-list__itemOne pill
.oc-stack-list__iconOptional glyph or SVG before the name (aria-hidden)
.oc-accent--*Accent for the tint
