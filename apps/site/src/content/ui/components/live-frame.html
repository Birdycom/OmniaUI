Live frame

Show a real page in a small box: the page is laid out at a virtual size such as 1280x720 and scaled down to the width of the frame, so it looks like a screenshot that is still alive. Pure CSS, no script and no resize listener. On its own or in the browser frame. All components.

How it scales

  • The frame is a size container (container-type: inline-size) with the ratio of the virtual size (aspect-ratio: var(--oc-live-w) / var(--oc-live-h)).
  • The iframe is exactly the virtual size and is scaled with scale: tan(atan2(100cqi, 1280px)): atan2 of two lengths and then tan gives their ratio, so frame width / virtual width, without a script.
  • The page inside lays out at 1280px wide, so it shows its desktop layout, not its phone layout.
  • scrolling="no" on the iframe hides its scrollbar; make the virtual height the height you want to show.

Framework wrappers

The same markup and classes as React, Vue and Blade components.

<!-- React --> <LiveFrame src="https://example.com" title="Example" width={1680} height={1400} static /> <!-- Vue --> <OcLiveFrame src="https://example.com" title="Example" in-browser-frame /> <!-- Blade --> <x-oc::live-frame src="https://example.com" title="Example" :width="1680" :height="1400" static />
