Live frame

Show a real page in a small box: the page is laid out at a virtual size such as 1280x720 and scaled down to the width of the frame, so it looks like a screenshot that is still alive. Pure CSS, no script and no resize listener. On its own or in the browser frame. All components.

Another size, as a picture

Set the virtual size with --oc-live-w and --oc-live-h; the frame takes that ratio. --static lets clicks and scrolling pass by, for a preview that is not meant to be used.

On a phone and a television, only to look at v0.16.0

--phone and --tv put a dark bezel with round corners around the page; the phone is 390 x 844 and at most 17rem wide (--oc-live-phone-max). The inert attribute on the iframe makes it a preview only: no clicks, no keyboard focus, and screen readers skip it, so the figure caption names it. Try it: press Tab through this demo, the focus never enters the two pages.

On a laptop v0.16.1

--laptop puts a thin bezel around the page and a base under it, a little wider than the screen, with the notch to open the lid. The page is 1440 x 900 by default in the wrappers. The frame leaves room for the base on both sides and below, so it never sticks out of its column; drag the preview to phone width to check. Colors: --oc-live-bezel and --oc-live-base.

How it scales

  • The frame is a size container (container-type: inline-size) with the ratio of the virtual size (aspect-ratio: var(--oc-live-w) / var(--oc-live-h)).
  • The iframe is exactly the virtual size and is scaled with scale: tan(atan2(100cqi, 1280px)): atan2 of two lengths and then tan gives their ratio, so frame width / virtual width, without a script.
  • The page inside lays out at 1280px wide, so it shows its desktop layout, not its phone layout.
  • scrolling="no" on the iframe hides its scrollbar; make the virtual height the height you want to show.

Framework wrappers

The same markup and classes as React, Vue and Blade components. inert and device on all three; React has frameRef and onFrameLoad, Vue the frame-load event and the exposed frame ref.

<!-- React --> <LiveFrame src="https://example.com" title="Example" width={1680} height={1400} static /> <LiveFrame device="phone" inert src="/preview" title="Preview" frameRef={ref} onFrameLoad={onLoad} /> <!-- Vue --> <OcLiveFrame src="https://example.com" title="Example" in-browser-frame /> <OcLiveFrame device="tv" inert src="/preview" title="Preview" @frame-load="onLoad" /> <!-- Blade --> <x-oc::live-frame src="https://example.com" title="Example" :width="1680" :height="1400" static /> <x-oc::live-frame device="phone" inert src="/preview" title="Preview" />
