Dropdown menu extras

Sub-menus, checkbox items, radio items, shortcuts, destructive and disabled items for the dropdown. The same classes work in the menubar and the context menu. All components.

Anatomy

  • Check / radio items the indicator is a pseudo-element shown when aria-checked="true", so state and visual cannot drift apart. Your click handler flips the attribute.
  • Sub-menu a .oc-dropdown-sub wrapper (position: relative) with a trigger item and an absolutely positioned .oc-dropdown-submenu; opens with :hover and :focus-within.
  • Shortcut push key hints right with .oc-dropdown-shortcut (can contain kbd.oc-kbd).

Accessibility and keyboard

Accessibility

  • Use role="menu" on the panel and menuitem, menuitemcheckbox, menuitemradio on items; set aria-haspopup="menu" on sub-menu triggers.
  • Sub-menus open on focus-within, so keyboard users reach them with Tab; full roving arrow-key handling is wrapper responsibility.

Keyboard

  • Enter/Space activates an item, Esc closes the popover. Wrapper: → opens a sub-menu, ← closes it.
