Document viewer

A PDF, video or image shown inline in a card with a label, and a full-screen view on a native <dialog>. The expand button (or the whole preview) opens it with invoker commands, so no JavaScript is needed. Install with npx omniaui add doc-viewer. All components.

Demo

Component snippets/doc-viewer.html v0.9.1

Click the expand button on the PDF card or the video preview. Esc, the close button or a click on the backdrop closes the view. The pictures here stand in for the real files; put an <iframe> (PDF), <video> or <img> in the frame.

Reference

Styles live in packages/ui/src/parts/media-doc-viewer.css. Colors are Omnia theme tokens only.

Class / attributeDescription
.oc-doc-viewer-gridOptional grid of cards (auto-fill, minimum 15rem)
figure.oc-doc-viewerOne card; --video 16 : 9 dark frame, --image natural height
.oc-doc-viewer__bar / __label / __metaCaption row: name and small meta text (type, size, duration)
button.oc-doc-viewer__expandOpens the dialog: command="show-modal" commandfor="id"
.oc-doc-viewer__frameHolds the iframe, video, img or object
button.oc-doc-viewer__openOptional: covers the preview, "Click for full screen" appears on hover and focus
dialog.oc-doc-viewer-dialogFull-screen view; --video is dark
.oc-doc-viewer-dialog__bar / __title / __actions / __close / __bodyTop bar with title, extra actions (download) and close; the body fills the rest

Platform features used

FeatureRole
<dialog> + closedby="any"Top layer, focus trap, closes with Esc or backdrop click
command / commandforOpen and close without a script
aspect-ratioA4 and 16 : 9 frames
