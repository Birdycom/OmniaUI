Barcode input

The barcode field from the article form: a barcode icon in the left column, then the code (EAN-13 or an internal code such as an article id). A preview under the field is optional. Price and margin use the same column for € and %. All components.

Demo

snippets/barcode-input.html v0.6.0

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/barcode-input.html.

13 digits is an EAN-13. Anything else is an internal code.

Empty and invalid

.oc-barcode-preview--empty fades the bars and shows a hint. An invalid field (aria-invalid or :user-invalid) also turns the preview border red.

Reference

Styles live in packages/ui/src/parts/forms-barcode-input.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-barcode-inputWrapper: field on top, preview below
.oc-barcode-input-fieldAdd to .oc-input: monospace digits
.oc-barcode-previewPreview area (a <figure>). Modifier: --empty.
.oc-barcode-preview-barsDecorative placeholder bars (not scannable). Replace with your own graphic.
.oc-barcode-preview-codeThe code (or a hint) as text

Framework wrappers

The wrappers keep only digits and show the code under the bars. Pass your own barcode graphic as children (React) or the preview slot (Vue / Blade).

<!-- React --> <BarcodeInput value={ean} onChange={setEan} label="EAN code" /> <!-- Vue --> <OcBarcodeInput v-model="ean" label="EAN code" /> <!-- Laravel Blade --> <x-oc::barcode-input name="ean" label="EAN code" :value="$product->ean" />
