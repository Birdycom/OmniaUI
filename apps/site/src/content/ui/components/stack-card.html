Stack card

A cover for a collection (playlist, course, album) drawn as a small pile of cards, with a count badge. The two layers behind the cover are pseudo-elements, so the markup stays one Media thumb plus a badge. On hover the layers fan out a little. All components.

Accessibility

  • The layers are pseudo-elements, so screen readers only meet the cover, the count text and the title link.
  • Write the count as words ("12 videos"); a decorative icon gets aria-hidden="true".
  • The fan-out animation only runs under prefers-reduced-motion: no-preference.
