Barcode

Shows a product or article code as a scannable barcode: EAN-13, EAN-8, UPC-A or Code 128, chosen from the value (or set). barcode.js draws it as SVG, with the digits under it and the check digit verified. Black on white in both themes, so scanners and printers read it. All components.

Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

Class / attributeDescription
figure.oc-barcode[data-value]The barcode. The script replaces its content with the SVG and the digits.
data-formatauto (default: 12–13 digits EAN-13, 7–8 EAN-8, 11 UPC-A, else Code 128), EAN13, EAN8, UPC or CODE128.
data-digits="false"Bars only, no digits.
.oc-barcode--hero / --compactLarge (product page, label) or small (table cell).
--oc-barcode-heightHeight of the bars (4rem).
[data-error]Set when the value cannot be encoded (wrong check digit, non-ASCII in Code 128); the reason shows instead of bars.
encodeBarcode(value, format)Exported: the module string and the text, for your own canvas or PDF.

The last example has a wrong check digit on purpose: EAN-13 checks it and shows the right one. Script: npx omniaui copy-js barcode, or import { initBarcodes } from "@birdycom/omniaui/barcode.js". To read barcodes with a scanner see Barcode input.
