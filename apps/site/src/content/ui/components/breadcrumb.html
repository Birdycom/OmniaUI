Breadcrumb

A trail of links that shows where the page sits in the site. A <nav> with links; the separators come from CSS and the current page is marked with aria-current="page", so screen readers announce it. Items can carry a webicon, and --chevron puts a › between them. No JavaScript. All components.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so the trail follows light and dark mode.

Class / attributeDescription
nav.oc-breadcrumbThe trail. Give it aria-label="Breadcrumb".
a.oc-breadcrumb-itemA link in the trail (muted, darker on hover). A "/" separator is added before every item but the first.
span.oc-breadcrumb-item[aria-current="page"]The current page: not a link, full text color and medium weight.
.oc-breadcrumb--chevronA › chevron between the items instead of "/".
<iconify-icon> / <svg> in an itemAn icon before the label (1.1em, muted on links, full color on the current page).
button.oc-breadcrumb-ellipsis"…" for the collapsed middle of a long trail; opens a menu with the hidden levels.
li.oc-breadcrumb-item > aOlder list markup (<ol class="oc-breadcrumb">) keeps working; there the last item is the current page.

Framework wrappers

Pass the items; the last one becomes the current page (no link, aria-current="page"). An item takes an optional icon (React: any node; Vue and Blade: a webicon name) and separator="chevron" switches to chevrons.

<!-- React --> <Breadcrumb items={[{ label: "Home", href: "/" }, { label: "Docs", href: "/docs" }, { label: "Components" }]} /> <!-- Vue --> <OcBreadcrumb :items="[{ label: 'Home', href: '/' }, { label: 'Docs', href: '/docs' }, { label: 'Components' }]" /> <!-- Laravel Blade --> <x-oc::breadcrumb :items="[['label' => 'Home', 'href' => '/'], ['label' => 'Docs', 'href' => '/docs'], ['label' => 'Components']]" /> <!-- With icons and chevrons --> <Breadcrumb separator="chevron" items={[ { label: "Dashboard", href: "/", icon: <iconify-icon icon="mdi:home-outline" /> }, { label: "Customers", icon: <iconify-icon icon="mdi:account-multiple-outline" /> }, ]} /> <OcBreadcrumb separator="chevron" :items="[{ label: 'Dashboard', href: '/', icon: 'mdi:home-outline' }, { label: 'Customers', icon: 'mdi:account-multiple-outline' }]" /> <x-oc::breadcrumb separator="chevron" :items="[['label' => 'Dashboard', 'href' => '/', 'icon' => 'mdi:home-outline'], ['label' => 'Customers', 'icon' => 'mdi:account-multiple-outline']]" />
