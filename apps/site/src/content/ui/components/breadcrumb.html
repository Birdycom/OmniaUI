Breadcrumb

A trail of links that shows where the page sits in the site. A <nav> with links; the separators come from CSS and the current page is marked with aria-current="page", so screen readers announce it. No JavaScript. All components.

Reference

Styles live in packages/ui/src/components.css. Colors are theme tokens, so the trail follows light and dark mode.

Class / attributeDescription
nav.oc-breadcrumbThe trail. Give it aria-label="Breadcrumb".
a.oc-breadcrumb-itemA link in the trail (muted, darker on hover). A "/" separator is added before every item but the first.
span.oc-breadcrumb-item[aria-current="page"]The current page: not a link, full text color and medium weight.
li.oc-breadcrumb-item > aOlder list markup (<ol class="oc-breadcrumb">) keeps working; there the last item is the current page.

Framework wrappers

Pass the items; the last one becomes the current page (no link, aria-current="page").

<!-- React --> <Breadcrumb items={[{ label: "Home", href: "/" }, { label: "Docs", href: "/docs" }, { label: "Components" }]} /> <!-- Vue --> <OcBreadcrumb :items="[{ label: 'Home', href: '/' }, { label: 'Docs', href: '/docs' }, { label: 'Components' }]" /> <!-- Laravel Blade --> <x-oc::breadcrumb :items="[['label' => 'Home', 'href' => '/'], ['label' => 'Docs', 'href' => '/docs'], ['label' => 'Components']]" />
