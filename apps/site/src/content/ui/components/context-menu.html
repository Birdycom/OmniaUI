Context menu

A dropdown menu opened at the pointer on right-click (or long-press / the menu key). The look is the dropdown menu; opening it at the cursor needs a few lines of script, shown below and optional to reuse. All components.

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/context-menu.html.

Right-click (or press the menu key) here

Anatomy

  • Area any element you attach contextmenu to. Make it focusable and also open on Shift+F10/the menu key (the browser fires contextmenu for those).
  • Menu a dropdown-menu popover. Its position comes from --oc-context-x / --oc-context-y instead of anchor positioning.
  • Script five lines: it is the only JavaScript, because the browser has no declarative way to open a popover at pointer coordinates.

Accessibility and keyboard

Accessibility

  • Right-click menus must never be the only way to reach an action; offer the same actions in a visible menu or toolbar.
  • Popover gives light dismiss, Esc and top-layer stacking. Items use role="menuitem"; check items menuitemcheckbox with aria-checked.

Keyboard

  • Right-click, long-press, Shift+F10 or the context-menu key opens it; Esc closes. Arrow-key navigation inside the menu is wrapper responsibility.
