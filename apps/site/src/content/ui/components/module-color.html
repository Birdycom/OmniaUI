Module colour

Give each part of an app its own accent with one attribute: data-module="green" on a wrapper, or the module prop on a component. Buttons, tabs, fields, launcher cards, form sections, the module header and the sidebar follow; without it everything stays in the primary colour. All components.

Demo

Plain HTML and CSS: the colour comes from packages/ui/src/parts/app-module-color.css, no JavaScript.

One attribute for a whole module v0.17.0

Put data-module="green" on the element around a module (the page, a panel, the app shell). Inside it the primary button, the link button, the active tab and the focus ring of every field take the module colour; the other button variants keep their own look. A badge only follows when you ask: variant="module" is a soft tint, a badge with its own module is solid. Click in the field to see the ring.

The ten colours v0.17.0

Generic colour names, each a light-dark() pair from the OmniaCSS palette: a dark tone with white text in light mode, a light tone with dark text in dark mode. Every pair reaches 4.5:1 for the text on the button and for module text on the page, so a badge or a link in the module colour stays readable. Switch the theme to compare.

Your own colour v0.17.0

A name that is not in the list sets no colour, so you choose it: set --oc-module on the same element (a light-dark() pair: dark in light mode, light in dark mode). --oc-module-soft is mixed from it; set --oc-module-fg too when white (light mode) and near-black (dark mode) do not fit your colour.

Reference

Styles live in packages/ui/src/parts/app-module-color.css (module header: packages/blocks/src/parts/app-modulehead-module.css). Every consumer falls back on the primary token, so a page without a module looks as before.

Attribute / tokenDescription
data-module="<name>"On any element: sets the module tokens for everything inside. Names: blue, green, purple, gold, cyan, pink, red, orange, teal, slate. Another name sets no colour (set --oc-module yourself).
--oc-moduleSolid accent: primary button, active tab line, focus ring, launcher border and icon, module header icon. Read as var(--oc-module, var(--oc-primary)).
--oc-module-softTint (12%) for backgrounds: module badge, launcher icon tile, form section icon, sidebar row, module header band.
--oc-module-fgText on the solid accent (white in light mode, near-black in dark mode). Falls back on --oc-primary-foreground.
module propReact, Vue and Blade on Badge, Button / ButtonLink, LauncherCard, FormSection, Tabs, the form fields and BlockModuleHeader: data-module on that component's root.
.oc-badge--moduleBadge in the soft module tint with module text (variant="module"); a default badge with its own data-module is solid.
