Severity card

An expandable card colored by risk: a security finding, an incident or an audit item. It is a native <details>, so it opens without JavaScript. Cards with the same name open one at a time. All components.

Finding with actions

CSS component parts/app-severity-card.css

The head shows an icon, the title, small tags and the level badge. The body holds the explanation and actions. .is-resolved returns the card to neutral colors. Snippet: packages/ui/snippets/severity-card.html.

Levels

Four levels on theme tokens: --low (success), --medium (warning), --high (destructive) and --critical (a deeper red with a filled badge).

Browser support

The open animation needs ::details-content and interpolate-size; elsewhere the card opens instantly.
