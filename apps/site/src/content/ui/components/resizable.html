Resizable

Split panes whose size the user can change. This version uses the native CSS resize property: drag the grip in the corner of the resizable pane. Free-form drag handles between panes with keyboard support need a small script. All components.

Reference

Styles live in packages/ui/src/components-extra.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

Class / attributeDescription
.oc-resizableThe container: a flex row with a border and clipped corners. Give it a size (inline-size, block-size).
.oc-resizable--verticalStacks the panes; the resizable pane changes height.
.oc-resizable-panelA pane; flex: 1 takes the remaining space.
.oc-resizable-panel--resizableThe pane with the grip, with a minimum and maximum so a pane never disappears.
.oc-resizable-boxFree box: resize: both.

Accessibility

The native grip works with mouse and touch only; browsers have no keyboard equivalent. When keyboard resizing matters, add a separator with role="separator", aria-valuenow and arrow-key handling (a wrapper responsibility). Keep panes useful at their minimum size.

Platform features used

CSS featureRole
resizeHorizontal, vertical or both: the native drag grip.
overflowRequired for resize to apply.
min-inline-size / max-inline-sizeBounds for the resizable pane.
