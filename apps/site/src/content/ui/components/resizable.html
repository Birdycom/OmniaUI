Resizable

Split panes whose size the user can change. This version uses the native CSS resize property: drag the grip in the corner of the resizable panel. Free-form drag handles between panes with keyboard support need a small script. All components.

Anatomy

  • Container a flex row (or column with --vertical) with a border and clipped corners.
  • Resizable pane resize: horizontal (or vertical), overflow: auto, with min- and max-inline-size so a pane cannot disappear.
  • Other pane flex: 1 absorbs the rest.

Accessibility and keyboard

Accessibility

  • The native resize grip is mouse/touch only; there is no keyboard equivalent in browsers. If keyboard resizing matters, add a separator with role="separator", aria-valuenow and arrow-key handling (wrapper responsibility).
  • Keep panes useful at their minimum size and store the size if it should persist.

Keyboard

  • Native resize has no keyboard support.
