Kbd

Shows a keyboard key or shortcut. A single <kbd> with .oc-kbd, or several in a .oc-kbd-group. All components.

Demo

Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/kbd.html.

Open the command palette with CtrlK or press / to search.

In buttons and menus

Keys sit next to labels; .oc-dropdown-shortcut and .oc-command-shortcut accept them too.

Ctrl+Shift+P

Anatomy

  • Key kbd.oc-kbd: monospace, 1.4rem high, thicker bottom border to suggest depth.
  • Group .oc-kbd-group lays out a combination; .oc-kbd-sep adds the plus sign.

Accessibility and keyboard

Accessibility

  • Use the <kbd> element: it is announced as keyboard input.
  • Write modifier keys as words or symbols with a text alternative if the symbol is not obvious (aria-label="Command").

Keyboard

  • Not interactive.
