Icons settings

OmniaUI uses Iconify with Material Design Icons (MDI) from Pictogrammers. The <iconify-icon> web component loads only the icons a page uses and draws them as SVG. Size and color come from OmniaCSS utilities. Pick an icon in the icon catalog: click it for its code.

Load Iconify

iconify-icon 3.0.4

Add one script in <head> or before </body>. It defines the <iconify-icon> element. No web font and no separate SVG files: each element fetches its icon and draws it as SVG.

Loaded by the script below <script src="https://cdn.jsdelivr.net/npm/iconify-icon@3/dist/iconify-icon.min.js"></script>

With npm: npm install iconify-icon and import "iconify-icon";. It replaces the older @iconify/iconify script (<span class="iconify" data-icon="…">), which is no longer maintained; that markup keeps working while you switch. Latest versions: iconify.design or jsDelivr iconify-icon.

Usage

Write <iconify-icon icon="prefix:name">. Names use dashes, for example mdi:arrow-left or mdi:check-circle. Without a size class the icon is 1em high and follows the font size.

<iconify-icon icon="mdi:home" class="size-6" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi:magnify" class="size-6" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi:arrow-left" class="size-6" height="unset" aria-hidden="true"></iconify-icon>

All icon names: icon catalog, pictogrammers.com/library/mdi and the Iconify MDI set.

Size and color

Size: the OmniaCSS utility size-N (N = 1–24, N × 0.25rem) sets width and height. Add height="unset" so the SVG fills that box instead of its default 1em. Color: the SVG uses currentColor, so it follows the text color, or a color utility such as text-blue-60.

Colors

Any OmniaCSS text color utility works: text-blue-60, text-green-60 and so on, from the Omnia palette.

inherit blue-60 green-60 orange-60 red-60 violet-60 <iconify-icon icon="mdi:heart" class="size-8" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi:heart" class="size-8 text-blue-60" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi:heart" class="size-8 text-green-60" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi:heart" class="size-8 text-orange-60" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi:heart" class="size-8 text-red-60" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi:heart" class="size-8 text-violet-60" height="unset" aria-hidden="true"></iconify-icon>

MDI Light

MDI Light 0.2.63

The Light variant has thinner strokes. Use the prefix mdi-light:. The set has fewer icons than MDI; see MDI Light on Iconify.

mdi:account mdi-light:account <iconify-icon icon="mdi:account" class="size-8" height="unset" aria-hidden="true"></iconify-icon> <iconify-icon icon="mdi-light:account" class="size-8" height="unset" aria-hidden="true"></iconify-icon>

More: Icon catalog → MDI Light.

Accessibility

Decorative icons get aria-hidden="true". An icon that carries meaning on its own gets role="img" and an aria-label; an icon-only button gets the aria-label on the button.

Home <!-- Decorative: the text says it all --> <iconify-icon icon="mdi:home" class="size-6" height="unset" aria-hidden="true"></iconify-icon> Home <!-- Meaningful on its own --> <iconify-icon icon="mdi:check-circle" class="size-6 text-green-60" height="unset" role="img" aria-label="Paid"></iconify-icon> <!-- Icon-only button --> <button type="button" class="oc-btn oc-btn--icon" aria-label="Close"> <iconify-icon icon="mdi:close" class="size-6" height="unset" aria-hidden="true"></iconify-icon> </button>
