Icons — Settings

We gebruiken Iconify met Material Design Icons (MDI) van Pictogrammers. Iconify laadt alleen de iconen die je gebruikt, als SVG. Zie de Pictogrammers Iconify-guide.

Iconify laden

Voeg één script toe in <head> of vóór </body>. Geen webfont, geen aparte SVG-bestanden — Iconify haalt alleen gebruikte iconen op en vervangt placeholders door SVG.

Live: het icoon hieronder wordt door dat script geladen.

← geladen via onderstaand script <script src="https://cdn.jsdelivr.net/npm/@iconify/iconify@3/dist/iconify.min.js" crossorigin="anonymous"></script>

Voor de nieuwste URL: iconify.design of jsDelivr @iconify/iconify.

Gebruik

Plaats een placeholder: class="iconify" en data-icon="mdi:<naam>". Iconify vervangt die door het bijbehorende SVG. Naam met streepjes (bv. mdi:arrow-left, mdi:check-circle).

Live demo:

<span class="iconify" data-icon="mdi:home"></span> <span class="iconify size-6" data-icon="mdi:magnify"></span> <span class="iconify size-6" data-icon="mdi:arrow-left"></span>

Lijst van iconen: pictogrammers.com/library/mdi en Iconify MDI-collectie.

Sizing en kleur

Grootte: gebruik de OmniaCSS-utility size-N (N = 1–24). Waarde = N×0.25rem. Geen data-width/data-height nodig. Kleur: de SVG erft color (currentColor).

MDI Light (voorbeeld)

Voor de Light-variant (dunnere lijnen) gebruik je de prefix mdi-light: in Iconify. De set heet “MDI Light” op Iconify.

Live demo:

<span class="iconify size-6" data-icon="mdi-light:account" aria-hidden="true"></span>

Meer: Icon catalog → MDI Light.

Extra Collecties

OmniaCSS ondersteunt via Iconify duizenden iconen uit diverse sets. Gebruik de prefix om te wisselen.

svg-spinners:180-ring
flag:be-4x3
material-symbols:home
vscode-icons:file-type-html

Zie de Icon catalog voor meer voorbeelden per set.

Accessibility

Decoratieve iconen: aria-hidden="true" op de placeholder. Functionele iconen (bv. alleen-icoon-knop): geef de knop een aria-label of zichtbare tekst.

Live demo:

Home

<!-- Decoratief --> <span class="iconify size-6" data-icon="mdi:home" aria-hidden="true"></span> Home <!-- Alleen-icoon-knop --> <button type="button" class="oc-btn oc-btn--icon" aria-label="Sluiten"> <span class="iconify size-6" data-icon="mdi:close" aria-hidden="true"></span> </button>
