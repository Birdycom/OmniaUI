Vue

@birdycom/omniaui-vue wraps every component and block in a Vue 3 single-file component (<script setup lang="ts">). The markup and classes are exactly the ones in the HTML snippets; the CSS packages own all styling and the SFCs carry no styles. Props map to modifiers (variant, size, boolean flags), slots map to the snippet slots, and v-model is used where it is natural (inputs, switch, segmented, tabs, tag input, OTP, dialogs).

Installation

Install the Vue package next to the stylesheets it renders for. Vue (version 3.4 or newer) is a peer dependency; the package has no other dependencies.

npm install @birdycom/omniaui-vue @birdycom/omniaui @birdycom/omniaui-blocks vue
  • Required CSS: omnia_main.css, oc-layout-module.css, oc-components.css, plus oc-blocks.css when you use blocks.
  • Plugin: app.use(OmniaVue) registers every Oc* component globally. Named imports are tree-shakable (sideEffects: false).
  • Copy mode: the package ships its src/ folder too. Copy src/components/OcButton.vue (and the files in src/composables/ it imports) into your project to own the code, or import from @birdycom/omniaui-vue/src/components/OcButton.vue.
  • Manifest: @birdycom/omniaui-vue/manifest.json lists every item as { name, kind, file, snippet } and points to the matching HTML snippet.

Usage

Extra attributes and class fall through to the root element. For wrappers around a form control (checkbox, switch, password input, dropzone) class and style stay on the wrapper and every other attribute (id, name, disabled...) goes to the input.

Plugin and named imports

import { createApp } from "vue"; import { OmniaVue } from "@birdycom/omniaui-vue"; import App from "./App.vue"; createApp(App).use(OmniaVue).mount("#app"); // or import what you use: import { OcButton, OcCard, OcFormField, OcInput } from "@birdycom/omniaui-vue";

Buttons, cards and form fields

<script setup lang="ts"> import { ref } from "vue"; import { OcButton, OcCard, OcFormField, OcInput } from "@birdycom/omniaui-vue"; const name = ref(""); </script> <template> <OcCard title="Create project" description="Deploy your new project in one click."> <OcFormField label="Name" description="Shown in the sidebar." v-slot="field"> <OcInput v-model="name" :id="field.id" :aria-describedby="field.describedBy" placeholder="My project" /> </OcFormField> <template #footer> <OcButton variant="outline">Cancel</OcButton> <OcButton>Deploy</OcButton> </template> </OcCard> </template>

Dialogs: v-model:open

OcModal, OcAlertDialog, OcSheet and OcBlockWizardDialog render a native <dialog>. v-model:open is synced to showModal() / close(); Escape and backdrop clicks write false back to the model. The footer slot receives { close }.

<script setup lang="ts"> import { ref } from "vue"; import { OcButton, OcModal } from "@birdycom/omniaui-vue"; const open = ref(false); </script> <template> <OcButton @click="open = true">Open modal</OcButton> <OcModal v-model:open="open" title="Are you sure?" description="This action cannot be undone."> <template #footer="{ close }"> <OcButton variant="outline" @click="close">Cancel</OcButton> <OcButton variant="destructive" @click="close">Delete</OcButton> </template> </OcModal> </template>

Toasts: useToast and OcToastContainer

Mount OcToastContainer once near the root. useToast() shares one queue across the app and auto-dismisses after duration milliseconds (default 5000, 0 keeps the toast until dismissed).

<script setup lang="ts"> import { OcButton, OcToastContainer, useToast } from "@birdycom/omniaui-vue"; const toast = useToast(); </script> <template> <OcButton @click="toast.success('Contact saved', 'Your changes are stored.')">Save</OcButton> <OcToastContainer /> </template>

Wrapper logic built in

  • Command: filters items from the search input, keeps aria-selected on the active row, arrow keys and Enter (emits select).
  • PasswordInput: show / hide button with aria-pressed.
  • CopyField, RecoveryCodes: clipboard copy (2 second is-copied feedback) and a .txt download.
  • Dropdown, Popover, Navmenu: native popover wired through popovertarget and a generated id.
  • Table: sortable headers (v-model:sort), row selection (v-model:selected) and aria-sort / aria-selected.

Blocks

Page sections are exported as OcBlock* components. Repeating parts are data props, free-form parts are slots. The blocks render structure only: they carry no demo content. Blocks marked Pro come from @birdycom/omniaui-pro-vue (OmniaUI Pro): import { OcBlockCmsDashboard } from "@birdycom/omniaui-pro-vue".
