OmniaUI Pro

OmniaCSS and every OmniaUI component stay free and open source (MIT). OmniaUI Pro adds the larger app screens on top: dashboards, a CMS admin, a form builder, a media manager, a chat inbox, calendars, status pages and the advanced sidebar and sign-in variants. Every Pro block has a live demo on this site; the HTML, Blade, React and Vue code comes with a license.

Install

Pro sits next to the free packages: same classes, same theme tokens, same x-oc:: prefix in Blade. omniacss build includes the Pro CSS as soon as the package is installed.

# styles + HTML snippets npm install @birdycom/omniaui @birdycom/omniaui-blocks @birdycom/omniaui-pro npx omniaui add cms-dashboard # React or Vue components npm install @birdycom/omniaui-pro-react # or @birdycom/omniaui-pro-vue # Laravel Blade: <x-oc::block.cms-dashboard> composer require birdycom/omniaui-pro-laravel

The Pro packages are not on the public npm registry: you get access with your license.
