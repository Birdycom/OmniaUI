Laravel

birdycom/omniaui-laravel turns every component and block into an anonymous Blade component under the prefix oc: <x-oc::button variant="primary">, <x-oc::block.app-shell>. The markup and classes are exactly the ones in the HTML snippets; the CSS packages own all styling and dark mode (light-dark()), so there are no colors in PHP. Props map to modifiers, slots become $slot and named slots, and $attributes is merged onto the root element. React and Vue have their own wrappers.

Installation

PHP 8.2+ and Laravel 11, 12 or 13. The service provider is auto-discovered.

composer require birdycom/omniaui-laravel php artisan omniacss:install npm install && npm run dev
  • omniacss:install: detects Vite, adds @birdycom/omniacss and @birdycom/omniaui (--blocks adds @birdycom/omniaui-blocks) to package.json, puts the @import lines at the top of resources/css/app.css, publishes config/omniacss.php and prints the next steps. Use --dry-run to see the changes without writing anything.
  • Layout: add the @omniacss directive to the <head> of your layout.
<head> <meta charset="utf-8"> @omniacss </head>

Set source in config/omniacss.php (or OMNIACSS_SOURCE in .env). @omniacss('cdn') overrides it for one page.

Usage

Props become modifiers (variant, size, boolean flags), the default slot is the content and named slots fill regions. Extra attributes (class, wire:*, x-*, data-*) are merged onto the root element. Form controls pass their attributes to the real input, so name, value and validation work as expected.

<x-oc::card title="Create project" description="Deploy your new project in one click."> <x-oc::form-field label="Name" for="name" :error="$errors->first('name')"> <x-oc::input id="name" name="name" placeholder="My project" /> </x-oc::form-field> <x-slot:footer> <x-oc::button variant="outline">Cancel</x-oc::button> <x-oc::button type="submit">Deploy</x-oc::button> </x-slot:footer> </x-oc::card>

Dialogs without JavaScript

modal, sheet and alert-dialog render a native <dialog>; buttons open and close it with command and commandfor.

<x-oc::modal id="delete" title="Are you sure?" size="sm"> <x-slot:trigger> <x-oc::button command="show-modal" commandfor="delete">Delete</x-oc::button> </x-slot:trigger> This action cannot be undone. <x-slot:footer> <x-oc::button variant="outline" command="close" commandfor="delete">Cancel</x-oc::button> <x-oc::button variant="destructive">Delete</x-oc::button> </x-slot:footer> </x-oc::modal>

Pagination

<x-oc::pagination :paginator="$users" />

Blocks

Every block is available as <x-oc::block.NAME> and needs @birdycom/omniaui-blocks. Without slots a block renders the snippet markup unchanged; a named slot replaces only its own region. Blocks marked Pro come from birdycom/omniaui-pro-laravel (OmniaUI Pro) and use the same x-oc::block. prefix.

<x-oc::block.app-shell height="40rem"> <x-slot:sidebar> <x-oc::sidebar label="Main navigation"> <x-oc::sidebar.group label="Platform"> <x-oc::sidebar.item href="/" current>Dashboard</x-oc::sidebar.item> <x-oc::sidebar.item href="/contacts" badge="12">Contacts</x-oc::sidebar.item> </x-oc::sidebar.group> </x-oc::sidebar> </x-slot:sidebar> <h1 class="oc-heading-title">Contacts</h1> </x-oc::block.app-shell> <x-oc::block.hero> <x-slot:title>Build faster</x-slot:title> </x-oc::block.hero>

Own the code

omniacss:publish-components copies Blade files into resources/views/components/oc. Published files are used as <x-oc.button>; the package keeps serving <x-oc::button>.

php artisan omniacss:publish-components button card modal php artisan omniacss:publish-components block.app-shell php artisan omniacss:publish-components --all php artisan omniacss:publish-components --list

Livewire

birdycom/omniaui-livewire adds Livewire 3 variants where state matters. It uses the same oc prefix.

composer require birdycom/omniaui-livewire
ComponentWhat it does
wire.input, wire.textarea, wire.select, wire.switch, wire.checkboxmodel, live, blur, debounce shorthand for wire:model; validation errors set the error state
wire.segmented, wire.otp, wire.tag-inputBound to a property: every radio, a one-time code with complete="verify", an array of tags via $wire.entangle
