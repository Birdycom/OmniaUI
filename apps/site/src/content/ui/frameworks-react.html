React

@birdycom/omniaui-react wraps every component and block in a typed React function component. The markup and classes are exactly the ones in the HTML snippets; the CSS packages own all styling. Props map to modifiers (variant, size, boolean flags), slots become children and named props (title, description, actions, footer). Works with React 18 and 19, including server components (interactive files carry "use client").

Installation

Install the React package next to the stylesheets it renders for. React and React DOM are peer dependencies (version 18 or newer).

npm install @birdycom/omniaui-react @birdycom/omniaui @birdycom/omniaui-blocks react react-dom
  • Required CSS: omnia_main.css, oc-layout-module.css, oc-components.css, plus oc-blocks.css when you use blocks.
  • Copy mode: the package ships its src/ folder too. Copy src/components/Button.tsx (and src/utils.ts, src/hooks.tsx) into your project to own the code, or import from @birdycom/omniaui-react/src/components/Button.
  • Manifest: @birdycom/omniaui-react/manifest.json lists every item as { name, kind, file, snippet } and points to the matching HTML snippet.

Usage

Import components and blocks from the package root. Refs are forwarded, extra props are spread on the root element and className is merged with the component classes.

Buttons, cards and form fields

import { Button, Card, CardHeader, CardTitle, CardContent, CardFooter, FormField, Input } from "@birdycom/omniaui-react"; export function CreateProject() { return ( <Card> <CardHeader> <CardTitle>Create project</CardTitle> </CardHeader> <CardContent> <FormField label="Name" description="Shown in the sidebar."> <Input placeholder="My project" /> </FormField> </CardContent> <CardFooter> <Button variant="outline">Cancel</Button> <Button size="sm">Deploy</Button> </CardFooter> </Card> ); }

Dialogs: the open prop

Modal, AlertDialog, Sheet and BlockWizardDialog render a native <dialog>. The open prop is synced to showModal() / close() in an effect; Escape and backdrop clicks come back through onOpenChange(false). Use defaultOpen for uncontrolled usage and ModalClose for buttons that close the dialog.

const [open, setOpen] = useState(false); <Button onClick={() => setOpen(true)}>Open modal</Button> <Modal open={open} onOpenChange={setOpen} title="Are you sure?" description="This action cannot be undone." footer={<> <ModalClose variant="outline">Cancel</ModalClose> <ModalClose variant="destructive">Delete</ModalClose> </>} />

Toasts: ToastProvider and useToast

Wrap your app once in ToastProvider; it keeps the queue, renders the fixed container and auto-dismisses after duration milliseconds (default 5000, 0 keeps the toast until dismissed).

function SaveButton() { const { toast } = useToast(); return ( <Button onClick={() => toast({ variant: "success", title: "Contact saved", description: "Your changes are stored." })}> Save </Button> ); } <ToastProvider><App /></ToastProvider>

Wrapper logic built in

  • Command: filters items from the search input (non-matching rows get hidden), keeps aria-selected on the active row, arrow keys and Enter.
  • PasswordInput: show / hide button with aria-pressed.
  • CopyField: clipboard copy with the 2 second is-copied feedback.
  • Dropdown, Popover, NavmenuDropdown: native popover wired through popovertarget and a generated id.
  • Controlled or uncontrolled: OtpInput, Segmented, Tabs, TagInput, ThemeSwitch, ColorField, Collapsible take value / defaultValue / onChange (or open / defaultOpen / onOpenChange).
