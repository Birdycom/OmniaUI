Icons

OmniaCSS UI uses Iconify with Material Design Icons (MDI) from Pictogrammers: only icons used on the page are loaded as SVG. No icon font; no full set in the bundle. See the Pictogrammers Iconify guide and our Settings page for reference and sizing.

Installation

Load the iconify-icon web component once (CDN or npm). Each <iconify-icon> fetches its icon and draws it as SVG.

  • CDN: Add <script src="https://cdn.jsdelivr.net/npm/iconify-icon@3/dist/iconify-icon.min.js"></script> in <head>.
  • npm: npm install iconify-icon, then import "iconify-icon";.
<script src="https://cdn.jsdelivr.net/npm/iconify-icon@3/dist/iconify-icon.min.js"></script>

Usage

Use <iconify-icon icon="mdi:<name>"> (MDI), icon="mdi-light:<name>" (MDI Light), or other sets like svg-spinners:, flag:, material-symbols:, and vscode-icons:. In the catalog, regular tiles = MDI, violet background = MDI Light. Size with size-N (N 1–24) and height="unset". Full list: Icon catalog.

Example

One icon to show the pattern. Browse more in the catalog.

icon="mdi:home" + class="size-8" height="unset" <iconify-icon icon="mdi:home" class="size-8" height="unset" aria-hidden="true"></iconify-icon>
