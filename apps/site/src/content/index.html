What is inside

Built from real apps, not from a mood board.

Every component started in a production app: an ERP, a workshop planner, a client CMS. That is why the data table has bulk actions and the forms have Belgian VAT and phone fields.

FormsInputs, selects, OTP, phone, number and time fields, password rules, tag input. DataData table with sorting, columns, bulk actions and CSV; charts, stat cards, trees. MediaLightbox, document viewer, carousel, media cards, chat messages and attachments. App UXDialogs, sheets, toasts, cookie consent, busy overlay, command palette, sidebars. MarketingHero, features, pricing, FAQ, timeline, portfolio and services sections. AdminWizard pages, plus the CMS dashboard, form builder, media manager and settings page in OmniaUI Pro.
