    Portfolio grid

    A "Our work" section: heading, short lead, a link to all projects and a responsive grid of project cards. Install with npx omniaui add portfolio-grid. All blocks.

    Demo

    blocks/portfolio-grid.html0 KB JavaScript

    The grid auto-fills cards from 18rem; --two makes them wider.

    Reference

    Styles live in packages/blocks/src/parts/site-portfolio-grid.css; the cards come from the project card component.

    Class / attributeDescription
    .oc-block-portfolioSection. Modifier --two: wider cards (from 26rem)
    .oc-block-portfolio-headTitle block left, link right; wraps on small screens
    .oc-block-portfolio-leadShort intro below the title
    .oc-block-portfolio-gridAuto-fill grid; --oc-portfolio-min sets the card width
    .oc-project-cardOne project (component)
