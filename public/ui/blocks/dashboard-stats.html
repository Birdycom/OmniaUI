    About OmniaUI Pro

    Reference

    Styles live in packages/pro/src/pro.css (OmniaUI Pro). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-block-kpisAuto-fit grid
    .oc-block-kpiOne card
    .oc-block-kpi-headLabel + icon row
    .oc-block-kpi-label / -icon / -valueLabel, optional icon, big number
    .oc-block-kpi-deltaTrend. Modifiers: --up (success), --down (destructive)
    .oc-block-kpi-noteMuted note inside the delta line
