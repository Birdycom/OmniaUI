    Type picker

    A gallery of the content types a user can add to a page, a step or a lesson. Every card is a label around a radio, so picking works with a click, a tap or the arrow keys without JavaScript, and each card shows a small real example of the block instead of grey bars. Install with npx omniaui add type-picker. All blocks.

    Demo

    blocks/type-picker.htmlBaseline

    Native radios in cards; the search field and the category chips use a few optional lines of script.

    Type picker v0.16.0

    Click a card, or press Tab to reach the cards and use the arrow keys: the picked card gets a blue frame and a check mark. Question is greyed out because this step already has one. Type time in the search field or click a category to filter the cards; the 15 lines of script at the end of the code do that, the picking itself needs no script.

<script>
  // Optional: filter the cards of every .oc-block-type-picker by search text and category. Without it all cards stay visible.
  document.querySelectorAll(".oc-block-type-picker").forEach((picker) => {
    const filter = () => {
      const q = (picker.querySelector(".oc-block-type-picker-search")?.value || "").trim().toLowerCase();
      const cat = picker.querySelector(".oc-block-type-picker-cats input:checked")?.value || "all";
      let shown = 0;
      picker.querySelectorAll(".oc-block-type-picker-item").forEach((item) => {
        item.hidden = !((cat === "all" || item.dataset.category === cat) && item.textContent.toLowerCase().includes(q));
        if (!item.hidden) shown++;
      });
      const empty = picker.querySelector(".oc-block-type-picker-empty");
      if (empty) empty.hidden = shown > 0;
    };
    picker.addEventListener("input", (e) => { if (e.target.closest(".oc-block-type-picker-tools")) filter(); });
  });
</script>

    Action mode: click to add, drag, say why not v0.17.0

    In an editor drawer you do not pick and confirm: a click adds the block at once. .oc-block-type-picker--action makes every card a <button>, so Enter adds it too and the arrow keys only move the focus (nothing is added by moving). Cards with draggable="true" can be dragged into your editor. A card that cannot be used now keeps the focus (aria-disabled="true", not disabled) and says why in .oc-block-type-picker-reason, linked with aria-describedby. Since v0.17.0 the picker CSS is in the components CSS too, so an editor that does not load the blocks CSS can use it.
