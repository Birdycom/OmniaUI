    Contact grid

    Contact information as a grid of cards: e-mail, phone, office address and opening hours, each with a soft product mark. Install with npx omniaui add contact-grid. All blocks.

    Demo

    The address card is an <address>. Links (mail, phone) are real mailto: and tel: links.

    Reference

    Styles live in packages/blocks/src/parts/site-contact-grid.css.

    Class / attributeDescription
    .oc-block-contactSection. Modifier --plain: no frames, a line on top
    .oc-block-contact-head / -heading / -leadIntro: eyebrow, title, text
    .oc-block-contact-gridAuto-fill grid (cards from 15rem)
    .oc-block-contact-cardOne card (article or address)
    .oc-block-contact-titleCard heading
    .oc-block-contact-lineInfo line (p, span or a link)
