    Form builder

    An admin screen to build a form: the fields as cards you drag into order, a palette of field types, and a dialog to edit one field. The options row in the dialog appears only for select, checkboxes and radio, with CSS alone. The script adds, edits and deletes fields in the page (the name follows the label), reorders them by drag and drop and reports every change with an oc-formbuilder-change event, so saving stays in your app. Comes from the contact form builder of the Verdavita admin. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.

    Demo

    Block blocks/form-builder.html Baselinev0.9.1

    Try it: click a field type on the palette, fill in a label (the name follows) and save; the new card appears in the list. Edit and delete work on every card, and cards can be dragged. Nothing is saved here: a real app listens for oc-formbuilder-change.

    Reference

    Styles live in packages/pro/src/parts/app-form-builder.css (OmniaUI Pro). Colors are Omnia theme tokens only.

    Class / attributeDescription
    .oc-block-form-builderBlock (size container)
    .oc-block-form-builder-top / -title / -subtitle / -actionsHeader with save and preview
    .oc-block-form-builder-canvasol of fields; .is-dragover while dragging over
    li.oc-block-form-builder-field[draggable][data-id]One field; --off = disabled; .is-dragging, .is-drop-before / -after
    .oc-block-form-builder-main / -label / -chips / -field-actionsName, badges (type, required, key) and buttons
    .oc-block-form-builder-emptyShown when the list has no fields
    .oc-block-form-builder-palette / -types / -type[data-type]Field types; each opens the dialog
    .oc-block-form-builder-dialog / -grid / -options / -togglesField dialog; -options only for choice types
    template.oc-block-form-builder-templateMarkup of one empty card, used when a field is added
    [data-action=edit] / [data-action=delete]Card buttons: open the dialog with this field / remove the card
    event oc-formbuilder-changeAfter add, edit, delete and reorder: { action, field, order }

    <script>
document.addEventListener("oc-formbuilder-change", async (e) => {
  // e.detail = { action: "add" | "edit" | "delete" | "reorder", field: { id, label, name, type, required, enabled, options, placeholder }, order: ["1", "3", "2"] }
  await fetch("/admin/contact-form/fields", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(e.detail) });
});
</script>

    Render the saved fields as cards with their data in data-* attributes; the <template class="oc-block-form-builder-template"> is only used for cards added in the browser.
