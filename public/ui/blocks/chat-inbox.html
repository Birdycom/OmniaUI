    Chat inbox Pro

    A split inbox for an app: conversations on the left with a search field, the last message, the time and an unread dot; the selected message thread on the right with the composer. Selecting a conversation is CSS only (radio inputs and :has()), the unread count is a CSS counter, and in a narrow container it becomes list or thread with a back link. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.

    Demo

    Block blocks/chat-inbox.html Baselinev0.9.1

    Open the unread conversations and watch the dot and the counter go. Type a reply and press Send (or Ctrl + Enter): the bubble appears and the row shows your message. Switch the preview to phone width to see the one-column layout.

    About OmniaUI Pro

    Reference

    Styles live in packages/pro/src/parts/app-chat-inbox.css (OmniaUI Pro). The thread, bubbles, attachments and composer are the message-thread, message, attachment and chat-composer components. Colors are Omnia theme tokens only.

    Class / attributeDescription
    .oc-block-chat-inboxSize container; height from --oc-block-chat-inbox-height (36rem)
    .oc-block-chat-inbox-layoutTwo-column frame (list | view), one column under 36rem
    input.oc-block-chat-inbox-noneExtra radio in the group: no conversation open (empty state, list on narrow screens)
    .oc-block-chat-inbox-list / -head / -title / -searchLeft column with title and search field
    ul.oc-block-chat-inbox-items > li > label.-item (--unread)Conversation row with a hidden radio
    -body / -top / -name / -time / -subject / -preview / -tagsRow content: name and time, subject, last message, badges
    .oc-block-chat-inbox-dotUnread dot (hidden once the row is opened)
    p.oc-block-chat-inbox-unreadFooter line; the unread count comes from a CSS counter
    .oc-block-chat-inbox-view > section.oc-message-threadOne thread per row, same order
    .oc-block-chat-inbox-emptyShown while no conversation is open
    label.oc-block-chat-inbox-backBack arrow in a thread header (narrow only)

    Platform features used

    FeatureRole
    :has() + radio inputsSwitch threads, clear unread, narrow list / thread
    @container (container-type: inline-size)One column in a narrow block, whatever the viewport
    CSS countersUnread count without JavaScript
    flex-direction: column-reverseThreads open at the newest message

    How it works

    • Selecting: every row is a <label> with a hidden radio (one shared name). .oc-block-chat-inbox:has(li:nth-child(2) input:checked) shows the second .oc-message-thread. Keep the threads in the same order as the rows (up to 8; add rules for more, or render only the open thread on the server).
    • Unread: rows with --unread show a dot and bold text until their radio is checked. Each unread, unopened row increments a CSS counter that the footer line prints ("2 unread").
    • Narrow: the block is a size container. Under 36rem it shows the list or the thread. The back arrow is a <label for> of an extra radio in the same group ("no conversation"); on a wide screen that radio shows the empty state.
    • Opens at the newest message: each thread scrolls with flex-direction: column-reverse, so new bubbles stay in view.
    • Optional script (about 30 lines): appends a sent message (with textContent), updates the preview and time of the row, filters the rows while you type in the search field, and makes Enter / Space work on the back arrow. In an app the form posts to your server.

    Accessibility and keyboard

    • The rows are a native radio group: Tab reaches the selected conversation and the arrow keys switch between conversations. The focused row gets a visible ring through :has(input:focus-visible).
    • The unread dot carries a visually hidden "Unread" text, so it is not color-only information.
    • Each thread is a labelled <section> with a role="log" scroll area; the hidden threads are display: none, so screen readers only meet the open one.
    • Hover and selection transitions are off under prefers-reduced-motion: reduce.
