    About with timeline

    An "About us" section: a picture with a floating badge next to the story of the company, ending in the timeline component. Install with npx omniaui add about-timeline. All blocks.

    Demo

    blocks/about-timeline.html0 KB JavaScript

    Without an img the picture is an accent gradient placeholder. Two columns from a 52rem wide container.

    Reference

    Styles live in packages/blocks/src/parts/site-about-timeline.css.

    Class / attributeDescription
    .oc-block-aboutSection (a size container). Modifier --reverse: picture right
    .oc-block-about-innerTwo-column grid from 52rem
    .oc-block-about-mediafigure: an img, or empty for the accent placeholder
    .oc-block-about-badgeGlass badge on the picture (strong = big number)
    .oc-block-about-copy / -titleText column and heading
    .oc-timelineThe timeline component
