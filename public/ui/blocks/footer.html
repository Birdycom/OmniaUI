    Reference

    Styles live in packages/blocks/src/blocks.css. Colors are theme tokens, so everything follows light and dark mode.

    ClassDescription
    .oc-block-footerFooter wrapper
    .oc-block-footer-gridAuto-fit grid for link columns
    .oc-block-footer-colSingle link column with heading and list
    .oc-block-footer-bottomBottom bar
