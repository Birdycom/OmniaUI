    About OmniaUI Pro

    Reference

    Styles live in packages/pro/src/pro.css (OmniaUI Pro). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Interactions are native HTML and CSS (details, popover, dialog, :has()).

    Class / attributeDescription
    .oc-block-chartChart card; parts -head, -title, -desc, -foot, -value
    .oc-chart-barsBar chart (components package): set --oc-bar on each li
    .oc-block-chart-svgStretched SVG viewBox with preserveAspectRatio="none"; draw with polyline and polygon
    .oc-block-chart-line / -area / -gridSVG strokes and fills; series color via -s1, -s2, -s3 (maps to --oc-chart-1 to --oc-chart-3)
    .oc-block-chart-monthsAxis labels row under an SVG
    .oc-block-chart-donutDonut from conic-gradient (edit the stops); -label for the center text
    .oc-block-chart-radialRadial progress: set --oc-radial from 0 to 100
    .oc-block-chart-hbarsHorizontal bars: li with a name, an i (set --oc-bar) and a b (value)
    .oc-block-chart-sparkCompact sparkline SVG
    .oc-chart-legend / .oc-chart-swatchLegend from the components package
