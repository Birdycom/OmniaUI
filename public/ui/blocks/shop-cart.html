    Shop cart Pro

    The cart: one line per product with photo, variant, unit price, quantity and line total, a remove button, and a summary with subtotal, delivery (free from an amount), included VAT, a discount code and the checkout button. shop.js keeps the totals right and shows the empty state. All blocks.

    About OmniaUI Pro

    What is in it

    Styles: packages/pro/src/parts/app-shop-front.css and the head of app-products.css (OmniaUI Pro); the parts are free components (price, stock, rating, gallery, quantity, spec list, tabs, stepper). Scripts: shop.js, form-extras.js.

    PartDescription
    .oc-block-shopThe block (a container): page head and content, full width.
    Eventsoc-shop-filter { shown } on the catalog, oc-cart-change { lines, subtotal, total } on the cart (from shop.js).
    Blade<x-oc::block.shop-cart /> renders this markup; fill it from your own data.
