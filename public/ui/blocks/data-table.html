    Data table

    The list page pattern: a card that holds a toolbar (search, status pills), a sortable table with selection and row actions, and a footer with the entry count, page size and pages. With data-table.js it works in the browser (try search, the pills, sorting, selecting and deleting); server side (Livewire) the same look renders links instead. Type tabs, filter selects, rich name cells and cards: the Data table component. All blocks.

    Reference

    Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: title, description, header actions, toolbar, table, footer.

    Class / attributeDescription
    .oc-card.oc-block-datatableCard root
    .oc-block-datatable-head / -title / -descriptionCard header area
    .oc-block-datatable-bodyPadded body
    .oc-table-toolbarSearch + filters row (.oc-table-toolbar-spacer pushes items right)
    [data-oc-data-table]On the card: data-table.js wires search, pills, sort, selection, pages (data-oc-live="true" = the demo changes its own rows)
    .oc-filter-pills / .oc-filter-pillStatus filter (data-oc-filter="active|all|archived", aria-current="true"); links server side
    .oc-block-datatable-bulkSelection bar (appears when rows are selected)
    .oc-table-wrap > .oc-tableTable with .oc-table-sort headers, .oc-table-actions cells (see Table)
    .oc-table-footerCount (data-oc-summary), page size (data-oc-page-size) and pages (data-oc-pager; server side .oc-pagination)
