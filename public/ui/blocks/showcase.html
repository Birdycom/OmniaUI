        ['href' => '/work/project-1', 'accent' => 'green', 'image' => '/img/blocks/hero.jpg', 'imageAlt' => 'Project 1, home page', 'pill' => 'Website with CMS', 'name' => 'Project 1', 'summary' => 'Garden design and maintenance', 'more' => 'View the project'],

    Reference

    Styles live in packages/ui/src/showcase.css. Colors are theme tokens, so everything follows light and dark mode.

    ClassDescription
    .oc-browser-frameBrowser window frame: __bar (dots) + img or __body
    .oc-product-cardCard (padding removed with .p-0)
    --oc-card-minWider cards in .oc-card-grid

    Framework wrappers

    The same markup and classes as React, Vue and Blade components. Their props follow the class modifiers on this page; see the source files below.
