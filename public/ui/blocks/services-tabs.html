    Services tabs

    A services section with one tab per service: a hero image or video, text, key points, actions and the documents of that service in document viewers. Built on the radio tabset, so it needs no JavaScript (up to six services). Below 48rem the tabs become a scrolling row. Comes from the services page of the Verdavita site. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.

    About OmniaUI Pro

    Reference

    Styles live in packages/pro/src/parts/site-services-tabs.css (OmniaUI Pro). Colors are Omnia theme tokens only.

    Class / attributeDescription
    .oc-block-servicesSection (size container)
    .oc-block-services-head / -title / -leadEyebrow, heading and intro
    .oc-block-services-tabsOn the .oc-tabset: vertical list left, panel right
    .oc-block-services-iconIcon tile in a tab
    .oc-block-services-panelInside each .oc-tab-panel
    .oc-block-services-mediaHero img, video or placeholder (16 : 7, 16 : 9 when narrow)
    .oc-block-services-name / -text / -points / -actionsService title, text, check list and buttons
    .oc-block-services-docs / -docs-titleDocuments row with an .oc-doc-viewer-grid
