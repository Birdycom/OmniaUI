    Masonry gallery Pro

    A project gallery: photos of different heights packed without gaps, a caption on hover or focus, category chips that filter without JavaScript, and every photo opens the lightbox. The layout is CSS columns, and display: grid-lanes where the browser supports real masonry. Comes from the projects page of the Verdavita site, which used a layout script and a lightbox library. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.

    About OmniaUI Pro

    Reference

    Styles live in packages/pro/src/parts/site-masonry-gallery.css (OmniaUI Pro). Colors are Omnia theme tokens only.

    Class / attributeDescription
    .oc-block-masonrySection (size container)
    .oc-block-masonry-head / -title / -leadHeading row
    .oc-block-masonry-filterOn an .oc-chip-filter with radio inputs: first = all, then up to six categories
    .oc-block-masonry-gridThe masonry; gap via --oc-masonry-gap
    button.oc-block-masonry-itemOne photo; data-cat="1 3" = category numbers; opens the lightbox
    .oc-block-masonry-item--tall / --square / --wideShapes for placeholders (real images keep their own height)
    .oc-block-masonry-captionTitle and meta, shown on hover and focus (always on touch screens)
