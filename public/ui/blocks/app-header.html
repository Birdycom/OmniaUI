    Reference

    Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes. Slots: toggle, module nav, actions (theme switch, workspace select, user dropdown).

    Class / attributeDescription
    .oc-block-appbarBar (flex row)
    .oc-block-appbar-navNavigation area; contains an .oc-navmenu
    .oc-block-appbar-actionsRight-aligned actions (theme switch, switchers, user menu)
    .oc-block-appbar-titleOptional page title
