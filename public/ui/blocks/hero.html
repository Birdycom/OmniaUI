    Reference

    Styles live in packages/blocks/src/blocks.css. Colors are theme tokens, so everything follows light and dark mode.

    ClassDescription
    .oc-block-heroCentered hero wrapper
    .oc-block-hero-badgePill badge above headline
    .oc-block-hero-actionsFlex row for CTA buttons
    .oc-block-hero-splitTwo-column grid hero
    .oc-block-hero-visualImage/visual placeholder in split layout
