    CMS dashboard Pro

    The admin home of a small website CMS: a dark sidebar with the content sections (pages, services, projects, questions, settings), a top bar with the page title and the signed-in user, a flash message, one tile per content type with its count and "manage / add" links, and the latest changes. The sidebar uses the new .oc-sidebar--dark modifier, which keeps it dark in the light theme. Comes from the Verdavita admin header, sidebar and dashboard. Part of OmniaUI Pro: the code comes with a Pro license. All blocks.

    About OmniaUI Pro

    Reference

    Styles live in packages/pro/src/parts/app-cms-dashboard.css (OmniaUI Pro). Colors are Omnia theme tokens only.

    Class / attributeDescription
    .oc-block-cmsOn the .oc-block-sb frame; height via --oc-block-sb-height
    aside.oc-sidebar.oc-sidebar--darkDark sidebar: color-scheme: dark switches every theme token inside it
    .oc-block-cms-bar / -title / -userTop bar: page title, user link and log-out button
    .oc-block-cms-body / -section-titleScrolling content with small section headings
    .oc-block-cms-tiles > .oc-block-cms-tileOne content type; modifiers --green, --orange, --magenta
    .oc-block-cms-tile-icon / -count / -label / -linksIcon tile, number, name and the manage / add links
