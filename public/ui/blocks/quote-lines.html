    Quote lines

    The lines of a quote or an order, in the order you choose: drag a line by its grip, drag a column edge to make it wider, and pick the columns in the header. The bordered data table with the totals below. Built on the free Data table component plus the Pro table script. All blocks.

    About OmniaUI Pro

    What is in it

    Styles: packages/pro/src/parts/app-quote-lines.css (OmniaUI Pro) for the page head and totals; the table is the free .oc-data-table with data-table.js, dragging and widths come from data-table-pro.js.

    PartDescription
    .oc-block-linesThe block: page head, the lines and the totals, full width.
    .oc-block-lines-headBreadcrumb and title with a status badge on the left, Preview and Add line on the right.
    Lines.oc-data-table--bordered with data-page-size="0" (every line on one page), a grip per line (.oc-sortable-row-grip), width handles in the header and the column menu. A drop fires oc-datatable-reorder with the keys in the new order.
    .oc-block-lines-itemProduct name in bold with the description below.
    .oc-block-lines-totalsSubtotal, VAT and total as a <dl>, right aligned; .is-total is the bold last line.
    React / Vue / Blade<BlockQuoteLines title breadcrumb actions table totals />, <OcBlockQuoteLines> (slot head-actions; other slots go to the table) and <x-oc::block.quote-lines />.
