    About OmniaUI Pro

    Reference

    Styles live in packages/pro/src/pro.css (OmniaUI Pro). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-card.oc-block-onboardingCard root
    .oc-block-onboarding-headIcon + heading
    .oc-block-onboarding-progressProgress bar + text (.oc-progress)
    .oc-checklist.oc-checklist--cardRows (see Checklist)
