    Event scene Pro

    Show a live demo of an event app where it would really run: a hall in 3D, made only with CSS. The customer screen hangs as an LED wall above the stage, the control screen stands on a laptop at the front of house, and in between a crowd bobs, jumps and waves with phones in the air while beams sweep through the haze. Both screens are live frames, so an iframe of your own demo runs in them. All blocks.

    Demo

    0 KB JavaScriptBaselinev0.13.0

    Here the screens show two still images; put an <iframe> of your demo in each live frame. With reduce motion the hall stands still.

    Event scene Pro

    Part of OmniaUI Pro. The HTML, Blade, React and Vue code of this block comes with an OmniaUI Pro license.

    About OmniaUI Pro

    What is in it

    Styles: packages/pro/src/parts/site-event-scene.css (OmniaUI Pro) with the Pro device mockups, the free live frame and watermark. No script; only transform and opacity move.

    PartDescription
    figure.oc-block-sceneThe hall: 16:10, square on a phone; a size container.
    -haze, -truss (lamps i with beams b), -stage, -floorSmoke, five sweeping spots that change color, the stage and colored washes on the floor.
    -led + -led__panelThe LED wall: .oc-device--display --glow around an .oc-live-frame (--oc-live-w / --oc-live-h = virtual size of the page).
    -crowdSVG silhouettes in four rows (-row0..3), groups that bob or jump (-jump), arms that wave (-arm), phones with a light (-phone).
    -tech, -desk, -console (__meters, __knobs, __faders)Front of house: two technicians, the desk edge and a mixing console with VU meters and faders (--f).
    -laptop + -laptop__panelThe laptop: .oc-device--laptop around an .oc-live-frame.
    --oc-scene-*Colors from the site tokens: light, glow, lamp, violet, magenta, amber, ink, metal, vu-low/-mid/-high, body-top, body-far-top.
    .oc-watermarkOptional text over the whole hall (Demo, Concept).

<!-- React -->
<BlockEventScene watermark="Demo" led={{ content: <iframe src="/demo/screen" title="Customer screen" /> }} laptop={{ content: <iframe src="/demo/control" title="Control screen" /> }} />

<!-- Vue -->
<OcBlockEventScene watermark="Demo">
  <template #led><iframe src="/demo/screen" title="Customer screen" /></template>
  <template #laptop><iframe src="/demo/control" title="Control screen" /></template>
</OcBlockEventScene>
