    Reference

    Styles live in packages/blocks/src/blocks.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-block-formpageColumn wrapper (max 56rem)
    details.oc-collapsibleSection (see Collapsible section)
    .oc-block-formpage-gridTwo-column field grid from 40rem
    .oc-block-formpage-actionsSticky bottom action bar
