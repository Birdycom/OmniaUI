    Product grid

    Grid of product cards. Every card can have its own accent color (.oc-accent--green, --orange, --violet, --cyan, ...): icon tile, tagline and hover border follow it. On hover the card lifts a few pixels after a short delay (0.3s ease, 0.08s), without a glow. Install with npx omniaui add product-grid. All blocks.

    Reference

    Styles live in packages/ui/src/showcase.css. Colors are theme tokens, so everything follows light and dark mode.

    ClassDescription
    .oc-card-gridResponsive grid (min width via --oc-card-min)
    .oc-product-cardCard with a soft hover lift (0.3s ease after 0.08s; --oc-hover-duration, --oc-hover-ease, --oc-hover-delay) and an accent border; no glow
    .oc-product-card__top / __name / __tagline / __summary / __moreCard parts
    .oc-icon-tileRounded accent tile for an icon or logo
    .oc-pillSmall rounded label
    .oc-accent--*Accent color presets from the Omnia palette
