    Contact form

    A contact form in a panel with a soft glow, next to a column of contact cards (mail, phone, visit, helpdesk). The fields are a filled form with a hint in a label, a honeypot against bots and a note next to the button. It works without JavaScript (POST + redirect); contact-form.js sends it without a reload and shows the field errors or the result in place. Install with npx omniaui add contact-form. All blocks.

    Sending without a reload

    npx omniaui copy-js contact-form puts oc-contact-form.js in public/js; load it with <script type="module" src="/js/oc-contact-form.js"></script> and it binds every form[data-contact-form].

    • Request: POST of the form data to form.action with Accept: application/json.
    • Answer: { "sent": true } (200), or { "sent": false, "errors": { "email": "…", "form": "…" } } (422). errors.form is the message above the form; without it the alert says Please check the fields in red.
    • While it sends: aria-busy="true" on the form, the button disabled and its label ([data-contact-label]) set to Sending….
    • Texts: data-busy-label, data-error-fields and data-error-network on the form, for your language.
    • Done: the form resets, [data-contact-body] hides, [data-contact-success] shows and gets the focus; the form fires oc-contact-sent. [data-contact-again] brings the form back.

    // Laravel: one route for both (JSON for the script, a redirect without it)
public function send(Request $request)
{
    $data = $request->validate(['name' => 'required', 'email' => 'required|email', 'message' => 'required']);
    if ($request->filled('website')) { return $request->wantsJson() ? ['sent' => true] : back(); } // honeypot
    Mail::to('info@company1.example')->send(new ContactMessage($data));

    return $request->wantsJson() ? ['sent' => true] : back()->with('sent', true);
}

    Laravel answers a failed validate() on a JSON request with 422 and { errors: { field: ["…"] } }; the script takes the first message of a list.
