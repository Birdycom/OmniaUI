    Glass navigation

    The navigation of the newest phones and desktops: a clear glass sheet with an action pill and a menu bar, and what is behind it bends and shifts colour through the glass (the lens). Click the items: the raised bubble moves. It builds on the free Glass component (liquid glass, menu bar, amount). The lens draws in Chrome, Edge, Opera and Electron; Safari and Firefox show the plain liquid glass. All blocks.

    Demo

    0 KB JavaScriptBaselinev0.12.6

    Live: click Home, Feed, Search or Settings; the colours behind the glass move slowly.

    Glass navigation Pro

    Part of OmniaUI Pro. The HTML, Blade, React and Vue code of this block comes with an OmniaUI Pro license.

    About OmniaUI Pro

    What is in it

    Styles: packages/pro/src/parts/site-glass-nav.css (OmniaUI Pro: the lens and the block layout) on top of the free glass parts. No script.

    PartDescription
    .oc-glass--lens + svg.oc-glass-defsThe lens: an SVG filter (#oc-glass-lens, once per page) that bends the backdrop. Chromium only; elsewhere plain glass.
    .oc-block-glass-nav__sheet / __action / __barThe glass sheet, the action pill and the menu bar.
    ItemsRadios in the demo (the bubble moves on click); links with aria-current="page" or buttons with aria-pressed in an app.
    Blade<x-oc::block.glass-nav /> renders this markup.
