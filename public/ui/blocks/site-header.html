    Site header

    Sticky header that turns into frosted glass once you scroll (scroll-driven animation) with a gradient call-to-action, in several styles: centred with actions, a mega menu with photos, dark, floating and glass. On small screens the menu opens as a native popover - no JavaScript. Install with npx omniaui add site-header. All blocks.

    Reference

    Styles live in packages/ui/src/showcase.css and parts/site-header-variants.css; the mega menu is in OmniaUI Pro (parts/site-mega-menu.css). Colors are theme tokens, so everything follows light and dark mode.

    ClassDescription
    .oc-site-headerSticky header; glass background after 120px of scrolling
    .oc-site-header__innerFlex row inside .oc-container
    .oc-site-header__brandLogo + name
    .oc-site-header__nav[popover]Navigation: inline on desktop, popover panel on mobile
    .oc-site-header__toggleMenu button (popovertarget), only visible on mobile; an icon in it is a block (as tall as the text)
    .oc-site-header__ctaThe call to action in the nav: room above it in the open mobile menu
    .oc-site-header__actionsRight side: sign in, call to action
    --center / --dark / --floating / --glassCentred menu / dark bar / rounded card with room around it / see-through pill with blur
    button.oc-mega-trigger[popovertarget] (Pro)Menu item that opens a mega menu; the chevron turns while it is open
    div.oc-mega[popover] (Pro)Mega menu panel: __cols with __title and ul.__links (__icon, b, small), and an a.__feature (photo, __feature-body, __feature-link)
