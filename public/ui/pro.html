    OmniaUI Pro

    OmniaCSS and every OmniaUI component stay free and open source (MIT). OmniaUI Pro adds the larger app screens on top: dashboards, a CMS admin, a form builder, a media manager, a chat inbox, calendars, status pages and the advanced sidebar and sign-in variants. Every Pro block has a live demo on this site; the HTML, Blade, React and Vue code comes with a license.

    Free, and stays free

    Everything you need to build an interface yourself.

    PackageWhat it holds
    @birdycom/omniacssUtilities, Omnia color palette, theme tokens, on-demand engine and CLI
    @birdycom/omniauiAll components (buttons, forms, dialogs, data table, sidebar, chat parts …)
    @birdycom/omniaui-blocksMarketing sections (hero, features, pricing, FAQ, footer …), app shell and header, the basic sign-in screens and sidebars 01 to 05
    @birdycom/omniaui-react, -vue, birdycom/omniaui-laravelThe same components and free blocks as React, Vue and Blade components

    What Pro adds

    34 blocks, each as HTML snippet, Blade component, React component and Vue component. Open one to see the live demo.

    Install

    Pro sits next to the free packages: same classes, same theme tokens, same x-oc:: prefix in Blade. omniacss build includes the Pro CSS as soon as the package is installed.

npm install @birdycom/omniaui @birdycom/omniaui-blocks @birdycom/omniaui-pro
npx omniaui add cms-dashboard

# React or Vue components
npm install @birdycom/omniaui-pro-react   # or @birdycom/omniaui-pro-vue

# Laravel Blade: <x-oc::block.cms-dashboard>
composer require birdycom/omniaui-pro-laravel

    The Pro packages are not on the public npm registry: you get access with your license.
