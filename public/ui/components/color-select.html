    Color select

    Pick one color from a fixed set, e.g. a label or category color. Each swatch is a radio input inside a label, so keyboard navigation, forms and name grouping work natively. The color comes from one CSS variable per option: --oc-swatch, set to an Omnia token. All components.

    Demo

    snippets/color-select.html 0 KB JavaScriptBaselinev0.6.0

    Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/color-select.html. The last swatch is disabled (a color already in use): it gets a diagonal line, cannot be picked and shows its reason on hover.

    Reference

    Styles live in packages/ui/src/parts/forms-color-select.css. Need any color (not a fixed set)? Use Color field.

    Class / attributeDescription
    .oc-color-selectGroup (<fieldset> or role="radiogroup"). Modifiers: --list, --sm.
    .oc-color-select-optionLabel around one radio; set style="--oc-swatch: var(--color-red-70)"
    .oc-color-select-swatchRound color dot; checked = double ring
    .oc-color-select-nameColor name: visible in --list, screen-reader only in the grid

    Framework wrappers

    options is a list of { value, label, color }; color is a CSS value such as var(--color-red-70).

    <!-- React -->
<ColorSelect aria-label="Label color" value={color} onChange={setColor} options={colors} />
<!-- Vue -->
<OcColorSelect v-model="color" label="Label color" :options="colors" list />
<!-- Laravel Blade -->
<x-oc::color-select name="color" value="blue" :options="['blue' => ['Blue', 'var(--color-vividblue-95)']]" />
