    Avatar picker

    Pick a profile picture or a company logo: the preview (initials until there is an image), Upload and Remove, and dropping an image on it. The file input is a real <input type="file"> inside the preview, so the form sends the file; form-extras.js shows the preview. All components.

    Demo

    Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/avatar-picker.html.

    Avatar and logo v0.12.6 v0.17.0

    Only images are taken: pick a PDF through "All files" and the picker refuses it with a message. The profile picture also has a 2 MB limit (data-oc-max-kb).

    import { AvatarPicker } from "@birdycom/omniaui-react";
import { useState } from "react";

export function Example() {
  const [avatar, setAvatar] = useState<File | null>(null);
  const [logo, setLogo] = useState<File | null>(null);

  return (
    <div style={{ display: "grid", gap: "1.5rem" }}>
      <AvatarPicker
        name="avatar"
        initials="C1"
        accept="image/png,image/jpeg,image/webp"
        maxKb={2048}
        hint="PNG, JPG or WebP up to 2 MB, at least 256 × 256 px. Drop an image on the circle."
        onChange={(file) => setAvatar(file)}
      />
      <AvatarPicker
        name="logo"
        initials="CO"
        label="Company logo"
        logo
        accept="image/svg+xml,image/png"
        hint="SVG or PNG on a transparent background."
        onChange={(file) => setLogo(file)}
      />
    </div>
  );
}

    <?php

namespace App\Livewire;

use Livewire\Attributes\Validate;
use Livewire\Component;
use Livewire\WithFileUploads;

class AvatarPicker extends Component
{
    use WithFileUploads;

    #[Validate('nullable|image|mimes:png,jpg,jpeg,webp|max:2048')]
    public $avatar;

    #[Validate('nullable|mimes:svg,png|max:1024')]
    public $logo;

    public function save(): void
    {
        $this->validate();

        if ($this->avatar) {
            $this->avatar->store('avatars', 'public');
        }
        if ($this->logo) {
            $this->logo->store('logos', 'public');
        }
    }

    public function render()
    {
        return view('livewire.avatar-picker');
    }
}

{{-- resources/views/livewire/avatar-picker.blade.php --}}
<form wire:submit="save" style="display:grid;gap:1.5rem">
    {{-- wire:model goes to the file input; the preview shows the new image at once --}}
    <x-oc::avatar-picker name="avatar" wire:model="avatar" id="oc-avatar-me" initials="C1" accept="image/png,image/jpeg,image/webp" :max-kb="2048"
        hint="PNG, JPG or WebP up to 2 MB, at least 256 × 256 px. Drop an image on the circle." />
    <x-oc::avatar-picker name="logo" wire:model="logo" id="oc-logo-company" initials="CO" label="Company logo" logo accept="image/svg+xml,image/png"
        hint="SVG or PNG on a transparent background." />
    <div><x-oc::button type="submit">Save</x-oc::button></div>
</form>

    Reference

    Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-avatar-pickerPreview and text side by side.
    label.oc-avatar-picker__previewThe preview; clicking it opens the file dialog (the file input fills it, invisible).
    [data-oc-initials]Shown until an image is picked.
    [data-oc-avatar-upload] / [data-oc-avatar-remove]Open the dialog / go back to the initials. Remove only shows while there is an image.
    .oc-avatar-picker--square / --logoRounded square; --logo fits the whole image on white (no crop).
    accept on the file inputWhich files are allowed (image/png,image/jpeg, .svg). The browser's "All files" option still lets a PDF through, so the script checks again and refuses it.
    data-oc-max-kbOptional size limit in KB on .oc-avatar-picker; data-oc-type-error / data-oc-size-error replace the messages.
    .oc-avatar-picker__error / .is-invalidAdded by the script when a file is refused: the reason in red (role="alert") and a red outline.
    oc-avatar-changeEvent with detail.file (the File, or null after Remove).
    oc-avatar-invalidEvent with detail.file and detail.reason when a file is refused.

    Send the file with the form (the input has a name in your app) or upload it yourself on oc-avatar-change. In Blade, wire:model (0.17.0) goes to the file input, so a Livewire component with WithFileUploads receives the file (see the Livewire tab); input-attributes adds more attributes to the input. Check the type and size on the server too: the browser check is for the user, not for security.
