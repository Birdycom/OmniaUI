    Table

    Semantic HTML tables styled with the OmniaCSS theme tokens: borders, header background and a row hover, in light and dark mode. Use .oc-table for data tables and the expandable table to show a few rows with a CSS-only "Show more" toggle.

    Demo

    0 KB JavaScriptBaseline

    Plain HTML and CSS; each example shows its markup in the HTML tab.

    Data table

    Add .oc-table to a <table>. Wrap it in .oc-table-wrap when it can be wider than the screen: the wrapper scrolls horizontally instead of the page.

    Column widths

    .oc-table uses table-layout: fixed, so a width utility on a header cell fixes that column (.w-10, .w-perc-1/3, …); the other columns share the rest.

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

    ClassDescription
    .oc-tableData table: borders, header background, row hover, fixed layout
    .oc-table-wrapHorizontal scroll container for wide tables
    .oc-table-refCompact reference table (class / value), used in the docs
    .oc-expandable-tableWrapper for a table with a "Show more" toggle
    .oc-expandable-table__row-moreRow hidden until the toggle is checked
    .oc-expandable-table__row-dimmedLast visible row, faded as a hint that more follows
