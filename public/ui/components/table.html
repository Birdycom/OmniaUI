    Columns by their content, fewer on a narrow screen v0.17.0

    .oc-table--auto sizes the columns by what is in them: the actions stay narrow and the name gets the room (the default fixed layout shares the width equally). data-hide-below="md" on a th and its tds hides that column when the table area is narrower than 32rem (sm 24rem, lg 48rem); such a table gets narrower instead of scrolling; it measures the table, not the window, so it also works in a side panel. .oc-table-action-label next to an action icon shows the text on a wide table and only the icon on a narrow one (or always with .oc-table-actions--compact); the title stays as tooltip. Use the tablet and phone buttons above the demo.

    <?php

namespace App\Livewire;

use Livewire\Component;

class RouteTable extends Component
{
    /** @var list<array{id: int, name: string, date: string, players: int}> */
    public array $routes = [
        ['id' => 1, 'name' => 'Route 1 through the old town', 'date' => '8 November 2026', 'players' => 42],
        ['id' => 2, 'name' => 'Route 2', 'date' => '15 November 2026', 'players' => 18],
    ];

    public function edit(int|string $id): void
    {
        $this->redirect('/routes/'.$id.'/edit', navigate: true);
    }

    public function copy(int|string $id): void
    {
        $route = collect($this->routes)->firstWhere('id', (int) $id);
        if ($route) {
            $this->routes[] = ['id' => count($this->routes) + 1, 'name' => $route['name'].' (copy)', 'date' => $route['date'], 'players' => 0];
        }
    }

    public function render()
    {
        return view('livewire.route-table');
    }
}

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

    ClassDescription
    .oc-tableData table: borders, header background, row hover, fixed layout
    .oc-table-wrapHorizontal scroll container for wide tables
    .oc-table--autoColumns sized by their content (React / Vue / Blade layout="auto")
    [data-hide-below=sm|md|lg]On a th and its tds: hidden when the table area is narrower than 24 / 32 / 48rem (Vue column hideBelow)
    .oc-table-action-labelText next to an action icon; hidden in a narrow table or in .oc-table-actions--compact (React TableActionIcon showLabel, TableActions compact)
    .oc-table-refCompact reference table (class / value), used in the docs
    .oc-expandable-tableWrapper for a table with a "Show more" toggle
    .oc-expandable-table__row-moreRow hidden until the toggle is checked
    .oc-expandable-table__row-dimmedLast visible row, faded as a hint that more follows
