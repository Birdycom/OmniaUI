    Tabs

    Switch between panels without JavaScript. A hidden radio input in every tab holds the state and :has() shows the panel at the same position, so the browser handles clicks, keyboard (arrow keys) and form state. Line tabs by default, with pill and vertical variants. All components.

    Class-toggle tabs (for existing scripts)

    When a script already manages the state, use buttons with role="tab" and set aria-selected="true" (or .is-active) on the active tab and .is-active on its panel. The small script below does exactly that; the same classes work with .oc-tab-list--pill.

    <script>
  // Tabs with data-oc-tabs: a click selects the tab and shows the panel named in aria-controls.
  document.addEventListener('click', (e) => {
    const tab = e.target.closest('[data-oc-tabs] [role="tab"]');
    if (!tab || tab.disabled) return;
    for (const other of tab.parentElement.querySelectorAll('[role="tab"]')) {
      const on = other === tab;
      other.setAttribute('aria-selected', String(on));
      document.getElementById(other.getAttribute('aria-controls'))?.classList.toggle('is-active', on);
    }
  });
</script>

    With icons and counts v0.12.6

    The type tabs of a list (as in the Data table and the Pro block Relations list): an icon, the label and a count. Add .oc-data-table-tabs to the tab list and a .oc-data-table-tab-count to every tab; --success, --info and --warning color the count like the type badge in the table. In a data table the tabs filter a column (data-oc-col-filter); here they switch panels with the script above.

    Reference

    Styles live in packages/ui/src/components.css. The CSS-only version supports up to six tabs per set.

    Class / attributeDescription
    .oc-tabsetWrapper of the CSS-only tabs: the tab list first, then one .oc-tab-panel per tab in the same order.
    .oc-tab-listRow of tabs (role="tablist"). Modifiers: --pill, --vertical.
    label.oc-tab-trigger > input[type=radio]One tab. The radio is visually hidden; the checked one marks the active tab. Give all radios of a set the same unique name.
    .oc-tab-panelA panel. In .oc-tabset the panel at the position of the checked tab shows.
    button.oc-tab-trigger[aria-selected] / .is-activeClass-toggle version: the active tab (aria-selected="true" or .is-active) and the visible panel (.oc-tab-panel.is-active).
    .oc-data-table-tabs + .oc-data-table-tab-countTabs with an icon and a count (--success, --info, --warning color the count). Styles in parts/app-data-table-rich.css.
    :disabled / [aria-disabled="true"]A tab that cannot be selected (dimmed).

<x-oc::tabs name="account" :tabs="['Account', 'Password']" variant="pill">

</x-oc::tabs>
