    Feature card

    The cards a company site uses everywhere: a service or a feature with an icon tile, a title and a short text and a quiet hover, and a card that is a whole link (an agent, a tool, a document) with a more line that moves on hover. Put them in an .oc-card-grid; --oc-card-min sets how wide a column must be. All components.

    Reference

    Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-feature-cardCard: tile, title, text; surface background, the border turns strong on hover.
    .oc-feature-card__title / __textTitle (display font, 1.2rem) and muted text.
    .oc-link-cardA card that is an <a>: __title, __text, __more (arrow moves on hover); the border takes the accent color on hover (.oc-accent--violet …).
    .oc-card-gridAuto-fill grid; --oc-card-min is the minimum column width (17rem), --oc-card-gap the gap.
    .oc-card-grid--wideWide cards (projects): from 32rem, three in a row from 1280px.
    .oc-tag-list--neutral / --lgChips without the accent color / larger chips in the display font (a strip of brand names).
    .oc-card-grid--fitThe cards stretch over the full width when there are fewer than fit in a row (auto-fit).
    --oc-link-card-hoverHover color of a link card on its own, so the tile keeps its color (instead of an accent preset on the card).
