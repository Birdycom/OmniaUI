    Data table

    A list table for business apps. Optional type tabs with counts, one toolbar (title, settings menu, search, trash pills, table or cards), filter selects, the table in a rounded frame with rich name cells and soft row actions, and a footer with the count, rows per page and page numbers. Search, filters, sort, pages and bulk actions run in the browser; column width and row drag come with OmniaUI Pro. All components.

    Article list

    The complete relations screen (type tabs with colored counts, filters, rich name cells, row actions per status) is the Pro block Relations list; the pieces it uses are all part of this free component and described in the reference below. Try it: search for "plaat", sort Price, check a row and move it to the trash, then open Trash only. The sliders menu next to the title switches comfortable and compact rows and exports CSV. Excel, PDF and the real delete call stay in the app: listen for oc-datatable-bulk.

    Reference

    Put .oc-data-table around the toolbar, the table and the footer. Load data-table.js once. The script wires every table on the page. Plain HTML or Blade: npx omniaui copy-js data-table puts it in public/js/oc-data-table.js, which starts on its own from <script type="module">.

    PieceWhat it does
    .oc-data-table--borderedVersion 2: tinted header row, lines between the columns, sort chevrons always visible, the filter icon in its own zone.
    .oc-data-table--plainNo stripes (rows are striped by default, in both versions).
    th[aria-sort]The column sorted when the page opens (ascending or descending); the sorted column shows a sort icon and a bold label.
    .oc-data-table-codeMonospace cell for article numbers and other codes.
    .oc-data-table-searchFilters rows as you type. Enter fires oc-datatable-search (barcode scanners).
    [data-oc-filter]Active only, including trash, trash only, archive only. Reads data-oc-status on the row. In the toolbar the chosen pill is filled.
    [data-oc-col-filter]Filters one column: on a <select> (its value) or on tab buttons with data-oc-value (aria-selected marks the chosen tab). A row passes when that cell's data-oc-value (or text) equals the value; "" means all.
    .oc-data-table-tabs + .oc-data-table-tab-countTabs above the toolbar (All, Customers, Companies …) with an icon and a count; the chosen tab is in the primary color.
    .oc-data-table-filters / .oc-data-table-filterRow of filter selects with a leading webicon. data-oc-filters-toggle on a button shows or hides the row.
    .oc-data-table-columns-btn (Pro)The column chooser in the actions header: a large plain icon that opens the .oc-column-menu ("Reset column widths" on top, then the columns). The sliders button next to the title opens the list actions (export, duplicate, trash, row density). Every control is 2rem high, also rows per page and the pager.
    .oc-data-table-tab-count--success / --info / --warningA tab count in the color of its type, the same tone as the type badge in the table.
    .oc-data-table-nameName cell: .oc-avatar, .oc-data-table-name-line (name + badge) and .oc-data-table-name-sub (VAT number, e-mail). Cards reuse it as their title.
    .oc-data-table-truncateOne line with an ellipsis at --oc-data-table-truncate (18rem); put the full text in title. Cells stay on one line and the frame scrolls sideways; td.oc-data-table-wrap lets a cell wrap.
    .oc-data-table-count[data-count]A count button (projects, invoices); muted while data-count="0".
    .oc-table-sortSorts the column. Numeric columns use data-oc-sort="numeric" and data-oc-value.
    [data-oc-page-size] / [data-oc-pager]Rows per page and the numbered pager. The count is [data-oc-summary]; give it a template to translate it: data-oc-summary="Toont {from} t/m {to} van {total} resultaten".
    .oc-column-menuOmniaUI Pro (Column menu): show or hide columns; the checkbox data-col is the column number.
    .oc-data-table-resizeOmniaUI Pro: with data-table-pro.js, drag to set the column width (remembered per table id; [data-oc-reset-widths] clears it).
    .oc-sortable-row-gripOmniaUI Pro: with data-table-pro.js, drag a row by the grip (fires oc-datatable-reorder).
    [data-oc-view]table or grid. Cards are built from the rows on the current page: the name cell as title, the other visible columns as label and value, and the row actions.
    [data-oc-density]comfortable or compact (tighter rows).
    [data-oc-bulk]export, duplicate, archive, restore, delete, clear. Fires oc-datatable-bulk with the selected keys.
    [data-oc-export] / [data-oc-import]Download the filtered rows as CSV, or pick a file (oc-datatable-import). The wrappers only offer import with importable; the demos on this page have none.
    [data-oc-row-action] + data-oc-whenPer-row restore or delete (fires oc-datatable-row with the action and the key). Put data-oc-when="active" on edit/view and data-oc-when="deleted" on restore/delete: each row shows the buttons of its status, also in the cards.
    data-oc-hrefClick the row to open that URL. Clicks on buttons and inputs stay on the control. Ctrl-click opens a new tab.
    data-oc-live="true"The demo updates rows in the page. Leave it off in an app and handle the event yourself.

    React, Vue and Laravel

    The wrappers render this markup and start the same script. All three take tabs (with a tone per tab), columnFilters, summary, archive, importable, selectable, draggable and a truncate width per column. Rich cells: React passes nodes (with <DataTableName>), Vue fills the cell-<key> slot (with <OcDataTableName>), Blade takes an HtmlString (or <x-oc::data-table-name>). Give a rich cell a plain values[key] for sorting, filtering and search. onBulk in React receives the action and the selected keys. Livewire: Omniacss\Livewire\DataTable renders the actions of actions() as soft icon buttons when they have an icon (and a tone).
