    Slider

    A styled native <input type="range">. Min, max, step, value, keyboard handling and form submission come from the browser; the CSS draws the track, fill and thumb in theme colors. All components.

    Reference

    Styles live in packages/ui/src/components-extra.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-slider-scaleMarks under a stepped slider: one child per step (empty = mark only, a number = mark with a label), each centered under its thumb position. Show the value in an <output>.
    input.oc-sliderRange input styled for light and dark
    .oc-slider--verticalVertical orientation (writing-mode)
    --oc-slider-progressFill length (percent) in Chromium and WebKit
    --oc-slider-track / --oc-slider-thumbTrack thickness and thumb size

    Platform features used

    CSS featureRole
    appearancenone removes the native look so the pseudo-elements can be styled
    accent-colorFallback color if pseudo-element styles are ignored
    writing-modeVertical slider

    Anatomy

    • Input a real range input. Name it with a <label> or aria-label.
    • Track and fill ::-webkit-slider-runnable-track paints the fill from --oc-slider-progress; Firefox uses ::-moz-range-progress.
    • Thumb round, outlined in the primary color, with a focus ring from --oc-ring.

    Accessibility and keyboard

    Accessibility

    • Native role="slider" with value, min and max announced automatically.
    • Show the current value as text next to the slider (an <output>) when precision matters.
    • For two thumbs (a range) combine two sliders or use a wrapper; a native dual-thumb input does not exist.

    Keyboard

    • ←/↓ decrease, →/↑ increase by one step; PageUp/PageDown larger steps; Home/End jump to min and max.
