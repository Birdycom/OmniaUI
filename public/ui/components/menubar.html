    Menubar

    A horizontal bar of menus (File, Edit, View). Each trigger is a button with popovertarget; each menu is the regular dropdown menu, so sub-menus, check items and shortcuts work unchanged. All components.

    Demo

    0 KB JavaScriptBaseline

    Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/menubar.html.

    As a React, Vue and Blade component v0.17.0

    Click File or View to open a menu. Hover Share for its sub-menu; Escape or a click outside closes it.

    import { useState } from "react";
import { Menubar } from "@birdycom/omniaui-react";

export function Example() {
  const [bookmarks, setBookmarks] = useState(true);
  const [fullUrls, setFullUrls] = useState(false);
  // each menu is a popover; an item closes it after a click, a check item (checked: true|false) stays open
  return (
    <Menubar
      label="Application"
      menus={[
        {
          label: "File",
          id: "oc-mb-file",
          items: [
            { label: "New tab", shortcut: "Ctrl T" },
            { label: "New window", shortcut: "Ctrl N" },
            { separator: true },
            { label: "Share", items: [{ label: "E-mail link" }, { label: "Messages" }] },
            { separator: true },
            { label: "Print", shortcut: "Ctrl P", onSelect: () => print() },
          ],
        },
        {
          label: "View",
          id: "oc-mb-view",
          items: [
            { label: "Always show bookmarks", checked: bookmarks, onSelect: () => setBookmarks(!bookmarks) },
            { label: "Always show full URLs", checked: fullUrls, onSelect: () => setFullUrls(!fullUrls) },
            { separator: true },
            { label: "Reload", shortcut: "Ctrl R", onSelect: () => location.reload() },
          ],
        },
      ]}
    />
  );
}

    <script setup lang="ts">
import { computed, ref } from "vue";
import { OcMenubar } from "@birdycom/omniaui-vue";

const bookmarks = ref(true);
const fullUrls = ref(false);
// each menu is a popover; an item closes it after a click, a check item (checked: true|false) stays open
const menus = computed(() => [
  {
    label: "File",
    id: "oc-mb-file",
    items: [
      { label: "New tab", shortcut: "Ctrl T" },
      { label: "New window", shortcut: "Ctrl N" },
      { separator: true as const },
      { label: "Share", items: [{ label: "E-mail link" }, { label: "Messages" }] },
      { separator: true as const },
      { label: "Print", shortcut: "Ctrl P", onSelect: () => print() },
    ],
  },
  {
    label: "View",
    id: "oc-mb-view",
    items: [
      { label: "Always show bookmarks", checked: bookmarks.value, onSelect: () => (bookmarks.value = !bookmarks.value) },
      { label: "Always show full URLs", checked: fullUrls.value, onSelect: () => (fullUrls.value = !fullUrls.value) },
      { separator: true as const },
      { label: "Reload", shortcut: "Ctrl R", onSelect: () => location.reload() },
    ],
  },
]);
</script>

<template>
  <OcMenubar label="Application" :menus="menus" />
</template>

    <?php

namespace App\Livewire;

use Livewire\Component;

class AppMenubar extends Component
{
    public bool $bookmarks = true;

    public bool $fullUrls = false;

    public function toggle(string $setting): void
    {
        if (in_array($setting, ['bookmarks', 'fullUrls'], true)) {
            $this->{$setting} = ! $this->{$setting};
        }
    }

    public function newTab(): void
    {
        // $this->redirect(route('tabs.create'));
    }

    public function render()
    {
        return view('livewire.app-menubar');
    }
}

    </x-oc::menubar>

    position-areaMenus open below their trigger

    Anatomy

    • Bar .oc-menubar: bordered flex row; triggers highlight while their popover is open (:has(+ :popover-open)).
    • Trigger a button whose popovertarget points to the menu. The menu is anchored to it by the invoker relationship.
    • Menus are the dropdown-menu panels; the browser provides light dismiss and Esc.

    Accessibility and keyboard

    Accessibility

    • Roles: menubar > menuitem triggers with aria-haspopup="menu"; the menus use role="menu".
    • Native popover gives focus return and light dismiss. The full ARIA menubar pattern (arrow keys between menus and items, hover-to-switch) is wrapper responsibility: a ~30 line script or the Vue/React/Blade wrappers.

    Keyboard

    • Tab and Enter/Space open a menu; Esc closes it and returns focus.
    • With the optional script: ←/→ switch menus, ↓/↑ move through items, letters jump to an item.

    Framework wrappers

    The same markup and classes as React, Vue and Blade components. Their props follow the class modifiers on this page; see the source files below.
