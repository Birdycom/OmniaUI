    Language select

    A compact locale or currency switcher for a site header. It is a native <select> in a small pill with a leading icon, so mobile users get the system picker and keyboards work out of the box. Your app listens to change (navigate to /nl/, set a cookie, or submit the form). All components.

    With the OmniaUI dropdown

    The pill as a <button> opens an OmniaUI dropdown (popovertarget + .oc-dropdown-menu), styled like every other menu, without JavaScript. Use links to the translated pages (hreflang); role="menuitemradio" with aria-checked="true" marks the current language.

    Reference

    Styles live in packages/ui/src/parts/forms-language-select.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-language-selectPill (a <label>) around icon and select. Modifiers: --ghost, --currency.
    .oc-language-select-iconLeading inline SVG or symbol, aria-hidden="true"
    .oc-language-select-controlThe native select; give it an aria-label
    button.oc-language-select + .oc-dropdown-menuDropdown variant: the pill opens a popover menu with one link per language (role="menuitemradio", aria-checked on the current one).

    Framework wrappers

    options is a list of { value, label }. Set currency for the currency look; icon replaces the globe or symbol.
