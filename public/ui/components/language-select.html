    Language select

    A compact locale or currency switcher for a site header. It is a native <select> in a small pill with a leading icon, so mobile users get the system picker and keyboards work out of the box. Your app listens to change (navigate to /nl/, set a cookie, or submit the form). All components.

    The open list v0.14.1

    In Chrome and Edge (135 and later) the open list of every language select looks like the OmniaUI dropdown: the popover colors, padding, radius and shadow, as wide as the longest language (at least 8rem), a check at the current language, under the field (above it only when it does not fit), and for --code aligned to the right of the button. It is still the native <select> (appearance: base-select), so keyboards, forms and change work as before; other browsers show the list of the system.

    Switch to the page in that language v0.14.1

    Put data-oc-language-select on the label and the address of the same page in each language in the option values; oc-language-select.js (npx omniaui copy-js language-select) goes there on change and keeps the #section you were reading (data-oc-keep-hash="false" turns that off). A select needs a script to switch pages: put the links in a <noscript>, or use the dropdown below, which works without JavaScript.

    Menu with flags v0.16.0

    The language menu of an app header: the button shows the flag and the code of the current language, the list shows each language with its flag, its name in that language (lang="…", so screen readers read it right), its code, and a check at the current one (aria-current="true"). It is a popover (popovertarget), so it opens, closes with Esc or a click outside, and works with the keyboard without any script. On your site each item is a link to the page in that language (hreflang); in this demo the items only close the menu. React LanguageMenu, Vue OcLanguageMenu and Blade React LanguageMenu and Vue OcLanguageMenu draw the flags as inline SVGlt;x-oc::language-menuReact LanguageMenu and Vue OcLanguageMenu draw the flags as inline SVGgt; (since v0.17.0) draw the flags as inline SVG (see Webicon), without the Iconify script: flag:nl-4x3, be, fr, de, gb, it and us are built in, any other flag you register once with addWebicons.

    Flags from the language code v0.17.0

    With flags="auto" you leave flag out of the options: the menu takes the flag from the language code. A region in the code wins (nl-BE shows Belgium, en-US the United States), otherwise the usual country of the language (en gb, da dk, nl nl). A flag on an option still wins, and flagFor(code) sets your own choice per language. The same rule is exported as languageFlag(code) (React, Vue) and Webicons::languageFlag() (Laravel). Flags other than the built-in seven you add with npx omniaui webicons flag:es-4x3.

    Reference

    Styles live in packages/ui/src/parts/forms-language-select.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-language-selectPill (a <label>) around icon and select. Modifiers: --ghost, --currency, --code (only the code, from data-code). data-oc-language-select: go to the page in the option value on change (language-select.js).
    .oc-language-select-iconLeading inline SVG or symbol, aria-hidden="true"
    .oc-language-select-controlThe native select; give it an aria-label
    button.oc-language-select + .oc-dropdown-menuDropdown variant: the pill opens a popover menu with one link per language (role="menuitemradio", aria-checked on the current one).
    .oc-dropdown-menu.oc-language-menuThe language menu: per item a flag, the name in that language (lang), .oc-language-menu-code and a check at aria-current="true" (or aria-checked="true")
    .oc-language-flagA 4:3 flag with a thin edge (webicon flag:nl-4x3, an svg or an img), in the trigger and in the items
    .oc-language-select-codeThe code in the trigger ("NL"), bold, the same width for every language
    .oc-language-select--iconRound icon-only trigger (flag or globe); put the name in aria-label and data-tooltip (oc-tooltip oc-tooltip--bottom)

    Framework wrappers

    options is a list of { value, label }. Set currency for the currency look; icon replaces the globe or symbol. The menu is a separate component: LanguageMenu / OcLanguageMenu / <x-oc::language-menu> with options { value, label, flag?, code?, href? } and show="code|name", compact, ghost, label.
