    Confirm dialog

    A variant of the alert dialog. Add .oc-alert-dialog--confirm for a larger icon ring, a close button, an optional typed confirmation and a third "discard" action. It is a native <dialog> with a <form method="dialog">, so no JavaScript is needed. All components.

    Typed confirmation v0.17.0

    For actions that cannot be undone. The input has pattern="DELETE" required; the confirm button is a submit button, so the browser blocks it until the word matches. Until then it looks disabled. Snippet: packages/ui/snippets/confirm-dialog.html. Press Delete project, then try the red button: it stays blocked until you type DELETE. Escape, the cross or Cancel close the dialog.

    <?php

namespace App\Livewire;

use Livewire\Component;
use Omniacss\Livewire\WithOcModal;

class DeleteProject extends Component
{
    use WithOcModal;

    public string $project = 'Kitchen renovation';

    public string $confirmation = '';

    public function delete(): void
    {
        $this->validate(['confirmation' => 'required|in:DELETE'], ['confirmation.in' => 'Type DELETE to confirm.']);
        // delete the project, its quotes and files
        $this->reset('confirmation');
        $this->closeOcModal('delete');
    }

    public function render()
    {
        return view('livewire.delete-project');
    }
}

{{-- resources/views/livewire/delete-project.blade.php --}}
<div>
    <x-oc::button variant="destructive" wire:click="openOcModal('delete')">Delete project</x-oc::button>

    {{-- open state entangled with ocModals.delete (WithOcModal); confirm runs delete() --}}
    <x-oc::wire.alert-dialog name="delete" type="error" :title="sprintf('Delete “%s”?', $project)" confirm="Delete project" action="delete">
        This removes the project, its quotes and all files. This cannot be undone.
        <label class="oc-alert-dialog-typed">
            <span>Type <code>DELETE</code> to confirm</span>
            <x-oc::wire.input model="confirmation" live autocomplete="off" />
        </label>
        @error('confirmation') <p class="oc-field-error">{{ $message }}</p> @enderror
    </x-oc::wire.alert-dialog>
</div>

    Three buttons: discard, cancel, save

    For unsaved changes. .oc-alert-dialog-discard goes to the start of the footer. Each submit button has a value; read dialog.returnValue after the close event to know which one was pressed. On narrow screens the buttons stack, with the main action on top. Press Leave page and pick one of the three buttons; each one closes the dialog with its own returnValue.

use Omniacss\Livewire\WithOcModal;

class QuoteEditor extends Component
{
    use WithOcModal;

    public bool $dirty = true;

    Reference

    Adds to the alert dialog classes. Types: --success, --error, --warning, --info, --question. Slots: icon, title, message, typed field, footer buttons.

    Class / attributeDescription
    .oc-alert-dialog--confirmOn the content box: thin 80px icon ring, wider box, wrapping footer
    .oc-alert-dialog-closeX button in the top corner (command="close")
    form.oc-alert-dialog-form[method=dialog]Wraps body and footer; a submit closes the dialog with its value
    .oc-alert-dialog-typedLabel + input with pattern and required
    .oc-alert-dialog-confirmConfirm (submit) button; dimmed while the typed value is invalid
    .oc-alert-dialog-discardThird action at the start of the footer
