    Line and area chart

    Line, area and sparkline charts for the chart family, in inline SVG and CSS only. Hover a month (or Tab to it) to see a tooltip with every series, a cursor line and dots, the way dashboard charts do it, but without a chart library or a script. Colors are the --oc-chart-1 to --oc-chart-5 tokens, so light and dark mode work by themselves. Install with npx omniaui add chart-line. All components.

    Reference

    Styles live in packages/ui/src/parts/data-chart-line.css; the series tokens and the legend come from the chart component.

    Class / attributeDescription
    figure.oc-chart-lineChart; height from --oc-chart-line-height (12rem)
    --area / --dots / --sparkFilled areas, dots always visible, compact without axes
    .oc-chart-line__head / __title / __sub / __valueCaption row with a title, a sub line and a big number
    .oc-chart-line__body / __y / __xGrid with the y labels (top to bottom), the plot and the x labels
    .oc-chart-line__plot + --oc-chart-line-rowsPlot with gridlines (4 rows by default)

    How it works without JavaScript

    • One coordinate system: the SVG has viewBox="0 0 100 100" and preserveAspectRatio="none", so it stretches to any plot size. A point is at x = index / (count - 1) × 100 and y = 100 - value / max × 100. vector-effect: non-scaling-stroke keeps the line width even when the chart is stretched.
    • Smooth lines: the paths are cubic curves; generate them where the data lives (server, build step) with any monotone curve function. Straight segments (L) work too.
    • Hover columns: .oc-chart-line__cols is an HTML list laid over the plot. Each column sits at --x / (--n - 1); its dots sit at --y (value / max in percent). HTML dots stay round, unlike circles in a stretched SVG.
    • Tooltip: shown with :hover and :focus-visible on the column. It moves by translate: calc(var(--x) / (var(--n) - 1) * -100%): left-aligned at the first point, right-aligned at the last.
    • Colors: series, dots and tooltip rows pick --oc-chart-1..5 by position, the same order as .oc-chart-legend.

    Accessibility and keyboard

    • The SVG, the axis labels and the tooltips are aria-hidden. Each column has tabindex="0" and an aria-label with all its values ("March: Desktop 237, Mobile 120"), so a screen reader gets the data point by point.
    • Tab moves from point to point and shows the tooltip, with a solid cursor line as focus indicator. For long series, offer a data table instead and leave out the tabindex.
    • Do not rely on color alone: the legend names the series and the tooltip lists them in the same order. Dashes can tell two series apart.
    • Dot and tooltip transitions are off under prefers-reduced-motion: reduce.
