    Color field

    The native <input type="color"> plus a text field for the value. Keeping both in sync is the wrapper's job. All components.

    Demo

    0 KB JavaScriptBaseline

    Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/color-field.html.

    Click the swatch and pick a color: the hex code next to it follows. Or type a code such as #0f766e and press Enter: the swatch follows. The two one-line oninput/onchange handlers keep them in sync.

    Contrast check for a customer's color v0.17.0

    When a customer picks a brand color, show at once whether it works. contrastAgainst lists the page backgrounds; the field checks text on the color (light or dark text, whichever reads best, at least 4.5:1) and the color on each background (at least 3:1, so a button or a link stands out). A word says the result, the color only repeats it. The yellow is fine for text but disappears on the light page. The same math is exported: contrastRatio(a, b) and pickOnColor(color) (React, Vue); colors may be theme tokens such as var(--oc-background).

    <?php

namespace App\Livewire;

use Livewire\Component;

class ColorFieldContrastCheck extends Component
{
    public string $brand = '#2f80ed';

    /** The backgrounds the brand color must stand out on (at least 3:1). */
    public array $pages = [
        ['name' => 'the light page', 'color' => '#ffffff'],
        ['name' => 'the dark page', 'color' => '#0b1020'],
    ];

    public function save(): void
    {
        $this->validate(['brand' => ['required', 'regex:/^#[0-9a-fA-F]{6}$/']]);
    }

    public function render()
    {
        return view('livewire.color-field-contrast-check');
    }
}

{{-- resources/views/livewire/color-field-contrast-check.blade.php --}}
<form wire:submit="save" style="display:grid;gap:1rem;max-inline-size:20rem">
    {{-- wire:model.blur: the server measures the contrast again when the field loses focus --}}
    <x-oc::color-field label="Brand color" id="brand" name="brand" :value="$brand" :contrast-against="$pages" wire:model.blur="brand" />
    <x-oc::button type="submit">Save</x-oc::button>
</form>
