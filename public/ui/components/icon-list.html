    Icon list

    Three kinds of list next to a text: rows with an icon in a small frame (the kinds of work you do), points with an icon tile, a title and a text (what makes an offer different), and a plain list whose markers take the accent color. With a note under a block, a row of badges and a tagline in the accent color. All components.

    Reference

    Styles live in packages/ui/src/parts/. Colors are theme tokens, so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-icon-listRows with an icon (svg, iconify-icon) in the primary color, each in a frame.
    .oc-icon-list--pointsPoints: an icon tile next to .oc-icon-list__title and .oc-icon-list__text, no frames.
    .oc-list--accentDisc list in muted text with markers in --oc-accent-from.
    .oc-noteSmall muted note under a block (0.85rem).
    .oc-badge-rowRow of badges or pills above a title.
    .oc-tagline--accentTagline in the accent color, lighter in dark mode.
    .oc-note--mdA note in the size of the running text around it (the body size) up to 60rem wide, under a grid.
