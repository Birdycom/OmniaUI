    Sortable row

    A table row with a drag grip. This component is styling only: the grip, the row being dragged and the drop line. You add the behaviour with native HTML drag and drop (or a small library) and set the state classes. All components.

    Keyboard pick-up

    Drag and drop is not usable with a keyboard. Give the grip a key handler: Space picks the row up (aria-pressed="true" on the grip highlights the row), arrow keys move it, Space drops it. Announce the new position in a live region.

    Adding the behaviour

    With native drag and drop: on dragstart add .is-dragging to the row; on dragover call preventDefault() and set .is-drop-before or .is-drop-after (top or bottom half of the target); on drop move the row and remove the classes. The React and Vue wrappers take dragging and drop props and pass every drag event through.

    Reference

    The grip dots are a CSS gradient in currentColor. The drop line uses the primary token.

    Class / attributeDescription
    tr.oc-sortable-row[draggable="true"]A row that can move
    .is-draggingThe row being moved (dimmed, dashed)
    .is-drop-before / .is-drop-afterDrop line on the top or bottom edge of the target row
    td.oc-sortable-row-grip-cellNarrow first cell
    button.oc-sortable-row-gripGrip with six dots. aria-pressed="true" = picked up, disabled = locked
