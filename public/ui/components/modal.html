    Modal / Dialog

    A modal on the native <dialog> element: focus trapping, Esc to close and a ::backdrop come from the browser. Buttons open and close it with invoker commands, so no JavaScript is needed. Header, scrollable body and footer; sizes from sm to full.

    Demo

    snippets/modal.html0 KB JavaScriptBaseline

    CSS-first: command="show-modal" and command="close" with commandfor open and close the dialog; closedby="any" also closes it when you click outside. The markup is also available as the snippet packages/ui/snippets/modal.html.

    Click the button: the dialog opens with a backdrop. Escape, the close button or Cancel closes it again, without JavaScript.

namespace App\Livewire;

use Livewire\Attributes\Validate;
use Livewire\Component;
use Omniacss\Livewire\WithOcModal;

class EditProfile extends Component
{
    use WithOcModal;

    #[Validate('required|max:80')]
    public string $name = 'Customer 7';

    #[Validate('required|max:30')]
    public string $username = '@anna';

    public function save(): void
    {
        $this->validate();
        // auth()->user()->update($this->only('name', 'username'));
        $this->closeOcModal('profile');
    }

    public function render()
    {
        return view('livewire.edit-profile');
    }
}

    Round close button v0.16.1

    .oc-close--round makes the close button a circle; it works on the close button of a modal, a sheet and a confirm or alert dialog. In React the components draw that button themselves: closeRound adds the class and closeClassName one of your own (Vue close-round and close-class, Blade the same). A modal and an alert dialog only get a close button when you ask for it: closeButton, or one of the two options. Open it and hover the cross.

    Compound Dialog v0.17.0

    Build the dialog from parts: Dialog holds the open state (open + onOpenChange, or defaultOpen), DialogTrigger opens it, DialogContent is the <dialog class="oc-modal">, and DialogHeader, DialogTitle, DialogDescription, DialogBody, DialogFooter and DialogClose fill it. Title and description become the accessible name and description. asChild on the trigger or close button puts the behaviour on your own element. scroll (or DialogScrollContent) keeps header and footer in place while the body scrolls. Vue has the same parts as OcDialog…; Blade as <x-oc::dialog> with .trigger, .content, .header, .title, .description, .body, .footer and .close, which work without JavaScript. Modal keeps its props API.

    import { useState } from "react";
import { Button, Modal, ModalClose } from "@birdycom/omniaui-react";

export function Example() {
  // In React the open state lives in your component: Modal opens the native <dialog> for you,
  // so you never toggle .is-open yourself (that class is for markup without a <dialog>).
  const [open, setOpen] = useState(false);
  return (
    <>
      <Button variant="outline" onClick={() => setOpen(true)}>Open (class toggle)</Button>
      <Modal
        open={open}
        onOpenChange={setOpen}
        size="sm"
        title="Confirm"
        description={<>Opened by adding <code>.is-open</code>.</>}
        footer={<ModalClose>Close</ModalClose>}
      />
    </>
  );
}

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

    Class / attributeDescription
    dialog.oc-modalThe modal. closedby="any" closes it on a click outside or Esc.
    command="show-modal" / command="close" + commandforOpen and close buttons, no script needed.
    .oc-modal-contentThe panel. Sizes: --sm, --lg, --xl, --full.
    .oc-modal-header, .oc-modal-title, .oc-modal-descriptionTitle and intro.
    .oc-modal-bodyScrollable middle part.
    .oc-modal-footerActions, aligned to the end.
    .oc-modal-closeThe × button in the corner. .oc-close--round: a circle.
    React closeButton, closeLabel, closeRound, closeClassNameThe close button of Modal and AlertDialog (shown with any of the options), round, with an own class; Sheet and ConfirmDialog always have one and take closeRound / closeClassName. Vue: close-button, close-label, close-round, close-class; Blade: close-button, close (label), close-round, close-class.
    .oc-modal-content--scrollHeader and footer stay in place, only .oc-modal-body scrolls (0.17.0, parts/app-compound-overlays.css).
    React Dialog, DialogTrigger, DialogContent / DialogScrollContent, DialogHeader, DialogTitle, DialogDescription, DialogBody, DialogFooter, DialogCloseCompound dialog (0.17.0): open / defaultOpen / onOpenChange on the root, asChild on trigger and close, size, scroll, closeButton (default on), closeRound on the content. Vue: OcDialog (v-model:open) and the same parts. Blade: <x-oc::dialog id> with .trigger, .content, .header, .title, .description, .body, .footer, .close; model ties the open state to a Livewire property.
    div.oc-modal.is-open + .oc-modal-overlayClass-toggle variant for existing scripts.
