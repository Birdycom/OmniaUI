    Label

    The text that names a form control. .oc-label is the standalone label; inside a field prefer .oc-field-label. Add modifiers for a required mark or an inline label around a checkbox. All components.

    Demo

    0 KB JavaScriptBaseline

    Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/label.html.

    <div class="oc-form-group">
  <label class="oc-label oc-label--required" for="oc-label-email">E-mail</label>
  <input class="oc-input" id="oc-label-email" type="email" placeholder="name@example.com">
</div>
<label class="oc-label oc-label--inline"><input class="oc-checkbox" type="checkbox"> Accept terms and conditions</label>

    Reference

    Styles live in packages/ui/src/components-extra.css (extensions) and components.css (base). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-labelBlock label, 0.875rem, weight 500
    .oc-label--requiredAdds a destructive-colored asterisk
    .oc-label--inlineInline-flex label that wraps a checkbox or radio
    .oc-label--mutedSecondary text color, normal weight

    Platform features used

    CSS featureRole
    colorTheme tokens, so light and dark mode follow

    Anatomy

    • Label label.oc-label with a for that matches the control's id, or wrapping the control.
    • Required mark --required draws an asterisk with ::after; the control still needs the required attribute.

    Accessibility and keyboard

    Accessibility

    • A visible <label> is the most robust accessible name; clicking it focuses or toggles the control.
    • The asterisk is decorative; set required or aria-required="true" on the control.

    Keyboard

    • Labels are not focusable; clicking one forwards focus (or the toggle) to its control.
