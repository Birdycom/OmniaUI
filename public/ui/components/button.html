    Button

    The base class .oc-btn with a variant and an optional size. Works on <button>, <a> and <label>, with a webicon before the label, as a square icon button, as a soft row action or busy with a spinner.

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

    Class / attributeDescription
    .oc-btnBase button in the primary color.
    .oc-btn--secondary / --outline / --ghost / --linkMuted fill / border only / no frame / looks like a text link.
    .oc-btn--destructive / --successDanger and confirm actions.
    .oc-btn--gradient / --glass / --pillShowcase buttons; the gradient uses --oc-accent-from and --oc-accent-to.
    .oc-btn--xs / --sm / --lgSizes around the default.
    .oc-btn--inlineWith --link: a button inside running text, no padding or height, the size of the text.
    .oc-btn--iconSquare button for one icon; give it an aria-label.
    <iconify-icon> / <svg> insideA webicon before or after the label, sized to the text (1.15em).
    .oc-btn--soft-primary / -success / -warning / -destructive / -infoTinted surface in a tone: row actions (edit, view, archive, delete, load) and quiet actions.
    .oc-btn--plainOnly the icon: no surface or padding, muted, the primary color on hover and with aria-expanded="true".
    aria-busy="true"Loading: a spinner before the label (replaces a leading icon), not clickable. React, Vue and Blade: loading.
    .oc-btn--toggleOn a <label> with a checkbox: .oc-btn-toggle__off / __on swap the text.
    .oc-btn-groupJoins buttons side by side.
    disabled / aria-disabled="true"Dimmed and not clickable.

    Which buttons OmniaUI itself uses

    These docs, the blocks and the components use the same classes; pick the same variant for the same job.

    ClassDescription
    .oc-btnPrimary action: block call-to-actions (hero, pricing, sign in), modal confirm.
    .oc-btn--secondaryQuiet action: "Show more / Show less" toggles.
    .oc-btn--outlineTriggers that open something: dropdown and popover buttons, "Open modal".
    .oc-btn--gradient + .oc-btn--glassLanding pages: hero primary and secondary.
    .oc-btn--ghostToolbar and icon actions without a frame (close buttons, pagination arrows).
    .oc-btn--destructive / --successConfirm dialogs (delete / save).
    .oc-btn--soft-* + --icon --smAction column of data tables (edit, view, delete).
