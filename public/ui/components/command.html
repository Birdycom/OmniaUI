    Items as children v0.18.0

    Next to the groups / items data, the rows can be written as children: <CommandGroup> with <CommandItem> in React, <OcCommandGroup> / <OcCommandItem> in Vue. A row shows its own content (text, <strong>, an icon), is searched by its text (or label, keywords) and may have its own onSelect / @select. Filtering and the arrow keys and Enter work as before. The rows are read from the children as you write them (also inside fragments, .map() and v-for); a row inside your own wrapper component is not found, see Items in your own component. Blade: <x-oc::command.group> and <x-oc::command.item> (markup only). A row is a flex line with a gap after a leading icon: React and Vue put the text after the icon in one <span> for you; in HTML and Blade wrap mixed text such as <strong>New</strong> invoice in a <span> yourself.

    Items in your own component v0.18.0

    React Command and Vue OcCommand read their rows statically from the children as you write them: the direct children of the Command and of each group, also inside fragments (<>…</>, <template>), arrays from .map(), v-for and conditions ({open && …}, v-if). They look at the element type only and do not render your own components to see what comes out. So a CommandItem (or CommandGroup) inside your own wrapper component, such as <CustomerItem> that returns a <CommandItem>, is not found: the row is missing, cannot be searched and cannot be chosen, without an error. Keep CommandItem / OcCommandItem directly in the Command or group (in a .map() or v-for) and pass the data as props, call a helper as a function ({customers.map(customerItem)}, not <CustomerItem />), or hand the rows over as data: React groups, Vue items with group. Blade is not affected: <x-oc::command.item> is plain markup, so your own Blade component around it works.

    import { Command, CommandGroup, CommandItem } from "@birdycom/omniaui-react";

type Customer = { id: string; name: string };
const customers: Customer[] = [
  { id: "customer-1", name: "Customer 1" },
  { id: "customer-2", name: "Customer 2" },
];

// Does NOT work: Command only sees <CustomerItem>, never the <CommandItem> it returns.
function CustomerItem({ customer }: { customer: Customer }) {
  return <CommandItem value={customer.id}>{customer.name}</CommandItem>;
}

export function Wrong() {
  return (
    <Command>
      <CommandGroup label="Invoices">
        <CommandItem value="new">New invoice</CommandItem>
      </CommandGroup>
      <CommandGroup label="Customers">
        {customers.map((c) => <CustomerItem key={c.id} customer={c} />)}
      </CommandGroup>
    </Command>
  );
}

// Works: CommandItem directly in .map(), the data as props.
export function Right() {
  return (
    <Command>
      <CommandGroup label="Invoices">
        <CommandItem value="new">New invoice</CommandItem>
      </CommandGroup>
      <CommandGroup label="Customers">
        {customers.map((c) => (
          <CommandItem key={c.id} value={c.id}>{c.name}</CommandItem>
        ))}
      </CommandGroup>
    </Command>
  );
}

// Also works: a helper you call as a function (it returns the CommandItem element itself).
const customerItem = (c: Customer) => <CommandItem key={c.id} value={c.id}>{c.name}</CommandItem>;

export function WithHelper() {
  return (
    <Command>
      <CommandGroup label="Customers">{customers.map(customerItem)}</CommandGroup>
    </Command>
  );
}

// Also works: the rows as data.
export function AsData() {
  return <Command groups={[{ label: "Customers", items: customers.map((c) => ({ id: c.id, label: c.name })) }]} />;
}

import { OcCommand, OcCommandGroup, OcCommandItem } from "@birdycom/omniaui-vue";

const customers = [
  { id: "customer-1", name: "Customer 1" },

// Does NOT work: your own component around OcCommandItem (usually its own CustomerItem.vue).

const CustomerItem = defineComponent({
  props: { id: { type: String, required: true }, name: { type: String, required: true } },

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-commandRoot
    .oc-command-inputSearch input
    .oc-command-listResults ul
    .oc-command-group-labelGroup heading
    .oc-command-itemResult. State: aria-selected="true", aria-disabled="true", hidden
    .oc-command-shortcutKeyboard hint on the right
    .oc-command-separatorDivider
    .oc-command-emptyShown when nothing matches
    CommandGroup / CommandItem React (and Vue OcCommandGroup / OcCommandItem): the rows as children next to groups / items. Item props: value, label (searched text, default the children's text), shortcut, disabled, keywords, onSelect. Blade: <x-oc::command.group label separator>, <x-oc::command.item shortcut selected disabled value>.
