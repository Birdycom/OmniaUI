    Browser frame

    Fake browser chrome (traffic lights, address pill) around a screenshot, a video or live HTML. Made for portfolio cards, product shots and docs. Variants: minimal, dark chrome and a 3D tilt that straightens on hover. All components.

    Plain HTML and CSS. Swap the placeholder for an <img> of your screenshot; it is cropped from the top.

    Minimal, dark, tilt and live content

    --minimal keeps only the dots; --dark darkens the chrome in both themes; --tilt adds a 3D angle that straightens on hover. With --auto the view takes the height of live content, here a Card.

    Variants

    .oc-browser-frame--minimal
    Only the three dots: when the address does not matter.
    .oc-browser-frame--dark
    Dark chrome in both themes, for a screenshot of a dark app.
    .oc-browser-frame--tilt
    A 3D angle that straightens when you hover it. Try it.
    .oc-browser-frame--auto
    The view takes the height of live content, here a card.

    Reference

    Styles live in packages/ui/src/parts/media-browser-frame.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-browser-frameFrame (a <figure>)
    .oc-browser-frame--minimal / --dark / --tilt / --autoDots only / dark chrome / 3D angle / free height
    .oc-browser-frame--glowShadow in the accent color, the screenshot zooms in a little on hover
    div.oc-browser-frame + .oc-browser-frame__bodyCompact frame: the bar and one body (16 / 10), the screenshot itself or a div; body prop in the components
    .oc-browser-frame__barChrome bar with three <i> dots
    .oc-browser-frame__addressAddress pill with a lock, ellipsis when narrow
    .oc-browser-frame__actionsSmall glyphs on the right
    .oc-browser-frame__viewScreenshot slot (cropped from the top)
    .oc-browser-frame__captionOptional caption
    --oc-browser-frame-ratioView ratio (default 16 / 10)

    Accessibility

    • Use <figure> + <figcaption> when the frame shows a screenshot; give the image real alt text.
    • The dots, lock and action glyphs are decorative (<i>, an empty alternative text on the lock, aria-hidden on the actions). The address is plain text.
    • The tilt only animates under prefers-reduced-motion: no-preference and is removed entirely under reduce.
