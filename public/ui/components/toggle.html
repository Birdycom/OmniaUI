    Toggle and toggle group

    A two-state button, or a connected group of them (text formatting, view mode, filters). The zero-JavaScript form wraps a checkbox or radio in a label; a <button aria-pressed> works with your own click handler. All components.

    Anatomy

    • Toggle label.oc-toggle wrapping a visually covered input, or button.oc-toggle.
    • On state a tint of the primary color via :has(input:checked), [aria-pressed="true"] or [data-state="on"].
    • Group .oc-toggle-group joins the radius and (for --outline) the borders.

    Accessibility and keyboard

    Accessibility

    • Icon-only toggles need an accessible name (aria-label on the input or button).
    • Group related toggles with role="group" (multiple) or role="radiogroup" (single) and a label.
    • Do not use a toggle for navigation or for a setting that applies immediately and is persistent: use the switch.

    Keyboard

    • Tab focuses, Space toggles. In a radio-based group the arrow keys move the selection.

    Reference

    Styles live in packages/ui/src/components-extra.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-toggleThe control
    .oc-toggle--outline / --sm / --lg / --iconVariant, sizes, square icon button
    .oc-toggle-groupConnected toggles
    .oc-toggle-group--spacedSeparate toggles with a gap
