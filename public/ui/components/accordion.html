    Accordion

    A vertically stacked set of headings that each reveal a section of content. Every item is a native <details> with a <summary> trigger: keyboard and screen reader support come from the browser, items with the same name open one at a time and the height animates in CSS. No JavaScript needed.

    Demo

    snippets/accordion.htmlNewest CSS

    CSS-first: plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/accordion.html.

    Accordion

    Is it accessible?

    Yes. It uses the native details and summary elements, so focus, Enter and Space work out of the box.

    Does it need JavaScript?

    No. Items with the same name open one at a time.

    Is it animated?

    Yes. ::details-content with interpolate-size animates the height; older browsers open without animation.

    Script-controlled

    When your own code decides which item is open, use a <button> trigger and toggle .is-open on the item (or aria-expanded="true"). A native disabled trigger dims the item.

  <div class="oc-accordion-item is-open">
    <button type="button" class="oc-accordion-trigger" aria-expanded="true" onclick="accordionSingle(this)">Can I access my account history?</button>
    <div class="oc-accordion-content"><p>Yes. Go to Settings → Account → History.</p></div>
  </div>
  <div class="oc-accordion-item">
    <button type="button" class="oc-accordion-trigger" disabled>Premium feature (disabled)</button>
    <div class="oc-accordion-content"><p>Only available on the Pro plan.</p></div>
  </div>
  <div class="oc-accordion-item">
    <button type="button" class="oc-accordion-trigger" aria-expanded="false" onclick="accordionSingle(this)">How do I update my e-mail address?</button>
    <div class="oc-accordion-content"><p>Settings → Profile → E-mail. You receive a verification link.</p></div>
  </div>
</div>
<script>
  // Single open: close the other items, toggle this one and keep aria-expanded in sync.
  function accordionSingle(trigger) {
    const item = trigger.closest(".oc-accordion-item");
    for (const other of trigger.closest(".oc-accordion").querySelectorAll(".oc-accordion-item")) {
      if (other === item) continue;
      other.classList.remove("is-open");
      other.querySelector(".oc-accordion-trigger")?.setAttribute("aria-expanded", "false");
    }
    trigger.setAttribute("aria-expanded", String(item.classList.toggle("is-open")));
  }
</script>

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

    Class / attributeDescription
    .oc-accordionThe wrapper: border, radius and a divider between items.
    .oc-accordion--flushNo outer border or radius, edge to edge.
    details.oc-accordion-itemOne item. open shows it on load; the same name on several items makes them exclusive.
    summary.oc-accordion-triggerThe heading that toggles the item; full width, chevron on the right.
    .oc-accordion-contentThe panel; its height animates via ::details-content.
    .oc-accordion-chevronOptional icon in the trigger that replaces the CSS chevron and rotates when open.
    div.oc-accordion-item.is-openScript-controlled item with a <button class="oc-accordion-trigger">; .is-open or aria-expanded="true" shows the panel.
    .oc-accordion-trigger:disabledMuted text, dimmed chevron, no hover (native disabled on a button trigger).
