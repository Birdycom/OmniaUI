    Search field

    Search field: an icon, a native input type="search" and an optional keyboard hint, in one bordered box that gets the focus ring as a whole. Pair it with the Command palette for results. All components.

  <input class="oc-search-input" type="search" name="q" placeholder="Search the docs" aria-label="Search the docs">
  <kbd class="oc-search-hint">/</kbd>
</label>

    Anatomy

    • Wrapper label.oc-search: a label, so clicking the icon focuses the input. It draws the border; :focus-within turns it into the focus ring.
    • Icon .oc-search-icon: decorative SVG (aria-hidden).
    • Input .oc-search-input: a native type="search", so you get the clear button, Esc to clear and the right mobile keyboard for free.
    • Hint .oc-search-hint: optional kbd with the shortcut; it hides while the field has focus.

    Behaviour and keyboard

    • Wrap it in a <form role="search" action="/search"> so Enter submits without JavaScript.
    • The input always needs an accessible name: aria-label or a visible label text.
    • Width: 100% up to 20rem; override with max-inline-size. In a flex toolbar it shrinks (min-inline-size: 0 on the input).
    • A live-filter list without JavaScript is not possible in CSS; use the Command component or filter on the server.

    Reference

    Styles live in packages/ui/src/docs-ui.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-searchWrapper label (border, focus ring)
    .oc-search-iconMagnifier icon
    .oc-search-inputNative search input without its own border
    .oc-search-hintShortcut hint, hidden on focus
