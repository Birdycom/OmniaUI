    Copy field

    For secrets, API keys and links. Copying needs one line of script (navigator.clipboard.writeText); the CSS provides the .is-copied state. All components.

    Demo

    Baseline

    Plain HTML and CSS. Below: the markup that builds it, also available as the snippet packages/ui/snippets/copy-field.html.

    Press Copy: the key goes to your clipboard and the button turns green and says Copied for a moment. That is the one line of script in the onclick; the CSS gives the .is-copied state.

    Large code to read and type over v0.17.0

    .oc-copy-field--display shows a code people read from a screen or a printout and type in elsewhere (a join code under a QR, a voucher): large, centred, spaced monospace, with an optional caption under it. Show the code in groups for reading and put the raw code in data-copy on the button: that is what gets copied. --oc-copy-chars (the number of characters shown) lets the code shrink to fit a narrow field; the components set it. --lg for a code read from a distance. On paper the button is left out.

    Secrets, long values and feedback v0.17.0

    masked shows a secret as dots with a show/hide toggle (aria-pressed, the eye icons swap); Copy still copies the real value. The copy button carries an icon and, after copying, says copiedLabel ("Copied"), which a hidden live region also announces. wrap lets a long token or link break over lines instead of ending in an ellipsis. Without a visible label, give the value a name with ariaLabel (default "Value", so translate it).

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-copy-fieldWrapper
    .oc-copy-field-valueRead-only <input readonly> (or <output>)
    .oc-copy-field-buttonCopy button; add .is-copied for 2s feedback. data-copy="…" is copied instead of the value.
    .oc-copy-field--display (+ --lg)Large centred code to read and type over. Prop display (true or "lg"), group (groups of n; the raw value is copied).
    .oc-copy-field-captionA short line under the code, inside the frame. Prop caption.
    .oc-copy-field-toggleShow/hide for a secret in input[type=password]: aria-pressed, aria-controls, aria-label; .oc-copy-field-icon-show / -hide (mdi:eye / mdi:eye-off) swap on aria-pressed (0.17.0). Props masked, revealLabel.
    .oc-copy-field-button-label + data-copied-labelThe button text; after copying it shows the copied label (default "Copied"). .oc-copy-field-icon-copy / -copied (mdi:content-copy / mdi:check) swap on .is-copied (0.17.0). Props copiedLabel, icon.
    .oc-copy-field-statusVisually hidden role="status" live region that announces the copied label (0.17.0).
    .oc-copy-field--wrapLong values break over lines; the value is an <output> (0.17.0). Prop wrap (not with masked).
    ariaLabel (prop)Name of the value when there is no visible label; default "Value". Same as label, and wins over it (0.17.0).

    <script>
  document.addEventListener('click', async (e) => {
    const toggle = e.target.closest('.oc-copy-field-toggle');
    if (toggle) {
      const show = toggle.getAttribute('aria-pressed') !== 'true';
      toggle.setAttribute('aria-pressed', String(show));
      const input = toggle.parentElement.querySelector('input.oc-copy-field-value');
      if (input) input.type = show ? 'text' : 'password';
      return;
    }
    const btn = e.target.closest('.oc-copy-field-button');
    if (!btn) return;
    const field = btn.parentElement;
    const value = field.querySelector('.oc-copy-field-value');
    // data-copy: the raw code when the field shows it in groups ("K7QM 2XPA" -> "K7QM2XPA")
    try { await navigator.clipboard.writeText(btn.dataset.copy ?? value.value); } catch { return; }
    // data-copied-label: the feedback on the button and in the live region (.oc-copy-field-status)
    const label = btn.querySelector('.oc-copy-field-button-label');
    const status = field.querySelector('.oc-copy-field-status');
    const done = btn.dataset.copiedLabel || 'Copied';
    if (label) { label.dataset.label ??= label.textContent; label.textContent = done; }
    if (status) status.textContent = done;
    btn.classList.add('is-copied');
    clearTimeout(btn.ocCopyTimer);
    btn.ocCopyTimer = setTimeout(() => {
      btn.classList.remove('is-copied');
      if (label) label.textContent = label.dataset.label;
      if (status) status.textContent = '';
    }, 2000);
  });
</script>
