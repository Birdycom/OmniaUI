    Message

    One chat bubble: incoming on the left with the avatar, outgoing on the right in the primary tint. It carries the sender name, the time, a "Read" receipt, a reply quote, attachments, and actions that appear on hover or keyboard focus. Consecutive messages of one sender group by themselves with :has(), and a date divider or system line separates the days. Install with npx omniaui add message. All components.

    Reference

    Styles live in packages/ui/src/parts/media-message.css. Colors are Omnia theme tokens only.

    Class / attributeDescription
    .oc-message-listColumn of messages; --oc-message-in / --oc-message-out set the bubble colors
    article.oc-messageOne row: avatar, bubble, actions; --out mirrors it and tints the bubble
    .oc-message--continuedFollows a message of the same sender: no name, avatar moves to the last message
    .oc-avatar.oc-message__avatarAvatar from the avatar component (initials or img)
    .oc-message__bubble / __sender / __textBubble, sender name and the text (paragraphs, lists, links, inline code)
    a.oc-message__quoteReply quote: strong name + span text (two lines), links back to the quoted message
    .oc-message__attachmentsHolds attachment chips or image previews
    .oc-message__meta / __status (--read, --failed)Time and read receipt
    .oc-message__actions / __action (--destructive)Icon buttons shown on hover and focus
    .oc-message-divider (--system)Date divider with lines, or a centred system notice

    Platform features used

    FeatureRole
    :has(+ …)Hide the avatar and round the corner of a message that is followed by one of the same sender
    :focus-within + @media (hover: none)Actions for keyboard and touch users
    color-mix()Outgoing bubble tint from the primary token

    Grouping without JavaScript

    • Mark follow-ups: when a message has the same sender as the one before it (and is sent within a few minutes), render it with oc-message--continued. That is one comparison in your template loop.
    • Name once: --continued hides .oc-message__sender, so the name only shows on the first bubble of a group.
    • Avatar once: .oc-message:has(+ .oc-message--continued) hides the avatar of every message that is followed by one of the same sender, so it ends up next to the last bubble. The space stays reserved, so the bubbles line up.
    • Corners: the small "tail" corner moves along the group in the same way.
    • Read receipt: show .oc-message__status--read on your last message once the other person opened the conversation, and a plain status ("Sent") before that.

    Accessibility and keyboard

    • Give the list role="log" and an aria-label when new messages arrive while the page is open; screen readers then announce them politely.
    • Each message is an <article>; an aria-label with the sender and time helps when the visible name is hidden by the grouping.
    • The actions fade in on :hover and :focus-within, so Tab reveals them. Every icon button has an aria-label. On touch screens (hover: none) they are always visible.
    • Times use <time datetime>. Colors meet contrast in light and dark mode, and the "Read" receipt is a word, not only a color.
    • The fade is switched off under prefers-reduced-motion: reduce.
