    Greeting

    The header of a dashboard: a time-of-day greeting ("Good morning, Ada"), today's date and a few actions. CSS cannot read the clock, so your app or the wrapper picks the time-of-day modifier. All components.

    Picking the modifier

    Morning is 05:00 to 12:00, afternoon 12:00 to 18:00, evening the rest. The React and Vue wrappers do this for you (pass name and optionally date); in Blade the component uses now(). Format the date with Intl.DateTimeFormat in the user's locale.

    Reference

    Slots: icon, eyebrow, title, date, actions. Tint: --oc-greeting-color.

    Class / attributeDescription
    .oc-greetingHeader row (wraps). Modifiers: --morning, --afternoon, --evening, --lg
    .oc-greeting-iconTinted icon tile
    .oc-greeting-body / -eyebrow / -title / -nameText column, small label, heading, highlighted name
    time.oc-greeting-dateToday's date
    .oc-greeting-actionsButtons at the end
