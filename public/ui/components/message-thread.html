    Message thread

    One conversation in a frame: a header with the subject, the people, a status badge and an actions menu; a scroll area on a subtle wallpaper that opens at the newest message; the chat composer pinned at the bottom; and a "Sending" overlay. The scroll position, the menu and the layout need no JavaScript. Install with npx omniaui add message-thread. All components.

    Demo

    Component snippets/message-thread.html Baselinev0.9.1

    Scroll up to read older messages, open the menu with the three dots, or type a reply and press Send (or Ctrl + Enter). The optional script shows the sending state for a moment and appends your message; the view stays at the bottom by itself.

// Optional: append the typed message as an outgoing bubble (demo behaviour; an app posts the form instead).
document.addEventListener("submit", (e) => {
  const form = e.target.closest(".oc-message-thread form.oc-chat-composer");
  if (!form || e.defaultPrevented) return;
  e.preventDefault();
  const thread = form.closest(".oc-message-thread"), field = form.querySelector("textarea"), text = field.value.trim();
  if (!text) return;
  thread.setAttribute("aria-busy", "true");
  setTimeout(() => {
    const list = thread.querySelector(".oc-message-list"), last = list.lastElementChild;
    const msg = document.createElement("article");
    msg.className = "oc-message oc-message--out" + (last?.matches(".oc-message--out") ? " oc-message--continued" : "");
    msg.innerHTML = '<span class="oc-avatar oc-message__avatar"></span><div class="oc-message__bubble"><div class="oc-message__text"><p></p></div><p class="oc-message__meta"><time></time><span class="oc-message__status">Sent</span></p></div>';
    msg.querySelector(".oc-avatar").textContent = list.querySelector(".oc-message--out .oc-avatar")?.textContent || "Me";
    msg.querySelector("p").textContent = text;
    msg.querySelector("time").textContent = new Date().toTimeString().slice(0, 5);
    list.append(msg);
    field.value = "";
    thread.removeAttribute("aria-busy");
    field.focus();
  }, 600);
});
document.addEventListener("keydown", (e) => {
  if (e.defaultPrevented || e.key !== "Enter" || !(e.ctrlKey || e.metaKey) || !e.target.matches(".oc-message-thread .oc-chat-composer__input")) return;
  e.preventDefault();
  e.target.form.requestSubmit();
});
</script>

    Platform features used

    FeatureRole
    flex-direction: column-reverseScroll area anchored at the newest message
    mask with an SVG imageWallpaper in a theme color
    popover + anchor positioningActions menu without a script
    field-sizing: contentComposer grows with the text
    backdrop-filterSoft blur behind the sending overlay

    How it works

    • Starts at the bottom: .oc-message-thread__scroll is a flex container with flex-direction: column-reverse and one child, the message list. The browser then anchors the scroll position at the end, so the newest message is in view on load and stays in view when one is added. No scrollTop = scrollHeight needed.
    • Layout: the thread is a three-row grid (header, messages, footer) with a fixed height from --oc-message-thread-height; only the middle row scrolls.
    • Wallpaper: a small line drawing (chat bubble, note, sun, house, lamp) used as a CSS mask on a pseudo-element, painted in a token color. It follows light and dark mode; --plain turns it off.
    • Actions menu: the dropdown menu on popover, anchored to its button.
    • Optional script (about 20 lines): appends the typed text as an outgoing bubble with textContent (never innerHTML for user text), and sends with Ctrl + Enter.

    Accessibility and keyboard

    • The scroll area has role="log", aria-live="polite" and an aria-label, so new messages are announced. With tabindex="0" it can be scrolled with the arrow keys.
    • The thread is a <section> labelled by its title. The menu button has an aria-label; the menu closes with Esc or a click outside.
    • The overlay has role="status", so "Sending message…" is read out. The blur behind it is removed under prefers-reduced-motion: reduce.
