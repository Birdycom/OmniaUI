    Time input

    A 24-hour time field (HH:mm) that looks the same in every locale. It is a short text field with a pattern and a <datalist> of suggested slots. For booking forms, the slot list shows the times as radio chips. No JavaScript; the wrappers add the colon while typing (0930 → 09:30). All components.

    Demo

    Slot list

    Radio chips in a grid. The checked slot is primary; a disabled slot is struck through (already booked). Arrow keys move between slots.

    Reference

    Styles live in packages/ui/src/parts/forms-time-input.css. Prefer the native type="time" picker? See Date picker; it shows AM/PM in some locales.

    Class / attributeDescription
    .oc-time-inputAdd to .oc-input: narrow centered field; red on :user-invalid
    pattern + list([01][0-9]|2[0-3]):[0-5][0-9] and the id of a <datalist>
    .oc-time-slotsSlot grid (role="radiogroup"). Modifier: --sm.
    .oc-time-slotLabel with one radio and the time text

    Framework wrappers

    slots fills the datalist. The value is always HH:mm or an empty string.

<TimeInput value={time} onChange={setTime} slots={["08:00", "08:30", "09:00"]} aria-label="Start" />
<!-- Vue -->
<OcTimeInput v-model="time" :slots="['08:00', '08:30']" aria-label="Start" />
<!-- Laravel Blade -->
<x-oc::time-input name="start" value="08:30" :slots="['08:00', '08:30']" />
