    Attachment

    A file chip or an image preview for chat messages and composers. The icon tile shows the extension and is tinted per type (PDF, document, sheet, archive, image); the chip shows the name, the size and, in a composer, a remove button. Upload progress and errors are states on the same chip. Install with npx omniaui add attachment. All components.

    Demo

    Component snippets/attachment.html 0 KB JavaScriptBaselinev0.9.1

    From top to bottom: file chips in a message, an image preview, and the row of files waiting in a composer (a pasted screenshot, an upload in progress and a file that is too large). The pictures are placeholders; use an <img>.

    Hover a file chip or the picture: the frame lights up. In your app each one is a link to the file; in this preview they go nowhere.

    import { useState } from "react";
import { AttachmentList, ChatComposer, Webicon, type AttachmentFile } from "@birdycom/omniaui-react";

export function Example() {
  const [files, setFiles] = useState<AttachmentFile[]>([
    { name: "screenshot-14-10.png", size: "412 KB", image: "/uploads/screenshot-14-10.png", removable: true },
    { name: "Floor plan kitchen.pdf", size: "3.4 MB", removable: true },
  ]);
  return (
    <div style={{ display: "grid", gap: "0.5rem", inlineSize: "100%", maxInlineSize: "32rem" }}>
      <AttachmentList stack items={files} aria-label="Files to send" onRemove={(_, i) => setFiles(files.filter((__, j) => j !== i))} />
      <ChatComposer
        inline
        placeholder="Add a note to the files…"
        tools={<button type="button" className="oc-chat-composer__tool" aria-label="Attach a file"><Webicon name="mdi:paperclip" /></button>}
        onSend={(text) => console.log("send", text, files)}
      />
    </div>
  );
}

    Reference

    Styles live in packages/ui/src/parts/media-attachment.css. Colors are Omnia theme tokens only.

    Class / attributeDescription
    .oc-attachment-list (--stack)Wrapping row of chips, or one per line at full width
    .oc-attachmentFile chip (link or div), max 20rem wide
    --pdf / --doc / --sheet / --zip / --imageTint of the icon tile per file type
    --uploading + --oc-attachment-progressProgress line along the bottom (set the percentage inline)
    --errorRed border and message
    .oc-attachment__iconPage tile with the extension, or an img for a small preview
    .oc-attachment__body / __name / __sizeName (truncates) and size or status
    button.oc-attachment__removeRound remove button
    a.oc-attachment-image / __captionImage preview in a message (4 : 3) with an optional caption
    .oc-attachment-thumbSquare thumbnail with a remove button on top

    Platform features used

    FeatureRole
    clip-path + gradientPage tile with a folded corner
    color-mix()Type tint from a theme token
    Custom propertyUpload progress without a script

    Accessibility and keyboard

    • A chip that opens or downloads the file is a link (<a href download>); in a composer it is a plain div with a remove <button>. The link and the button are separate tab stops.
    • The extension tile is decorative (aria-hidden="true"): the file name already says the type. Image previews need alt text.
    • Remove buttons need an aria-label with the file name ("Remove Floor plan kitchen.pdf"), so a list of them stays clear.
    • Put role="status" on the size text while uploading, so progress and errors are announced. The error state uses words as well as color.

    Framework wrappers

    The same markup and classes as React, Vue and Blade components. Their props follow the class modifiers on this page; see the source files below.
