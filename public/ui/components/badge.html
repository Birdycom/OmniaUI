    Small labels for a status, a count or a category next to text or in a table cell. Seven variants plus a set of status badges with icons, all on theme tokens, so they follow light and dark mode. All components.

    Source and version badges v0.17.0

    The small labels at the top of every docs section on omniacss.eu and omniaui.eu: where the code lives and since which version. One color per kind; each has its own --oc-badge-* tokens. Components: BadgeSource / VersionBadge (React), OcBadgeSource / OcVersionBadge (Vue), <x-oc::badge-source> / <x-oc::version-badge> (Blade); kind="mdi" gives the icon-set badge.

    Badge - source and version

    .oc-badge-source
    What it is: Component, Block or Utility.
    Component
    .oc-badge-source-file
    A file path: a snippet, a block or a CSS file.
    snippets/badge.html
    .oc-badge-source-scss
    A SCSS source file.
    _badges.scss
    .oc-badge-version
    Since which version the item exists.
    v0.12.1
    .oc-badge-version-mdi
    Which version of an icon set is used.

    Status badges v0.17.1

    A ready-made set for the statuses an app shows all day: invoices, documents, reviews and tasks. One class, .oc-badge--status, with the status in data-status: the colour follows the meaning (green done, amber waiting, red needs action, blue on its way, grey over or quiet) and a webicon before the label makes it readable without colour. React, Vue and Blade take status and add the icon and the English label themselves; your own text (a translation) replaces the label, icon replaces the icon (false: none). Statuses: paid, pending, overdue, refunded, draft, sent, scheduled, cancelled, archived, approved, rejected, read-only, active, inactive, in-progress, done, failed (and working, waiting, error, idle of the status dot). Any other name gets the colour you give --oc-badge-status.

    Read-only value v0.17.1

    variant="readonly" shows a value the user sees but cannot change here: the customer of an invoice, the account a booking goes to, a linked record. Squarer and calmer than a status pill, at the size of body text, with the icon in the muted colour; a long name is cut off with an ellipsis and title shows it in full. In plain HTML wrap the text in a <span> so it can be cut off.

    Reference

    Styles live in packages/ui/src/components.css. Colors are theme tokens, so everything follows light and dark mode.

    Class / attributeDescription
    .oc-badgeDefault: primary color.
    --secondary / --outlineMuted fill, or only a border.
    --success / --warning / --info / --destructiveStatus colors.
    <svg> / <iconify-icon> insideA webicon before the text: 1em, with a small gap. React, Vue and Blade: icon. With title and no text the badge is role="img" with that title as aria-label.
    .oc-badge--status + data-statusA status from the set (paid, pending, overdue, draft, sent, cancelled, approved, rejected, active, inactive, archived, failed, refunded, scheduled, in-progress, done, read-only, working, waiting, error, idle). Your own status: --oc-badge-status. React, Vue and Blade: status (icon and label included).
    .oc-badge--readonlyA read-only value (customer, account): squarer, body text size, muted icon; the inner <span> is cut off with an ellipsis.
    .oc-badge-sourceWhat it is or where it comes from (Component, Block, Utility). Teal.
    .oc-badge-source-fileA file path (snippet, block, CSS file). Purple.
    .oc-badge-source-scssA SCSS source file. Red.
    .oc-badge-version / .oc-badge-version-mdiSince which version (or which icon set version). Green.
    --oc-badge-source-color, --oc-badge-version-color …One set of tokens per kind (color, background, border, padding, radius, font size) to restyle them.
