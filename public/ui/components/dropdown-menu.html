    <?php

namespace App\Livewire;

use Livewire\Component;

class ViewMenu extends Component
{
    public bool $statusBar = true;

    public bool $activityBar = false;

    public string $panel = 'bottom';

    public function toggleStatusBar(): void
    {
        $this->statusBar = ! $this->statusBar;
    }

    public function toggleActivityBar(): void
    {
        $this->activityBar = ! $this->activityBar;
    }

    public function setPanel(string $position): void
    {
        $this->panel = in_array($position, ['top', 'bottom'], true) ? $position : 'bottom';
    }

    public function delete(): void
    {
        // delete the item, then redirect or toast
    }

    public function render()
    {
        return view('livewire.view-menu');
    }
}

    With a description and a tinted icon v0.17.0

    For a menu where each choice needs a word of explanation: wrap the label in .oc-dropdown-text and add a .oc-dropdown-desc under it, a muted second line that may wrap (the menu stays at most 22rem wide). .oc-dropdown-icon--primary, --success, --warning, --destructive or --muted put the icon in a soft tinted square of that color, so the kinds are easy to tell apart. React and Vue: description and iconTone on the item; Blade: 'description' and 'tone'.

    Anatomy

    • Check / radio items the indicator is a pseudo-element shown when aria-checked="true", so state and visual cannot drift apart. Your click handler flips the attribute.
    • Sub-menu a .oc-dropdown-sub wrapper (position: relative) with a trigger item and an absolutely positioned .oc-dropdown-submenu; opens with :hover and :focus-within.
    • Shortcut push key hints right with .oc-dropdown-shortcut (can contain kbd.oc-kbd).

    Accessibility and keyboard

    Accessibility

    • Use role="menu" on the panel and menuitem, menuitemcheckbox, menuitemradio on items; set aria-haspopup="menu" on sub-menu triggers.
    • Sub-menus open on focus-within, so keyboard users reach them with Tab; full roving arrow-key handling is wrapper responsibility.

    Keyboard

    • Enter/Space activates an item, Esc closes the popover. Wrapper: → opens a sub-menu, ← closes it.
