    Scroll area

    A bounded region that scrolls, with a thin themed scrollbar. .oc-scroll-area is the panel; the older .oc-scrollbar utilities style the scrollbar on any element. Optional edge shadows show where more content is hiding. All components.

    Demo

    Plain HTML and CSS. The markup is also available as the snippet packages/ui/snippets/scroll-area.html. Scroll inside the panels, or Tab into them and use the arrow keys.

    Reference

    Styles live in packages/ui/src/components-extra.css (extensions) and components.css (base). Colors are theme tokens (--oc-*), so light and dark mode work without extra classes.

    Class / attributeDescription
    .oc-scroll-areaBordered panel, scrolls on both axes. Set the limit with max-block-size or block-size.
    .oc-scroll-area--xHorizontal only, no wrapping.
    .oc-scroll-area--shadowsEdge shadows while content is hidden: local and scroll-attached gradients, so a shadow appears only at an edge with more content.
    .oc-scrollbarThin themed scrollbar on any overflow element.
    tabindex="0", role="region", aria-labelMake the region keyboard reachable and give it a name. Tab focuses it, then ↑ ↓ PageUp PageDown Home End scroll it.

    Platform features used

    CSS featureRole
    scrollbar-colorThumb and track colors from theme tokens; browsers without it keep their default scrollbar.
    scrollbar-widthThin scrollbar.
    background-attachmentlocal vs scroll layers draw the edge shadows.
