    Add one to your project

    Install the package for the styles, then copy the component you need in the flavour you use. The command writes the file into your project; you own the code from then on.

    1
2
3
4
    npm install @birdycom/omniaui
npx omniaui add modal                 # plain HTML
npx omniaui add modal -f vue          # or -f react, -f blade
npx omniaui list components

    In your editor: OmniaCSS IntelliSense for VS Code and Cursor completes every oc-* class and shows its CSS on hover, from the OmniaUI version your project has installed (Pro included when you have it).

    Actions

    Buttons, toggles and the controls people press.

    ButtonUpdated
    Buttons in primary, secondary, outline, ghost, link, destructive and success variants, with sizes, icons, a loading state, toggles and groups.omniaui add button14 demos
    Button groupUpdated
    Button group: joined buttons with shared borders, side by side or stacked, with a text cell for a count. The text cell is not a button.omniaui add button-group2 demos
    KbdUpdated
    Kbd: a keyboard key and a shortcut group such as Ctrl K, with or without a plus between the keys. Used in text, in buttons and next to menu items.omniaui add kbd2 demos
    Segmented control
    A radio group drawn as a pill switcher for a single choice. :has() highlights the active segment; arrow keys and form submission work natively.omniaui add segmented1 demo
    Toggle and toggle groupUpdated
    Toggle: a button that stays pressed, on a checkbox, radio or aria-pressed. Icon toggles, joined or spaced groups, single choice and three sizes.omniaui add toggle3 demos

    Forms

    Inputs, pickers and fields on native form elements.

    Affix input
    Input group variant with a prefix or suffix inside the field: the symbol sits in its own column with a divider. Error and disabled states included.omniaui add affix-input2 demos
    Avatar pickerUpdated
    Avatar or company logo picker with a preview, Upload and Remove buttons, drag and drop, a size limit in the browser and a server error message.omniaui add avatar-picker1 demo
    Barcode inputUpdated
    Monospace field for an EAN-13 or internal article code, with a preview of placeholder bars or your own barcode graphic, an empty and an error state.omniaui add barcode-input2 demos
    CalendarUpdated
    Month grid markup and styling: a grid of day buttons with today, selected, outside-month, disabled and range states, in light and dark mode.omniaui add calendar3 demos
    Chip filterUpdated
    Rounded filter chips above a list, with single or multiple choice, counts per chip, disabled options, a small size and a scrolling row.omniaui add chip-filter2 demos
    Color fieldUpdated
    Native color picker next to a hex text input, with an optional contrast check: text on the color and the color on the light and the dark page.omniaui add color-field2 demos
    Color selectUpdated
    Pick one color from a fixed set of swatches on radio inputs, with names, colors that are in use and cannot be chosen, and a list for a popover.omniaui add color-select2 demos
    ComboboxUpdated
    Input with a listbox of suggestions: icons, server search, a clear row and a manage link. Filtering and choosing come from a wrapper or script.omniaui add combobox3 demos
    Copy fieldUpdated
    A read-only monospace field with a copy button for API keys, secrets and links. One line of script copies the value; CSS shows the copied state.omniaui add copy-field3 demos
    Date fieldUpdated
    Native date input with a calendar icon zone and the ISO week (Week 45) next to it, an optional year in the label and a small size variant.omniaui add date-field1 demo
    Date pickerUpdated
    Date picker: a trigger button that opens a month calendar in a popover, with keyboard navigation; a pick closes it. Shown next to a native date input.omniaui add date-picker1 demo
    Decimal input
    A text field for numbers written the local way, like 1.234,56, with a numeric keyboard on phones, a pattern for validation and an optional unit.omniaui add decimal-input2 demos
    Dropzone
    A file upload target: a label around a real, invisible file input, so clicking and keyboard work natively, with a drag-over state for feedback.omniaui add dropzone1 demo
    Filter countsUpdated
    View tiles such as Active, Deleted and All that show how many items each holds, on radio buttons, with tones, a hint line and a compact size.omniaui add filter-counts2 demos
    Form density
    Compact forms: .oc-density-compact on a form or wrapper makes every input, select, textarea and button in it 2rem high instead of 2.5rem.omniaui add form-density1 demo
    Form sectionUpdated
    Collapsible part of a long form with an icon, title, hint and status on native details; a red edge while a field inside is invalid, also when closed.omniaui add form-section4 demos
    Forms & InputsUpdated
    Form fields with label, help, error and tooltip, input masks with validation, a compact ledger look, input groups, select, textarea, checkbox and switch.10 demos
    LabelUpdated
    Form label with a required asterisk, an inline form that wraps a checkbox or radio, and a muted form for optional fields. Links to its control with for.omniaui add label1 demo
    Language selectUpdated
    A compact locale or currency switcher for a site header: a native select in a small pill with a leading icon, so phones get the system picker.omniaui add language-select7 demos
    Native select
    The real select element, themed in every browser. With the custom modifier, browsers that support base-select also theme the open picker panel.omniaui add native-select1 demo
    Number input
    A native number input between minus and plus buttons. Min, max and step come from the input, and the buttons call stepDown() and stepUp() for you.omniaui add number-input2 demos
    OTP inputUpdated
    A one-time code field drawn as separate cells on a single real input, so paste, autofill and password managers keep working. The length is a token.omniaui add otp-input3 demos
    Password input
    A password field with a show and hide button over the input. The button flips the input type, with aria-pressed for the state and an optional script.omniaui add password-input1 demo
    Password requirements
    A live checklist of password rules under a new password field. Each rule turns green with a check when met, announced politely to screen readers.omniaui add password-requirements2 demos
    Phone inputUpdated
    Country dial code select joined to a phone number field, with an error state and a small size; the code and the number post as two fields.omniaui add phone-input2 demos
    Quantity
    Number field with minus and plus buttons for amounts in carts, orders and stock. The buttons step within min, max and step and switch off at the limits.omniaui add quantity1 demo
    Radio groupUpdated
    Radio group on native inputs in a fieldset with a legend: stacked or in a row, a disabled option, a second line of description and a bordered card style.omniaui add radio3 demos
    Rating
    Star rating: show a score with halves or tenths, or let people pick 1 to 5 stars with hover preview and arrow keys as a normal form value. No JavaScript.omniaui add rating2 demos
    Recovery codesUpdated
    A warning panel with a grid of two-factor recovery codes, shown once after setup, with copy, download and print actions and a Copied message.omniaui add recovery-codes2 demos
    Search fieldUpdated
    Search field: an icon, a native search input and an optional key hint such as / in one bordered box with one focus ring. Pairs with the command palette.omniaui add search1 demo
    SliderUpdated
    Slider on a native range input with a themed track, fill and thumb. Examples with the value shown, a scale, a step, disabled and vertical.omniaui add slider2 demos
    Tag input
    Chips with remove buttons and a free-text field in one bordered control, with suggestions. The chips also work alone as labels for tags or filters.omniaui add tag-input1 demo
    Time input
    A 24-hour time field (HH:mm) that looks the same in every locale: a short text field with a pattern and an optional list of suggested time slots.omniaui add time-input2 demos
    Toggle field
    A settings row with a title, a description and a switch. The whole row is a label, so clicking the text flips the switch, with keyboard support built in.omniaui add toggle-field2 demos

    TooltipUpdated
