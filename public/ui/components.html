    Components

    Themeable building blocks with the oc- prefix. Native HTML does the behaviour: dialogs on <dialog>, menus on popover, tabs on radio inputs and :has(). Every page has live demos you can resize, copy-ready code and the browser support straight from MDN.

    Add one to your project

    Install the package for the styles, then copy the component you need in the flavour you use. The command writes the file into your project; you own the code from then on.

    1
2
3
4
    npm install @birdycom/omniaui
npx omniaui add modal                 # plain HTML
npx omniaui add modal -f vue          # or -f react, -f blade
npx omniaui list components

    In your editor: OmniaCSS IntelliSense for VS Code and Cursor completes every oc-* class and shows its CSS on hover, from the OmniaUI version your project has installed (Pro included when you have it).
