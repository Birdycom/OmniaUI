    Blocks

    Whole sections and screens, composed from OmniaCSS utilities and OmniaUI components: dashboards, sign-in flows, landing page sections. Open one to resize the live demo, copy the HTML, or add it to your project as Vue, React or Blade with one command. Blocks marked Pro are part of OmniaUI Pro: their demos are live here, their code comes with a license.

    • 99blocks
    • 47free
    • 52Pro
    • 4categories
    • 4flavours: HTML, Vue, React, Blade

    Add one to your project

    Install the package for the styles, then copy the block you need in the flavour you use. The command writes the file into your project; you own the code from then on.

    1
2
3
4
    npm install @birdycom/omniaui @birdycom/omniaui-blocks
npx omniaui add pricing                 # plain HTML
npx omniaui add pricing -f vue          # or -f react, -f blade
npx omniaui list blocks

    In your editor: OmniaCSS IntelliSense for VS Code and Cursor completes every oc-* class and shows its CSS on hover, from the OmniaUI version your project has installed (Pro included when you have it).
