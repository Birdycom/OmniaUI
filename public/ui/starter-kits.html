    Starter kits

    Four Laravel starter kits, rebuilt from the official Laravel kits with OmniaCSS utilities and OmniaUI components: Livewire, Blade, React and Vue. Same backend and tests (Laravel Fortify: sign-in, two-factor, passkeys, settings), no Tailwind, and every kit ships only the CSS it uses, about 13 to 15 kB gzipped. Free and MIT licensed. Try a live demo, or start a new app with one laravel new command.

    Click a kit to open its live demo in a new tab. The demo account is filled in on the login page.

    Live demo

    Every kit runs as a live app. Log in with the demo account (already filled in) or register your own account.

    • Demo account: demo@omniaui.test with password password.
    • Everyone shares the demo account and its data is reset every hour, so do not store anything you want to keep.
    • Try two-factor, passkeys, the profile and appearance settings, and the light and dark theme.

    In every kit

    The same screens and the same tests in all four kits.

    • Sign-in and sign-up: login, registration, password reset, email verification and password confirmation, all by Laravel Fortify.
    • Two-factor and passkeys: authenticator app with QR code and recovery codes, plus passkeys for sign-in without a password.
    • Settings: profile, security and appearance pages, and deleting the account with a confirmation.
    • App shell: collapsible sidebar or a top bar, breadcrumbs, user menu, and a sheet on phones.
    • Light and dark: follows the operating system or the user's choice, without a flash on load.
    • Only the CSS you use: the OmniaCSS PostCSS plugin scans your views and keeps only the used utilities, components and blocks.

    Filament panel

    A prototype: birdycom/omniaui-filament runs a Filament panel on OmniaCSS and OmniaUI, without a Tailwind build.

    • Your own Filament pages and widgets use OmniaUI Blade components (<x-oc::stat-card>, <x-oc::tabs>, charts) and OmniaCSS utilities.
    • Filament's colors come from the OmniaUI palette, and OmniaUI follows Filament's light, dark and system setting.
    • Filament's own screens keep Filament's compiled CSS; the package does not restyle the fi-* components.
    • With OmniaUI Pro, the Pro blocks (charts, calendars, inbox, dashboards) work in Filament pages too.

    Icons

    The kits use the OmniaCSS webicons, bundled with the app: no icon font and no calls to an icon API.

    Installed sets: Material Design Icons (mdi:), MDI Light (mdi-light:), Material Symbols (material-symbols:), SVG Spinners (svg-spinners:), Flags (flag:) and VSCode Icons (vscode-icons:). Write an icon name in a view and the build adds only that icon.

    1
2
    <x-icon name="mdi:cog-outline" />               <!-- Livewire and Blade -->
<Icon icon="material-symbols:home-outline" />  <!-- React and Vue -->

    AI assistants

    The OmniaCSS MCP server checks every class and gives your assistant the reference markup of every component, so it extends the kit without falling back to Tailwind. Without MCP, point it at omniacss.eu/llms.txt and omniaui.eu/llms.txt.

    1
    claude mcp add omniacss -- npx -y @birdycom/omniacss-mcp
