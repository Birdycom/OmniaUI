    Laravel

    birdycom/omniaui-laravel turns every component and block into an anonymous Blade component under the prefix oc: <x-oc::button variant="primary">, <x-oc::block.app-shell>. The markup and classes are exactly the ones in the HTML snippets; the CSS packages own all styling and dark mode (light-dark()), so there are no colors in PHP. Props map to modifiers, slots become $slot and named slots, and $attributes is merged onto the root element. React and Vue have their own wrappers.

    Installation

    PHP 8.2+ and Laravel 11, 12 or 13. The service provider is auto-discovered.

    1
2
3
    composer require birdycom/omniaui-laravel
php artisan omniacss:install
npm install && npm run dev
    • omniacss:install: detects Vite, adds @birdycom/omniacss and @birdycom/omniaui (--blocks adds @birdycom/omniaui-blocks) to package.json, puts the @import lines at the top of resources/css/app.css, publishes config/omniacss.php and prints the next steps. Use --dry-run to see the changes without writing anything.
    • Layout: add the @omniacss directive to the <head> of your layout.
    1
2
3
4
    <head>
    <meta charset="utf-8">
    @omniacss
</head>

    Usage

    Props become modifiers (variant, size, boolean flags), the default slot is the content and named slots fill regions. Extra attributes (class, wire:*, x-*, data-*) are merged onto the root element. Form controls pass their attributes to the real input, so name, value and validation work as expected.

    1
2

    <x-oc::card title="Create project" description="Deploy your new project in one click.">
    <x-oc::form-field label="Name" for="name" :error="$errors->first('name')">
        <x-oc::input id="name" name="name" placeholder="My project" />
    </x-oc::form-field>

    <x-slot:footer>
        <x-oc::button variant="outline">Cancel</x-oc::button>
        <x-oc::button type="submit">Deploy</x-oc::button>
    </x-slot:footer>
</x-oc::card>

    Livewire

    birdycom/omniaui-livewire adds Livewire 3 variants where state matters. It uses the same oc prefix.

    1
    composer require birdycom/omniaui-livewire
    ComponentWhat it does
    wire.input, wire.textarea, wire.select, wire.switch, wire.checkboxmodel, live, blur, debounce shorthand for wire:model; validation errors set the error state
    wire.segmented, wire.otp, wire.tag-inputBound to a property: every radio, a one-time code with complete="verify", an array of tags via $wire.entangle
    wire.modal, wire.sheet, wire.alert-dialogOpen state entangled with ocModals.{name} (trait WithOcModal) or any boolean model
    toast-stackListens for the oc-toast browser event; $this->ocToast('success', 'Saved') from trait WithOcToast
    Omniacss\Livewire\DataTableAbstract component on the data-table block: search, sortable columns, pagination, row actions
