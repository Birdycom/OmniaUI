    Icons

    OmniaCSS UI uses Iconify with Material Design Icons (MDI) from Pictogrammers: only icons used on the page are loaded as SVG. No icon font; no full set in the bundle. See the Pictogrammers Iconify guide and our Settings page for reference and sizing.

    Installation

    Load the Iconify script once (CDN or npm). It replaces placeholders with SVG on demand.

    • CDN: Add <script src="https://cdn.jsdelivr.net/npm/@iconify/iconify@3/dist/iconify.min.js" crossorigin="anonymous"></script> before </body>.
    • npm: @iconify/iconify — import or bundle as needed.
    1
    <script src="https://cdn.jsdelivr.net/npm/@iconify/iconify@3/dist/iconify.min.js" crossorigin="anonymous"></script>

    Usage

    Use class="iconify" and data-icon="mdi:<name>" (MDI), data-icon="mdi-light:<name>" (MDI Light), or other sets like svg-spinners:, flag:, material-symbols:, and vscode-icons:. In the catalog, regular tiles = MDI, violet background = MDI Light. Size with size-N (N 1–24). Full list: Icon catalog.

    Example

    One icon to show the pattern. Browse more in the catalog.

    Example

    data-icon="mdi:home" + class="iconify size-8" 
    1
    <span class="iconify size-8" data-icon="mdi:home" aria-hidden="true"></span>
